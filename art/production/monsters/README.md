# 한뎃벌 몬스터 스프라이트

`docs/monsters.md` 9.1–9.3절의 일반 적 100장, 엘리트 17장, 보스·졸개 135장이 37개 PNG 시트에 있습니다. 9.5절의 보스 초상 96×96과 체력 바 아이콘 32×32는 각 6장입니다.

- 기본 자세는 `preview-regular.png`, `preview-bosses.png`, `preview-elites.png`에서 확인할 수 있습니다.
- `manifest.json`의 `entries`가 전투 스프라이트를, `bossUi`가 초상과 체력 바 아이콘을 가리킵니다. 일반 적은 2.1절 ID에 `enemy.`를 붙였고 보스와 엘리트는 문서의 이름 범위에 맞춰 영문 ID를 정했습니다.
- `size`는 한 프레임의 가로와 세로입니다. 프레임별 `rect`는 시트 내부의 `[x, y, width, height]`, `origin`은 프레임 내부의 기준점입니다. 좌표는 왼쪽 위에서 시작합니다. nearest 텍스처 필터를 사용하고, 이동 방향에 따라 좌우 반전합니다.
- 스승의 허상은 플레이어 지팡이를 회색으로 렌더링해 붙입니다. 밝은 림, 타격 번쩍임, 잔상과 공격 구역은 런타임 효과입니다. 엘리트 장식은 별도 레이어입니다. 종과 자세마다 붙일 위치는 게임에서 정합니다.

`draw_monsters.py`의 정수 좌표로 각 자세의 실루엣, 재질 색면과 하이라이트를 직접 그렸습니다. 스크립트를 실행하면 전투 시트, 보스 초상·아이콘, 미리보기와 매니페스트를 다시 내보냅니다. 전투 셀의 프레임 수, 크기, 이진 알파, 여백과 위치를 확인했습니다. 실제 전투에서의 재생 속도와 부착 위치는 연결 후 확인해야 합니다.
