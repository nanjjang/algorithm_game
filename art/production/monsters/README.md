# 한뎃벌 몬스터 스프라이트

`docs/monsters.md` 9.1–9.3절을 기준으로 작업했습니다. 정지 자세는 `preview-regular.png`, `preview-bosses.png`, `preview-elites.png`에서 확인할 수 있습니다.

## 불러오기

- `manifest.json`의 `entries` 키가 에셋 ID입니다. 일반 적은 2.1절의 ID에 `enemy.`를 붙였고, 보스와 엘리트는 기획서에 지정된 개별 ID가 없어 이 폴더에서 영문 ID를 정했습니다.
- `size`는 프레임 크기입니다. `clips`의 프레임에는 PNG 안의 픽셀 좌표 `rect = [x, y, width, height]`와 프레임 내부의 기준점 `origin = [x, y]`가 들어 있습니다. 좌표 원점은 왼쪽 위입니다.
- 텍스처 필터는 nearest를 사용합니다. 발이 있는 적은 발 위치, 비행 적은 캔버스 가운데가 기본 기준점입니다. 이동 방향에 따라 좌우로 반전합니다. 애니메이션 속도와 피격 판정은 게임에서 정합니다.
- 스승의 허상 지팡이는 플레이어 지팡이를 회색으로 렌더링해 손 위치에 붙입니다. 밝은 림, 타격 번쩍임, 잔상, 공격 구역은 게임에서 그립니다. 엘리트 장식은 오버레이로 제공하며, 종과 자세에 따라 붙는 위치를 맞춰야 합니다. 쌍둥이불은 전용 본체 시트를 사용합니다.

## 그림 제작

기본 제공 ImageGen에 사용자 레퍼런스를 스타일로 넣고 종별 기본 실루엣을 만든 뒤, 그 기본 시안을 입력으로 삼아 동작 시트를 생성했습니다. 결과를 프레임별로 잘라 알파 경계를 정리하고, nearest-neighbor로 기획서의 픽셀 캔버스에 맞췄습니다. 허상의 은회색 팔레트는 캔버스에 배치하기 전에 보정했습니다.

- 공통 프롬프트의 요지는 한국 설화풍 게임 스프라이트, 큰 픽셀 색면에 필요한 곳만 작은 재질 표현, 남색 외곽선, 분리된 셀과 투명 여백입니다. 첫 시안은 사용자 레퍼런스의 실루엣과 색 단계를 바탕으로 다시 생성했습니다.
- 일반 적은 2.2–2.3절의 종별 실루엣과 색, 이동·예고·공격·사망의 순서를 입력했습니다. 예를 들어 갓버섯 술사는 갓 윗면의 숯 얼굴과 지팡이를, 덤불 늑대는 등 가시·잎 꼬리와 달리기·돌진을 지정했습니다.
- 보스는 3.3–3.9절과 9.3절을 입력했습니다. 가마등은 가마와 연장, 허상은 얼굴을 대체한 타원형 거울과 빈 손, 밤삼킴은 초승달 볏과 머리·마디·꼬리 분리를 지정했습니다.
- 엘리트는 3.1절의 부착물, 뿔 표식, 박쥐 급강하와 쌍둥이불 떠 있기 자세를 입력했습니다.

생성·검수 상태는 매니페스트의 `artwork`와 `missingOrProvisional`에 표시합니다. 알파와 시트 좌표 검증은 별도로 수행했으며, 게임 플레이에서의 프레임 전환과 부착 위치는 확인 전입니다.
