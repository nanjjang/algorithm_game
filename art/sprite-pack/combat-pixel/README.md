# 전투 도트 에셋

소울 나이트의 인게임 화면을 참고해 작은 해상도에서 실루엣과 HUD 상태를 알아볼 수 있게 그린 에셋이다. 제자와 몬스터의 모양, 주문 블록과 색은 프로젝트 기획서를 따른다.

| 폴더 | 포함된 에셋 |
|---|---|
| `players/` | 제자 5명. 대기 4장, 옆 걷기 4장, 앞·뒤 걷기 각 2장, 시전 4장, 피격 2장, 쓰러짐 2장. 각 64×64. 오른쪽 3/4 자세를 반전해 왼쪽에 쓸 수 있다. |
| `enemies/` | 일반 적 12종, 보스 6종, 갓버섯 새싹, 밤눈 지상, 밤삼킴 마디·꼬리. 이끼 슬라임에는 피격·사망, 덤불 늑대·갓버섯 술사·허상에는 공격·시전 등의 별도 동작을 포함한다. 다른 적과 보스는 기본 동작 2장씩이다. |
| `world/` | 느루의 흔들의자, 행상 수레, 까마귀, 연습 허수아비. 4장씩. |
| `combat-art/wands/` | 지팡이 5종의 +0~+13. 한 단계당 손에 든 투명 PNG 1장. 통합 시트는 행이 지팡이, 열이 단계다. |
| `combat-art/fx/` | 투사체 6종의 발사체·적중 시트와 사망 연기·과열 증기·회피 먼지 시트. |
| `gui/` | 체력·결정·코인·회로 슬롯·버튼 상태·메뉴 부품. 주문 블록 16종, 비기 15종 및 잠금 아이콘을 각각 24px와 48px로 제공한다. |

`motion-preview.gif`는 전투 HUD에서 그믐의 걷기·시전, 발사체의 비행·적중, 몬스터 동작을 이어 재생한다. `players/motion-preview.gif`에는 제자 다섯 명의 동작을, `combat-art/combat-playback.gif`에는 이펙트 재생을 모았다. `gui/menu-preview.png`는 메뉴 부품을 배치한 예시다.

각 `manifest.json`의 좌표는 시트 좌상단 기준이다. 프레임마다 영역, 순서, 재생 시간과 필요한 기준점을 기록했다. 캐릭터와 지팡이는 별도 이미지다. Unity에서는 필터 `Point`, 밉맵과 압축 해제를 기준으로 잡는다.

기획서의 나머지 적·보스별 공격과 사망 동작, 엘리트 덧그림, 지팡이의 방향·자세별 그림과 전체 메뉴 화면은 이 묶음에서 아직 빠져 있다. 미리보기는 에셋을 조합한 영상이며 Unity 씬 연결은 남아 있다.
