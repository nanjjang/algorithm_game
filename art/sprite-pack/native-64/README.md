# 제자 64×64 원본과 PC 강화 화면

`characters/`는 64×64 격자에 직접 색을 배치한 제자 다섯 명이다. 각 제자의 `sheet.png`는 열 4칸, 행 5칸이다. 위부터 대기, 걷기, 시전, 강화 성공, 강화 실패 순서다. 각 동작 폴더에 한 줄짜리 시트와 개별 투명 PNG가 있다. 몸과 지팡이는 별도 층이며 좌상단 좌표, 발과 손 위치, 프레임 시간은 `manifest.json`에 있다.

`enhancement/`는 `docs/effects.md` 1.2절과 20.1절, `docs/ui-assets.md` 4.12절의 PC 전용 강화 화면을 따랐다. `background/workbench.png`는 화면 전체 배경이다. 느루·촛불, 지팡이, 마법진, GUI와 효과는 분리했다. 가운데 무대만 2배 정수 배율로 사용한다.

- 새 작업대, 느루와 촛불, 공용 마법진 5겹, 속성 문양 5종, 변이 아이콘 6종, 강화 버튼과 창 바탕을 포함했다.
- 다섯 지팡이의 192×192 큰 그림을 +0부터 +13까지 묶었다. +7은 이번 그림이며 다른 단계는 기존 `art/production/wands` 그림이다. 기존 GUI 부품과 강화 이펙트도 출처를 구분해 담았다.
- `previews`에는 대기·충전·성공·하락, 지팡이 선택·떠나보내기·슬롯 새기기·변이 제거를 조합한 1920×1080 이미지가 있다. `ritual.gif`는 대기에서 충전·성공으로 이어지는 재생 예시다.

파일을 프로젝트에서 사용할 때 확대 필터는 Point로 설정한다. 미리보기는 에셋을 조합한 이미지다. 게임에서의 입력, 서버·오프라인 강화 처리, Unity 씬 연결은 이 묶음에 없다. 캐릭터의 위·아래 방향, 나머지 전투 자세, 강화 외 화면의 신규 디자인 현황은 `asset-coverage.md`에 적었다.
