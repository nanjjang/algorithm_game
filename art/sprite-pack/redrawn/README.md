# 엄청엄청 위대한 마법사 키우기 · 재작화 에셋

첨부된 그믐 스프라이트를 기준으로 ImageGen에서 새 도트 그림을 만들고, 게임에 넣을 수 있는 크기의 PNG와 스프라이트 시트로 내보냈습니다. [전체 미리보기](preview.png)와 [걷기·피격 재생](motion-preview.gif)에 실제로 저장된 프레임을 사용했습니다.

| 폴더 | 구성 | 매니페스트 |
|---|---|---|
| `characters/` | 제자 5명의 서기·선택 그림과 오른쪽 걷기 6프레임씩, 일반 적 12종과 보스 6종의 기본 자세, 느루·행상·까마귀·허수아비, 밤삼킴의 마디·꼬리 | `manifest.json`, `motion/manifest.json` |
| `wands/` | 5종 × +0~+13. 손 그림 32×64, 아이콘 64×64, 큰 그림 192×192. 각 지팡이마다 손 자세·큰 그림·아이콘 시트 | `complete/manifest.json`, `remaining/manifest.json` |
| `effects/` | 투사체 기본 그림 6종, 5속성 피격 4프레임, 고유 비기 5종의 겹그림과 적의 원형·직선·부채꼴 적중 효과 | `manifest.json`, `extra/manifest.json` |
| `gui/` | 주문 블록 16종과 비기 15종의 48px·24px 그림, 강화 재료 8종, 판·버튼·슬롯, 원정·결투·광장 카드 | `manifest.json` |

## Unity용 좌표

- PNG 좌표 원점은 왼쪽 위입니다. Point 필터, mipmap 끄기, 무손실 압축을 기준으로 내보냈습니다.
- 걷기 몸체는 64×64, 발 기준점은 (32, 59)입니다. 왼쪽은 오른쪽 걷기를 좌우 반전합니다. 그믐의 서기·선택 그림은 기준 디자인을 보여 주는 지팡이 포함 이미지입니다.
- 지팡이 손잡이는 (16, 48)입니다. 정면 들기 그림을 기준으로 방향·내밀기 자세를 픽셀 보간 없이 변환했습니다. 손잡이와 캐릭터 프레임의 손 좌표를 맞춰 겹칩니다.
- 적의 공격 예고 면은 기획서대로 런타임 셰이더가 그립니다. 충격 파편의 이미지는 `effects/extra/enemy/`에 있습니다.

## 남은 검수와 작화

제자의 위·아래 이동과 시전, 적·보스의 공격과 사망, NPC의 상호작용 모션 및 화면별 GUI 전체는 추가 작화 범위입니다. 지팡이의 일부 세부 모양은 원문의 설명을 픽셀 크기에 맞춰 해석했습니다. 예를 들어 성에 +9의 궤도는 규칙적인 점선보다 끊긴 고리로 보입니다. Unity에서의 프레임 재생, 9조각 늘리기, 손 위치 부착은 별도 확인이 필요합니다.
