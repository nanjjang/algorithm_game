각 동작 폴더에 개별 RGBA PNG와 가로로 배열한 `sheet.png`가 있습니다. 원점은 왼쪽 위이며, `size`는 프레임 캔버스, `pivot`은 픽셀 좌표입니다. Unity에서는 Point 필터와 mipmap 끄기를 사용합니다. `durationsMs`는 미리보기 및 애니메이션 작업용 값입니다. 공격 판정과 예고 시간은 게임 로직과 기획서가 정합니다.

이끼 슬라임과 해거름 박쥐는 접촉 공격을 사용합니다. 꽈리 벌레는 점화 뒤 공용 폭발을 재생합니다. 갓버섯 술사는 갓 위에 가짜 얼굴이 있고, 대기 그림으로 `move/01.png`를 쓸 수 있습니다. 도깨비불은 연노랑 불꽃을 지정한 기획서에 맞춰 `hover`를 새 대기 그림으로 사용합니다. 밤눈의 지상 프레임은 96×128입니다. 허상의 지팡이는 플레이어 지팡이에 회색조 셰이더를 적용해 부착합니다. 첫 만남 퇴장은 사망의 마지막 두 프레임을 재사용합니다.

예고 구역, 피격 번쩍, 림과 엘리트의 금빛 고리는 런타임에서 그립니다. 야영 모닥불은 [월드의 공용 시트](../../world/sprites/field.campfire.png)를 쓰고, 허상의 머리 위 커맨드는 기존 [K-53 방향 문양](shared/command-glyphs/) 네 장을 재사용합니다. 엘리트 장식은 애니메이션에 맞춰 본체 위 부착 위치를 조정해야 합니다.
