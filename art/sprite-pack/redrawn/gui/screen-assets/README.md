# 화면 전용 그림과 공용 GUI

[미리보기](preview.png)에는 타이틀 합성, 7개 화면 배경, 프로필 카드, 전리품 카드, 상점·리그·대화 패널과 일부 아이콘을 담았습니다. [매니페스트](manifest.json)에는 PNG 606개와 치수, 사용한 원본, 프레임 위치, 9조각 테두리를 기록했습니다.

[명세 대조표](coverage.json)는 `docs/ui-assets.md` §7의 그림 662장을 ID별로 연결합니다. 이 폴더에 580개를 추가했고 앞선 GUI 팩의 그림 82개를 이어 씁니다. 조립과 미리보기에 쓰는 PNG 26개에는 프레임을 가로로 붙인 시트 15개와 재사용 원본 11개가 포함됩니다. 한글 본문에는 [기존 글꼴 팩](../catalog/font/)을 사용합니다. 개별 꾸미기 아이콘은 꾸미기 목록이 확정되면 수량이 정해집니다.

ImageGen으로 화면 배경, 판과 칸, 대화 초상, 아이콘 및 숫자 글꼴 원본을 만들었습니다. 상태와 크기에 따라 색 입힘, 점 필터 배율 변환, 합성, 픽셀 격자에 맞춘 선과 점을 사용했습니다. `derivedFrom`에 파생 원본을 적었습니다. Unity에서는 Point, mipmap 끄기, 무손실 압축을 사용합니다. 매니페스트의 위치 좌표는 왼쪽 위 기준이며 9조각 순서는 왼쪽·위·오른쪽·아래입니다.

타이틀과 메뉴의 불은 별도 RGBA 시트에 있습니다. 타이틀 제목 PNG에는 `엄청엄청 위대한 마법사 키우기`가 들어 있습니다. 실행 아이콘의 네 크기는 크기별 그림에서 각각 잘랐습니다.
