# 사용자에게 물을 것 — 엄청엄청 위대한 마법사 키우기

명세와 `docs/DECISIONS.md`가 정하지 않아서 tech-lead가 임시값으로 진행하는 것들이다(PIPELINE 3.7절). 구현은 임시값으로 막히지 않고 간다. 사용자가 정하면 해당 문서와 작업을 고친다. `docs/DECISIONS.md`는 사용자만 고친다.

일정이나 범위에 대한 물음은 없다. 전부 "어느 쪽으로 할 것인가"다.
