# 엄청엄청 위대한 마법사 키우기 — 연출 설계서 (강화 의식 · 전투 효과 · 소리 · 에셋)

기준은 `docs/DECISIONS.md`다. 이 문서와 다르면 `DECISIONS.md`가 맞다. 그 밖에 `docs/world-characters.md`, `docs/monsters.md`, `docs/online.md`, `docs/wands/*.md`와 함께 읽는다. `docs/GDD.md`는 3판에서 `DECISIONS.md`와 이 문서에 맞춰졌다(연출·효과·입자 예산은 GDD 0절이 이 문서를 주인으로 가리킨다). 21.1절은 2판과 달랐던 곳의 기록이다.

이 문서는 규칙(확률, 피해, 판정)을 정하지 않는다. 이미 정해진 규칙이 **어떻게 보이고 들리는지**만 정한다. 다만 아래 세 가지는 이 문서가 유일한 기준이고 다른 문서는 이 문서를 가리키기만 한다.

| 이 문서가 기준인 것 | 절 |
|---|---|
| 입자 수 예산과 넘쳤을 때의 처리 (`DECISIONS.md` 2.8). 지팡이 문서가 인용할 절 번호는 **9.3절** 하나다 | 9.3절 |
| 내 효과가 적의 예고를 얼마나 덮을 수 있는가(누적 가림 상한) | 9.2절 |
| 예고 구역의 테두리·채움 그리는 법, 번쩍·흔들림의 안전 한도 | 14절, 0.3절 |
| 강화 화면의 구성과 표시 배율, 하락 흔적을 누구에게 보이는가, 서버 전체 알림의 모양 | 1.2절, 1.3절, 8절 |
| 옵션 목록, 공용 소리 목록, 효과 에셋 목록 | 18절, 19절, 20절 |

표기: **[개발자]** 는 개발자가 정한 것(`DECISIONS.md`). 표시가 없는 수치·이름·연출은 QA에서 조정할 시작값이다.

이름 **[개발자: DECISIONS 1.25]**: 이 문서의 문구 예시에 나오는 캐릭터, 지팡이, 스승, 장소의 이름(달구, 그믐, 끓는 부지깽이, 느루 …)은 전부 작업용 이름이다. 화면에 찍는 문자열(칭호 띠, 서버 전체 알림, 기술 이름 띠, 대사)은 글자를 그림이나 코드에 박아 넣지 않고 이름 표(`world-characters.md` 0절)에서 id로 읽어 끼워 넣는다. 지금 캐릭터의 표시 이름은 "제자 1"~"제자 5"이므로, 아래 예시의 "엄청엄청 위대한 그믐"은 실제 화면에 "엄청엄청 위대한 제자 5"로 나온다. 이름이 들어가는 띠는 글자 수가 달라져도 되게 가운데 맞춤과 폭 늘림으로 만든다.

기준 단위 (`DECISIONS.md` 2.1):

| 항목 | 값 |
|---|---|
| 1칸 | 64px |
| 기준 화면 | 1920×1080. 전장 24×14칸 = 1536×896px이 가운데 들어간다 |
| 캐릭터 캔버스 | 64×64px. 적과 타일도 같은 배율 |
| 그림의 1픽셀 | 화면의 1픽셀. 이 문서의 px는 전부 이 기준이다. 선 굵기는 2px 단위로 쓴다. 예외는 강화 화면의 가운데 무대와 초상 하나뿐이고, 거기서는 그림의 1픽셀을 화면의 2×2픽셀로 그린다(1.2절) |
| 1프레임 | 1/60초 |
| 시간 표기 | 초. 연출 시간은 **실제 시간**으로 잰다 |

지팡이 5종의 +0~+13 모양과 상시 효과는 지팡이별 문서의 일이다. 이 문서는 "강화하는 행위"의 연출과 전투 효과를 맡는다.

## 0. 모든 연출이 지키는 규칙

### 0.1 색의 뜻

| 색 | 뜻 | 쓰는 곳 | 금지 |
|---|---|---|---|
| 위험색: 빨강 `#FF3B30`, 자홍 `#FF2E88` | 적이 나를 해친다 | 전장 안에서는 **적의 공격, 예고, 적 탄에만**. HUD 층에서는 내가 맞았을 때의 화면 가장자리, 체력 1칸 귀퉁이, 최종 격노 표시 | 플레이어의 몸·지팡이·주문·열 링, 강화 화면, 배경, 치장 효과, 적의 눈과 몸(공격 부위가 물드는 순간 제외) |
| 금색 `#FFD24A` | 값진 것 | 골드, 대성공, +13, 별똥 결정, **엘리트**(적 몸의 금 테와 머리 표식, `monsters.md`) | 탄과 주문, 임계, 일반 성공, 일반 적중 |
| 임계 표식: 흰 안쪽 테 + 검정 바깥 테 + 쐐기 | 지금 임계다 | 임계 사격의 탄, 임계 구간의 열 링, 임계 피해 숫자 | 비기, 일반 탄 |
| 속성 주색·보조색 | 그 속성의 주문 | 주문, 비기, 강화 성공 | 다른 속성의 효과 |
| 연두 `#B8F04A` | 야생 마력 | 폭주 변이 전용 | 그 밖의 모든 곳 |
| 흰색 | 순간(판정, 적중, 스침) | 예고의 마지막 번쩍, 적중 번쩍, 스침 고리 | 오래 남는 넓은 효과 |
| 꺼짐(무채색, 어두워짐) | 잃음, 못 씀 | 강화 실패, 콤보 끊김, 불발, **과열 잠금** | — |

위험색의 정의는 `DECISIONS.md` 2.2 그대로다: 색상각 330~15도이면서 채도 70% 이상, 명도 70% 이상. 쓸 때는 항상 채도 80% 이상(빨강 81%, 자홍 82%)에 흰 중심이나 흰 선을 함께 쓴다. 플레이어 쪽에는 이 범위의 색을 쓰지 않는다. 그믐의 후드 같은 탁하고 어두운 자주색은 범위 밖이라 허용한다.

속성 주문색 (`DECISIONS.md` 2.2, 값은 `world-characters.md`의 속성표):

| 속성 | 주색 | 보조색 | 탄의 모양 |
|---|---|---|---|
| 화염 | 주황 `#FF8A1F` | 밝은 노랑 `#FFE08A` | 둥글고 꼬리가 일렁인다 |
| 번개 | 레몬 `#FFF36B` | 흰색 `#FFFFFF` | 꺾인 선 |
| 비전 | 청록 `#4FE3C1` | 흰 민트 `#D6FFF3` | 네모·마름모 |
| 냉기 | 하늘 `#9FDCFF` | 흰 하늘 `#F4FBFF` | 뾰족한 육각 조각 |
| 암흑 | 푸른 보라 `#8A5CFF` | 연보라 `#D9C7FF` | 고리(밝은 테 + 어두운 고리 + 밝은 심, 16.2절) |

**임계, 엘리트, 화염·번개를 서로 다른 것으로 가른다.** 예전에는 임계도 엘리트도 금색(색상각 45도)이었고, 이 금색은 화염의 주황·노랑(29도, 44도)과 번개의 레몬(55도) 사이에 끼어 탄 위에서 보이지 않았다.

| 대상 | 무엇으로 알아보나 | 색 |
|---|---|---|
| 화염 주문 | 둥근 탄, 일렁이는 꼬리 | 주황 + 밝은 노랑 |
| 번개 주문 | 꺾인 선 | 레몬 + 흰색 |
| 임계 | **모양**: 탄 앞의 쐐기(`>` 모양 6px)와 이중 테(안쪽 흰 2px, 바깥 검정 `#000000` 2px). 속성색은 그대로 둔다 | 흰색과 검정뿐이다. 다섯 속성에서 똑같이 보인다 |
| 엘리트 | 적 몸의 금 테 2px + 머리 위 표식. 탄에는 금색이 없으므로 탄과 섞이지 않는다 | 금색 `#FFD24A` |

- 흰 테와 검정 테는 어느 속성색 위에서도 둘 중 하나가 4.5:1을 넘는다(검정 대 레몬 18.3:1, 검정 대 주황 8.9:1, 흰색 대 암흑 보라 4.2:1 + 검정 대 암흑 보라 5.1:1).
- 임계로 처치한 적의 조각도 금색이 아니라 **흰 조각 + 검정 테**다.
- 강화 실패는 빨강으로 그리지 않는다. **빛이 꺼지는 것**으로 그린다.
- 과열 잠금도 빨강으로 그리지 않는다. 열 링이 식은 재색 `#5A5F6B`으로 꺼진다(10절). 발밑의 빨간 원은 적의 원형 예고와 같은 자리에 같은 모양으로 겹치기 때문이다.
- **흰색으로 꽉 찬 닫힌 도형은 적 예고의 번쩍 전용이다.** 플레이어가 내는 넓은 효과(지름 2칸 이상)는 면을 흰색이나 위험색으로 채우지 않는다. 선으로 된 고리나 끊어진 호에 속성 보조색을 쓰고, 안을 채울 때는 속성색 30% 이하로만 채운다.
- 청록은 플레이어의 비전 전용이다. 적의 몸, 적의 눈, 떨어지는 재료에 청록을 쓰지 않는다(`monsters.md`가 따른다). 적의 눈은 흰색·연노랑만 쓴다.

### 0.2 화면을 건드리는 효과의 단위

| 이름 | 흔들림 폭 (기준 화면) | 길이 | 쓰는 곳의 예 |
|---|---|---|---|
| 흔들림 소 | 4px | 0.15초 | 임계 적중, 난이도 3 비기 |
| 흔들림 중 | 8px | 0.25초 | 피격, 뇌광창, 강화 성공(높은 단계) |
| 흔들림 대 | 12px | 0.40초 | 대성공, 보스 단계 전환, 만개 마지막 파동 |
| 흔들림 특대 | 16px | 0.60초 | +13 도달 한 곳뿐 |

- 흔들림은 누적값(0~1) 하나로 관리한다. 사건마다 누적값을 더하고, 실제 폭은 `누적값² × 16px`, 누적값은 초당 2.5씩 줄어든다. 여러 사건이 겹쳐도 16px을 넘지 않는다.
- 흔들리는 것은 전장 카메라다. HUD, 예고 구역의 판정, 입력은 흔들리지 않는다.
- **그림 정지(히트스톱)**: 게임 시간을 멈추지 않는다. 맞은 대상과 맞힌 탄의 **그림만** 멈춘다. 게임 시간은 서버의 결투 판정과 무한 웨이브 재실행 검증에 쓰이므로(`online.md`) 연출이 건드리지 않는다. 강화 화면은 전투가 아니므로 화면 전체를 멈춰도 된다.

### 0.3 광과민 안전 한도

아래 한도는 옵션과 무관하게 **항상** 적용한다. 널리 쓰이는 기준(1초에 3회 이하의 번쩍임)보다 엄격하게 잡았다.

| 항목 | 한도 |
|---|---|
| 전체 화면 번쩍 횟수 | 어느 1초 구간에서도 2회 이하. 번쩍 사이 간격 0.4초 이상 |
| 전체 화면 번쩍 세기 | 덮는 색의 불투명도 35% 이하. 순백 100%는 쓰지 않는다 |
| 번쩍의 모양 | 0.05초 안에 켜지고 0.10초 이상에 걸쳐 꺼진다. 1프레임짜리 켜짐/꺼짐 반복 금지 |
| 빨강 전체 화면 번쩍 | 금지. 피격 표시는 화면 가장자리(면적 25% 미만)에만 |
| 화면 25% 이상을 덮는 국소 번쩍 | 전체 화면 번쩍으로 센다 |
| 깜빡이는 넓은 무늬(줄무늬, 바둑판) | 금지 |
| 밝기 급락(강화 실패의 어두워짐) | 1회 전환으로만. 어두워졌다 밝아졌다를 반복하지 않는다 |
| 흔들림 | 폭 16px, 길이 0.6초 이하. 화면 회전·확대 떨림 금지 |
| 카메라 확대 | 1.00~1.12배, 초당 0.1배 이하의 속도 |

**번쩍 관리기**: 전체 화면 번쩍과 큰 국소 번쩍은 한 곳(번쩍 관리기)을 거쳐서만 낸다. 한도를 넘는 요청은 버리지 않고 **테두리 강조(흰 선 8px, 0.15초)** 로 바꿔 낸다. 정보는 남기고 빛만 뺀다.

### 0.4 연출 줄이기 옵션

설정 > 화면에 3단계를 둔다. 첫 실행 때 타이틀 전에 한 번 묻는다("번쩍임과 흔들림을 줄일까요?").

| 항목 | 전체 | 줄임 | 최소 |
|---|---|---|---|
| 화면 흔들림 | 100% | 30% | 없음 |
| 전체 화면 번쩍 | 35%까지 | 15%까지 | 없음(테두리 강조로 대체) |
| 그림 정지 | 켬 | 절반 길이 | 끔 |
| 카메라 확대(강화 의식) | 켬 | 절반 | 끔 |
| 예고의 흰 번쩍 | 구역 전체 | 테두리만 굵게 | 테두리만 굵게 |
| 무적 중 캐릭터 깜빡임 | 8Hz 반투명 | 깜빡임 없이 60% 투명 + 흰 테두리 | 같음 |
| 열 아지랑이, 균열 등 화면 덮개 | 켬 | 정지 그림 | 끔 |
| 입자 예산(9.3절) | 1,500 | 800 | 300 |
| 강화 의식 | 전체 | 어두워짐 40% → 20%, 균열은 화면이 아니라 마법진 안에만 | 결과 카드만 |

세 단계와 별개로 낱개 조절도 둔다: 흔들림 0~100, 번쩍 0~100, 그림 정지 켬/끔. 전투 가독성 옵션은 18절.

**소리로만 전달되는 정보는 없다.** 모든 소리 신호에는 같은 뜻의 그림이 있다(예: 심장 소리 ↔ 게이지 고리의 맥동).

### 0.5 서버나 결제를 연결하지 않아도 동작하는 구조

연출은 "어디서 온 결과인지"를 모른다. 받는 것은 결과 꾸러미 하나다.

| 꾸러미 항목 | 내용 |
|---|---|
| 결과 종류 | 성공 / 대성공 / 실패(하락) / 실패(부적이 막음) / 실패(하락 없음) / 변이 제시 |
| 단계 | 시도 전 단계, 시도 후 단계, 역대 최고 갱신 여부 |
| 덧붙는 일 | 슬롯 확장 여부, 부적 소모 여부, 기운 전·후, 변이 후보, 밀려나는 변이 |
| 내역 | 확률 내역(기본·제물·속성·기운), 뽑힌 값 |

| 연결점 | 오프라인 프로필 (서버 없음) | 서버 프로필 |
|---|---|---|
| 강화 결과 | 기기 안의 구현이 꾸러미를 만든다. 강화 화면과 의식이 **전부** 그대로 돌아간다 (`DECISIONS.md` 2.6) | 서버가 같은 꾸러미를 준다. 연출 코드는 같다 |
| 서버 전체 알림(8절) | 내보내지도 받지도 않는다. 내 화면의 의식은 똑같이 재생된다 | +10 이상 성공과 +13 달성을 내보내고 받는다 |
| 치장 효과(강화 의식 겉모습, 발사 궤적, 처치 효과, 발자국) | 칸마다 기본 효과가 들어 있다. 얻지 못한 효과는 목록에 나오지 않고, 빈 칸이나 잠금 표시가 화면에 없다 | 같다. 거래로 받은 효과가 목록에 더해진다 |
| 결제 | 연출 코드 어디에도 유료 여부를 보는 분기가 없다 | 나중에 결제를 붙여도 이 문서는 바뀌지 않는다 |

나중에 추가되는 치장 효과가 지켜야 하는 것(돈이나 희귀함으로 시야를 가리는 일을 막는다):

- 0.1절의 색 규칙(위험색·연두 금지, 금색은 정해진 곳만), 0.3절의 한도, 9.2절의 가림 상한, 9.3절의 입자 예산을 그대로 따른다.
- 효과의 크기와 지속 시간은 기본 효과의 120%를 넘지 않는다. 판정과 무관하다.
- 결투에서 상대 화면에는 내 탄 장식이 가장 단순한 형태로만 보인다(17절, `DECISIONS.md` 2.7).

# A부. 강화 의식

강화는 이 게임에서 가장 떨리는 순간이어야 한다. 원칙은 넷이다.

1. **결과는 버튼을 누른 순간 이미 정해져 있다**(`online.md`). 연출은 결과를 바꾸지 않고, 결과에 따라 충전 길이가 달라지지도 않는다. 충전 구간에서는 결과를 짐작할 수 없다.
2. **속이지 않는다.** 확률 숫자는 실제 값이다. "아깝게 실패한 것처럼" 꾸미는 연출은 넣지 않는다. 결과 카드에서 뽑힌 값을 볼 수 있다.
3. **단계가 높을수록 길고 조용하고 크다.** +2 도전은 가볍게, +13 도전은 숨이 막히게.
4. **실패한 직후에 다음 희망을 보여 준다.** 장인의 기운이 오르고 확률 숫자가 그 자리에서 올라간다.

## 1. 강화 화면

### 1.1 어떤 화면인가 [개발자]

- 강화는 **전용 전체 화면**에서 한다. 캐릭터를 움직이는 공간이 아니라 메뉴에서 들어가는 별도 화면이다(피파의 강화 화면처럼). 판 중과 야영에서는 강화하지 않는다.
- 들어가는 곳은 둘이다: 메인 메뉴의 "강화", 광장 메뉴의 "강화". 어디서 들어가든 같은 화면이고, 나가면 들어온 곳으로 돌아간다. 광장에 강화용 장소나 NPC는 없다.
- 광장 메뉴에서 들어가도 이 화면이 화면 전체를 덮는다. 뒤에 광장이 비치지 않고, 광장의 다른 사람에게는 내가 메뉴를 보고 있다는 표시(머리 위 말줄임표)만 보인다. **구경꾼 연출은 없다.** 남에게 전해지는 것은 서버 전체 알림(8절)뿐이다.
- 화면에 들어올 때 강화할 지팡이를 고른다(가진 지팡이 목록, 캐릭터별). 화면 안에서 Q와 E로 지팡이를 바꿀 수 있다.
- 서버 없이도 오프라인 프로필로 똑같이 돌아간다(0.5절).

| 비용 | 강화 버튼 위 | 골드와 강화석. 모자라면 버튼이 꺼지고 모자란 쪽이 흔들린다 |

- 큰 그림(192×192)은 지팡이 문서가 그 크기로 따로 그린 그림이다(손 그림 32×64를 키운 것이 아니다). **강화 화면에서는 이것을 2배(384×384)로 보여 준다.** 마법진과 그 위의 효과가 전부 2배이므로 지팡이만 1배로 두면 픽셀 크기가 섞인다. 살펴보기, 거래 확인 창, 결투 시작 화면처럼 강화 화면이 아닌 곳에서는 같은 그림을 1배(192×192)로 쓴다. 지팡이 문서는 강화 화면의 배율을 따로 적지 않고 이 절을 가리킨다.
- 메뉴이므로 마우스를 쓸 수 있고 키보드만으로도 된다: 방향키로 칸 이동, J 넣기·강화, K 빼기, Esc 나가기.
- 하락할 수 있는데 부적이 없으면 강화 버튼 테두리에 "하락 가능" 꼬리표가 붙는다. 확인 창은 띄우지 않는다(연속 시도의 흐름을 끊지 않는다).
- 확률, 비용, 실패 규칙은 다섯 지팡이가 똑같다(`DECISIONS.md` 2.4). 지팡이마다 다른 것은 5절의 재질·무늬·악기뿐이다.
- 이 화면에 광과민 한도(0.3절, 6절)가 그대로 적용된다. 이 화면만의 입자 상한은 9.3절.

### 1.3 하락 흔적과 공개 설정 [개발자]

실패로 단계가 떨어진 지팡이에는 흔적이 남는다. 흔적의 모양과 그 지팡이에서 부르는 이름은 지팡이 문서가 정한다(달구의 식은 얼룩, 초롱의 금, 성에의 언 물줄기, 그믐의 아문 자국 등). 이 문서는 **누구에게 보이는가**를 정하고, 이 절이 그 기준이다(GDD 9절이 이 절을 가리킨다).

| 항목 | 내용 |
|---|---|
| 흔적이 있는 조건 | 현재 단계가 역대 최고 단계보다 낮다. 낮은 만큼 1~2개(하락 바닥이 역대 최고 −2이므로 최대 2) |
| 공개 설정 | 강화 화면 왼쪽 칸의 "흔적 공개 [켬 / 끔]". **지팡이마다 따로** 저장한다(계정 설정 하나가 아니다). 주인이 언제든 바꾼다. 설정의 이름은 다섯 지팡이 모두 "흔적 공개" 하나다("하락 흔적 공개", "녹은 흔적 공개" 같은 지팡이별 이름을 쓰지 않는다). 설정 화면에는 이 항목이 없고 강화 화면에만 있다 |
| 내 화면 | 설정과 무관하게 항상 보인다. 끔일 때는 흔적 옆에 작은 가림 표시(눈을 가린 아이콘 16×16)가 붙어 "남에게는 안 보인다"를 알려 준다 |
| 남의 화면(광장, 결투, 살펴보기, 순위표 프로필) | 켬: 흔적 겹그림과 "역대 최고 +N" 표기가 보인다. 끔: 흔적 겹그림도, 역대 최고 단계도, 실패 횟수 같은 이력 꼬리표도 보이지 않는다. 현재 단계의 모양만 보인다 |
| 거래(직접 거래 창, 장터 목록과 미리보기) | **설정과 무관하게 항상 보인다.** 흔적 겹그림 + "역대 최고 +N, 지금 +M" 글자. 거래 창에 올리는 순간 주인 화면에 "거래 상대에게는 흔적이 보인다" 한 줄 |
| 흔적이 사라지는 때 | 역대 최고 단계까지 다시 올리면 흔적 조각이 하나씩 떨어져 나간다(성공 연출 0.40 시점, 조각 2개가 떨어지며 흐려진다) |
| 하락한 직후 | 3.3절 결과 카드에 "흔적이 남았다 · 지금은 [비공개]" 한 줄과 바로 바꾸는 단추 |

- 흔적은 겉모습일 뿐 판정과 무관하다. 결투에서 상대 화면에 흔적을 보일지는 이 설정을 그대로 따른다.
- 기본값은 끔(비공개)이다. 개발자 확인 필요 2번.

## 2. 한 번의 시도: 시간표

기준은 +7~+9 도전(강도 3단)이다. 단계별 길이는 4절.

| 시각(초) | 구간 | 화면 | 소리 |
|---|---|---|---|
| 0.00 | 누름 | 버튼이 눌리고 화면의 다른 조작이 잠긴다. 결과 요청이 나간다 | 묵직한 누름 |
| 0.00~0.15 | 값 치르기 | 골드 숫자가 굴러 내려가고 강화석 하나가 마법진 가운데로 떨어진다 | 동전 쓸림, 돌 놓임 |
| 0.15~0.75 | 제물 바치기 | 제물이 ①부터 0.12초 간격으로 실을 타고 마법진에 빨려 든다. 하나 들어갈 때마다 마법진 고리가 한 겹 켜진다. 부적이 있으면 마지막에 부적이 한 번 빛난다 | 제물마다 한 음씩 올라가는 다섯 음(5음 음계) |
| 0.75~2.55 | **충전** (1.8초) | 마법진 둘레의 게이지 고리가 찬다. 처음 40% 시간에 80%까지 빨리 차고, 남은 60% 시간에 마지막 20%를 천천히 채운다. 지팡이가 16px 떠오르며 떨린다(0 → 4px). 마법진 회전이 6초 → 1초에 한 바퀴로 빨라진다. 카메라 1.00 → 1.08배. 배경이 60% → 75% 어두워진다 | **심장 소리**: 분당 70회에서 140회로, 음높이 +5반음까지. 밑에 깔리는 지속음이 함께 올라간다. 배경음은 −12dB |
| 2.55~2.90 | **숨 멈춤** (0.35초) | 게이지가 가득 찬 채 모든 것이 멈춘다. 지팡이의 떨림도 멈춘다. 입자가 공중에 선다 | 모든 소리가 끊긴다 |
| 2.90 | **판정** | 결과 연출 시작(3절) | |
| 결과 뒤 | 정리 | 결과 카드가 오른쪽에서 나온다. 조작 잠금이 풀리고, J를 누르면 같은 구성으로 다시 시도한다 | |

- 제물이 없으면 제물 바치기는 0.2초로 줄인다.
- **+1 도전**(확률 100%)은 충전 0.4초, 심장 소리와 숨 멈춤 없이 바로 성공한다.
- **결과가 늦게 올 때**: 충전이 끝날 때까지 결과 꾸러미가 오지 않으면 게이지가 97%에서 떨며 기다리고 심장 소리가 최고 속도로 이어진다. 5초를 넘기면 "까마귀가 늦는다"를 띄우고 조작을 풀어 준다. 결과는 도착하는 대로 짧은 형태(7절)로 보여 준다. 접속이 끊긴 채 나갔다 오면 다시 들어왔을 때 보여 준다. 오프라인 프로필에서는 결과가 기기 안에서 바로 나오므로 이런 기다림이 없다.
- 충전 구간의 길이, 소리, 움직임은 **결과와 무관하게 같다.**

## 3. 결과별 연출

판정 시각을 0으로 적는다. 길이는 강도 3단 기준이고 괄호는 화면 효과다.

### 3.1 성공 (약 2.0초)

| 시각 | 내용 |
|---|---|
| 0.00 | 화면 정지 0.08초. 마법진에서 속성색 빛기둥이 위로 솟는다. (번쩍: 속성 보조색 25%, 흔들림 소) |
| 0.10~0.40 | 지팡이가 흰 실루엣이 되었다가 다음 단계 모양으로 바뀐다(6프레임) |
| 0.40 | 단계 숫자가 "+7 → +8"로 넘어가며 1.3배에서 1.0배로 내려찍힌다. 속성 모양 입자 24개가 고리로 퍼진다 |
| 0.90~1.60 | 새 단계의 상시 효과를 한 번 크게 보여 준다. 강화 배율이 "×2.66 → ×3.06"으로 굴러 오른다 |
| 1.60 | 결과 카드. 캐릭터 한마디(`world-characters.md`: "거봐! 내가 뭐랬어!") |

소리: 속성 악기의 성공 화음(5절) + 종 한 번. 기운 불씨가 있었다면 불씨들이 지팡이로 빨려 들며 꺼진다(성공하면 기운 0).

### 3.2 대성공 (약 3.6초) — 가짜 실패로 시작한다

대성공은 성공 중 15%다(GDD 9절). **대성공은 항상 실패처럼 시작한다.** 실패(3.3~3.5절)의 첫 0.5초와 완전히 같은 그림·같은 소리를 쓴다. 그래서 진짜 실패의 첫 0.5초에도 "혹시?"가 남는다.

| 시각 | 내용 |
|---|---|
| 0.00 | 빛이 꺼진다(화면 밝기 40%까지, 0.1초에 걸쳐). 화면 한가운데에 금 한 줄. 심장 소리 한 번 "쿵" |
| 0.00~0.50 | 금이 조금 더 벌어진다. 조용하다. **여기까지는 실패와 같다** |
| 0.50~0.95 | 갈림: 금 사이로 금빛이 샌다. 금이 0.15초 간격으로 세 번 번진다. 번질 때마다 유리 긁히는 높은 소리가 올라간다 |
| 0.95 | 화면 정지 0.12초 |
| 1.07 | 화면이 유리처럼 깨져 조각 18개가 바깥으로 날아가고, 그 뒤에서 금빛이 터진다. (번쩍: 금색 35%, 흔들림 대) |
| 1.20~2.20 | 단계 숫자가 두 번 내려찍힌다: "+7 → +8", 0.25초 뒤 "→ +9". 두 번째 종은 3도 높다 |
| 2.20~3.20 | **슬롯 확장**: 왼쪽 지팡이 회로에서 새 슬롯 자리가 금 테두리와 함께 벌어져 열린다. "연결 슬롯 +1 (2/3)" |
| 3.20 | 결과 카드. 금색 테두리 |

- 깨지는 조각의 재질은 속성마다 다르다(5절).
- 이미 확장 3칸을 채운 지팡이는 슬롯 확장 구간을 건너뛰고 카드에 "슬롯은 이미 다 자랐다"를 적는다.
- +12에서 대성공이면 숫자는 한 번만 내려찍히고 3.8절(+13 도달)로 이어진다.
- "연출 줄이기 = 줄임"에서는 화면 균열 대신 마법진 안의 지팡이 빛에만 금이 간다.

### 3.3 실패, 단계 하락 (약 2.2초)

| 시각 | 내용 |
|---|---|
| 0.00~0.50 | 대성공의 0.00~0.50과 같다 |
| 0.50 | 금이 회색인 채 흐려져 사라진다. 지팡이의 빛이 꺼진다. 게이지 고리가 한 번에 빈다. 낮은 "툭" |
| 0.70 | 지팡이가 마법진 위로 16px 떨어져 두 번 튄다. 먼지. 지팡이가 회색 실루엣을 거쳐 한 단계 아래 모양으로 돌아간다 |
| 1.00 | 단계 숫자가 "+7 → +6"으로 아래로 떨어진다. 색은 회색 |
| 1.20~1.80 | **기운**: 마법진의 재에서 불씨 하나가 올라와 기운 칸에 앉는다. 따뜻한 한 음. 큰 확률 숫자가 그 자리에서 "+15" 굴러 오른다 |
| 1.80 | 결과 카드. 느루: "원래 그런 거다." 캐릭터 한마디 |

화면 번쩍 없음, 흔들림 없음. 실패는 조용하다. 배경음은 1.2초부터 원래 크기로 돌아온다.

단계가 내려간 지팡이에는 하락 흔적이 남고, 결과 카드에 공개 설정 한 줄이 붙는다(1.3절). 실패는 누구에게도 알려지지 않는다(8절).

### 3.4 실패, 부적이 막음 (약 2.4초)

| 시각 | 내용 |
|---|---|
| 0.00~0.50 | 실패와 같다 |
| 0.50 | 지팡이의 빛이 꺼지고 떨어지기 시작한다 |
| 0.60 | 지팡이 밑동의 부적이 빛나며 종이 띠 여러 가닥으로 풀려 지팡이를 받아 올린다(6프레임). 종이 펄럭이는 소리 |
| 1.00 | 부적이 끝에서부터 타서 재가 된다(6프레임). 지팡이에 빛이 약하게 돌아온다 |
| 1.30 | 단계 숫자가 좌우로 떨리다 멈춘다. 숫자 옆에 도장 "지켰다" |
| 1.60 | 기운 칸은 한 번 흔들리고 그대로다(막은 실패에는 기운이 쌓이지 않는다. GDD 9절). 부적 칸이 빈다 |
| 1.90 | 결과 카드: "부적 1개가 대신 탔다." |

### 3.5 실패, 하락 없는 구간 (약 1.6초)

+3 이하이거나 하락 바닥(역대 최고 −2)에 닿아 있는 경우다.

| 시각 | 내용 |
|---|---|
| 0.00~0.50 | 실패와 같다(강도 1단에서는 어두워짐이 40%가 아니라 70%까지만) |
| 0.50 | 지팡이의 빛이 꺼지고 기우뚱한다. 마법진 안쪽 고리에서 뿌리 무늬가 올라와 지팡이를 붙든다. 지팡이는 떨어지지 않는다 |
| 0.80 | 김빠지는 "픽" 소리와 작은 연기. 단계 숫자는 그대로 |
| 1.00 | 기운 불씨 +1 (3.3절과 같다) |
| 1.30 | 결과 카드: "내려가지는 않았다." 바닥에 닿은 경우 "더는 안 내려간다 (역대 최고 +9)" |

### 3.6 변이 제시 (고를 때까지 멈춘다)

실패 중 25%. 단계는 유지된다.

| 시각 | 내용 |
|---|---|
| 0.00~0.50 | 실패와 같다 |
| 0.50 | 금 사이로 **연두빛**이 샌다. 금에서 가시덩굴이 자라 지팡이를 감는다(8프레임). 뒤틀리는 나무 소리 |
| 1.10 | 심장 소리가 분당 60회로 느리게 돌아온다. 변이 카드가 뜬다: 변이 이름, 이득, 대가, [받는다] [거절한다]. 변이 칸이 가득이면 "가장 오래된 ○○가 밀려난다"를 함께 적는다 |
| 선택 전 | 시간 제한 없음. 덩굴이 느리게 숨 쉬듯 움직인다 |
| 받는다 | 덩굴이 지팡이 속으로 스며든다(6프레임). 지팡이 그림에 변이 표식 고리가 생긴다. 단계 유지, 기운 +1. 야생 마력 소리 한 번 |
| 거절한다 | 덩굴이 시든다(6프레임). 이어서 돌려받은 결과(하락 / 부적이 막음 / 하락 없음)의 0.50 이후를 재생한다 |

- 변이 카드는 건너뛸 수 없다(선택이 필요하다).
- 0.1절대로 연두는 이 연출에만 쓴다. 금빛(대성공), 회색(실패)과 0.50 시점에 한눈에 갈린다.

### 3.7 마일스톤 단계 도달

칭호가 바뀌는 단계(+4, +7, +10)에 **닿았을 때** 성공·대성공 연출 뒤에 덧붙인다(칭호는 `world-characters.md`).

| 조건 | 덧붙는 연출 | 길이 |
|---|---|---|
| 역대 최고를 새로 쓰며 도달 | 카메라가 지팡이로 1.12배 다가간다. 새 단계 모양을 한 바퀴 돌려 보여 준다. 칭호 띠가 화면 가운데를 지나간다: "달 없는 밤의 → **꽤 위대한 그림자**". 속성 모양 꽃가루. 팡파르 | 2.5초 |
| 전에 닿은 적이 있는 단계에 다시 도달 | 칭호 띠만 작게 | 0.8초 |

+10에 닿으면(그리고 +11, +12 성공에도) 결과 카드에 "서버 전체에 알렸다" 한 줄이 붙는다(8절).

### 3.8 +13 도달 (약 9초)

성공(+12 → +13) 또는 대성공(+11·+12 → +13) 뒤에 이어진다. 전부 강화 화면 안에서 일어난다.

| 시각 | 내용 |
|---|---|
| 0.00 | 성공 연출의 숫자 내려찍기 직전에 끼어든다. 모든 소리가 끊기고 화면이 한 번 더 조용해진다(0.8초) |
| 0.80 | 단계 숫자 "+13"이 금색으로 내려찍힌다. (번쩍: 흰 금색 35%, 흔들림 특대) 큰 종 |
| 1.00~3.00 | 마법진에서 빛기둥이 화면 위 끝까지 솟는다. 지팡이가 마지막 모양으로 바뀐다(실루엣 전환 12프레임). 지팡이 뒤에 금빛 후광 고리 |
| 3.00~5.00 | 칭호 띠: "**엄청엄청 위대한 그믐**"(이름 자리는 이름 표의 캐릭터 표시 이름. 지금은 "제자 5"). 속성 합창·악기의 주제 선율 4마디 |
| 5.00~7.00 | 배경의 작업대가 그 속성색 빛으로 환해지고 화면 위쪽에 속성색 빛띠가 걸린다. 구석에서 졸던 느루가 눈을 뜬다. 느루: "…그건 나도 못 해 봤다." |
| 7.00~9.00 | 결과 카드(금 테두리). 서버 전체 알림이 나간다(8절) |

- 역대 최고 갱신일 때만 전체를 재생한다. +13에서 내려갔다가 다시 올라온 경우는 0.80~3.00만 재생한다.
- 처음 2초는 건너뛸 수 없다. 그 뒤는 J로 넘길 수 있다.
- 두 번째 번쩍은 없다. 0.3절의 한도 안에서 한 번만 쓴다.

## 4. 도전 단계에 따른 강도

도전하는 단계로 다섯 단을 나눈다. 구간은 칭호 구간과 같다.

| 강도 | 도전 단계 | 충전 | 숨 멈춤 | 심장 소리(분당) | 음높이 오름 | 카메라 | 배경 어두움 | 마법진 겹 | 충전 입자(초당) | 배경음 |
|---|---|---|---|---|---|---|---|---|---|---|
| 1단 | +2, +3 (+1은 2절의 예외) | 0.8초 | 0.15초 | 70 → 100 | +2반음 | 확대 없음 | 60% 그대로 | 1겹 | 10 | −6dB |
| 2단 | +4 ~ +6 | 1.2초 | 0.25초 | 70 → 120 | +4반음 | 1.04배 | 70% | 2겹 | 20 | −9dB |
| 3단 | +7 ~ +9 | 1.8초 | 0.35초 | 70 → 140 | +5반음 | 1.08배 | 75% | 3겹 | 35 | −12dB |
| 4단 | +10 ~ +12 | 2.4초 | 0.50초 | 70 → 160 | +7반음 | 1.10배 | 85% | 4겹 | 50 | 끔 |
| 5단 | +13 | 3.2초 | 0.80초 | 70 → 180 | +9반음 | 1.12배 | 90% | 5겹 + 바깥 고리 | 70 | 끔 |

단마다 더해지는 것:

| 강도 | 더해지는 연출 |
|---|---|
| 2단 | 지팡이가 떠오른다. 제물 실이 충전 내내 빛난다 |
| 3단 | 마법진 바깥 바닥에 속성 무늬가 번진다. 배경의 촛불이 심장 소리에 맞춰 흔들린다 |
| 4단 | 배경의 빛이 마법진 쪽으로 기운다. 충전 중 구석의 느루가 한쪽 눈을 뜬다. 성공하면 결과 카드에 "서버 전체에 알렸다" |
| 5단 | 충전 마지막 1초에 심장 소리 말고는 아무 소리도 없다. 배경의 촛불이 낮아진다. 지팡이 그림자가 화면 끝까지 늘어난다 |

- 성공 연출의 크기도 강도를 따른다: 빛기둥 폭(확대 전 64 → 192px), 고리 입자(16 → 48개), 종의 겹(1 → 3음).
- 실패 연출은 강도가 올라도 **커지지 않고 길어진다**: 0.50 뒤의 침묵이 0.2초(1단)에서 0.6초(5단)로 늘어난다.

## 5. 속성별 변주

구조와 시간은 다섯이 같다. 재질, 무늬, 악기가 다르다. 금빛(대성공)과 연두(변이)는 다섯이 같은 색을 쓴다.

| | 달구 (화염) | 초롱 (번개) | 갈피 (비전) | 성에 (냉기) | 그믐 (암흑) |
|---|---|---|---|---|---|
| 마법진 무늬 | 화덕 벽돌 고리와 풀무 | 등대 렌즈의 동심원 | 펼친 책장과 글자 고리 | 눈 결정 육각 | 달이 차고 기우는 모양의 고리 |
| 충전 | 지팡이 끝이 검정 → 주황 → 흰 노랑으로 달아오른다 | 등불이 점점 밝아진다(깜빡임은 초당 2회 이하, 밝기만 올린다) | 글자가 고리를 따라 한 줄씩 써진다 | 서리가 가장자리에서 가운데로 자란다 | 그믐달이 보름으로 차오르고 그림자가 가운데로 모인다 |
| 심장 소리에 겹치는 소리 | 풀무질 | 전기 웅웅거림 | 펜 긁는 소리 | 얼음이 팽팽해지는 소리 | 낮은 합창 |
| 성공 | 담금질 "치익"과 불티 분수 | 등이 환히 켜지고 줄기 번개가 위로 | 밑줄이 쫙 그어지고 도장 "쾅" | 눈꽃이 한 번에 핀다 | 보름달이 뜨고 구슬이 눈을 뜬다 |
| 성공 악기 | 모루 종 | 유리 종 | 실로폰 | 유리 하프 | 낮은 종과 합창 |
| 실패(빛이 꺼짐) | 쇠가 식어 검어지고 김 | 등이 "틱" 꺼진다 | 먹물이 번져 글자가 흘러내린다 | 서리가 녹아 물이 떨어진다 | 달이 그믐으로 돌아가고 구슬 눈이 감긴다 |
| 대성공 때 깨지는 것 | 식은 쇳물 껍질 | 등피 유리 | 종이(찢어지며 금박 글자) | 얼음 | 어둠(금빛 고리의 일식) |
| 부적이 막을 때 | 종이 띠가 그을리며 버틴다 | 종이 띠에 정전기 | 종이 띠에 글자가 돈다 | 종이 띠에 서리 | 종이 띠가 그림자에서 나온다 |
| 하락 없음의 뿌리 | 달궈진 쇠집게 | 놋쇠 받침 | 책갈피 끈 | 고드름 받침 | 뿌리 손가락 |
| 입자 모양 | 일렁이는 불티 | 꺾인 선 | 글자 조각, 마름모 | 육각 조각 | 가운데가 어두운 고리 |
| 캐릭터 반응 | 주전자 뚜껑이 들썩인다 | 반쯤 감긴 눈이 떠진다 | 책 지붕을 양손으로 잡는다 | 감은 눈이 한쪽만 떠진다 | 눈빛 모양이 바뀐다(성공: 반달, 실패: 점) |

- 캐릭터는 왼쪽 칸 아래의 초상(64×64 그림을 2배로)으로 나온다. 초상일 뿐 조작하지 않는다. 그림은 `world-characters.md` 10.1절의 캐릭터 그림을 쓰고 이 문서가 따로 그리지 않는다.
  - 성공과 실패: 그 절의 "강화 반응"(성공 4프레임, 실패 4프레임). 위 표의 "캐릭터 반응" 줄이 그 그림의 내용이다.
  - 기다림: 그 절의 "서기"(아래 방향, 숨쉬기 4프레임)를 그대로 돌린다.
  - 충전: 같은 서기 그림을 쓰되 숨쉬기를 심장 소리 박자에 맞춰 돌린다(박자가 빨라지면 숨도 빨라진다). 숨 멈춤 구간에는 첫 프레임에서 멈춘다.
- 초롱의 충전은 깜빡임이 아니라 밝기 증가로 그린다(0.3절).

## 6. 화면 효과의 한도(강화 화면)

0.3절을 강화 화면에 적용한 것이다.

| 항목 | 값 |
|---|---|
| 한 번의 시도에 쓰는 전체 화면 번쩍 | 최대 1회 |
| 연속 시도에서 번쩍 사이 간격 | 가장 짧은 빠른 강화(0.8초 주기)에서도 0.4초 이상. 빠른 강화의 번쩍은 15% 이하 |
| 어두워짐 | 0.1초에 걸친 1회 전환. 빠른 강화에서는 쓰지 않는다 |
| 충전 중 떨림 | 지팡이 그림만 4px. 화면은 떨지 않는다 |
| 화면 균열 덮개 | 정지 그림 3장. 깜빡이지 않는다 |

## 7. 건너뛰기, 빠른 강화, 이어서 강화

| 기능 | 동작 | 제한 |
|---|---|---|
| 건너뛰기 | 의식 중 J를 다시 누르면(누름 뒤 0.3초는 무시) 판정 시각으로 넘어가고 결과는 0.5초짜리 짧은 형태로 본다 | 변이 카드, +13 첫 도달의 처음 2초는 넘길 수 없다 |
| 빠른 강화(켬/끔) | 충전 0.3초, 심장 소리·숨 멈춤·카메라·어두워짐 없음. 결과는 짧은 형태: 숫자 내려찍기 + 속성색 또는 회색 고리 + 한 음. 시도 한 번에 약 0.8초 | +10 이상 도전은 빠른 강화를 켜도 전체 의식이 기본이다. 설정에서 풀 수 있다 |
| 이어서 강화 | 같은 제물 구성(같은 등급·속성의 블록이 서고에 남아 있을 때)과 부적 사용 여부로 시도를 반복한다. 시도마다 따로 결과를 요청한다(미리 여러 번 뽑아 두지 않는다) | 아래 조건에서 멈춘다 |

이어서 강화가 멈추는 조건: 목표 단계 도달, 골드·강화석·제물·부적 부족, 변이 제시, 대성공, 마일스톤 도달, (선택) 단계 하락, J나 K를 누름.

- 짧은 형태에서도 대성공은 금색 고리와 두 번의 숫자 내려찍기로, 변이는 연두 고리로 구분된다. 기운 불씨와 확률 숫자의 변화는 생략하지 않는다.
- 이어서 강화 중에는 화면 위에 "12번째 시도 · 성공 5 · 실패 7 · 쓴 골드 44,800"이 쌓인다.
- 결과 카드에는 "뽑힌 값 37.2 / 82.0 이하면 성공"을 펼쳐 볼 수 있다.

## 8. 서버 전체 알림

강화 화면은 혼자 보는 메뉴 화면이라 구경꾼이 없다. 남에게 전해지는 것은 이 알림 하나다. **+10 이상 성공**(+10, +11, +12가 된 순간)과 **+13 달성**을 서버 전체에 알린다(`DECISIONS.md` 2.4).

| 사건 | 받는 사람이 있는 곳 | 보이는 것 | 들리는 것 |
|---|---|---|---|
| +10 ~ +12 성공 | 광장 | 화면 위 알림 띠 4초(960×80px). 알림 띠는 느루의 까마귀(32×32, `world-characters.md` 10.2절의 그림)가 물고 화면 위 가장자리로 들어온다. 느루의 흔들의자에서 느루가 한쪽 눈을 뜬다(`world-characters.md` 2.5절). 대화창에 시스템 줄 | 종 한 번 |
| | 메인 메뉴, 강화 화면, 그 밖의 메뉴 | 화면 위 가장자리에 한 줄 소식 4초(높이 40px). 내 의식이 재생 중이면 의식이 끝난 뒤에 낸다 | 종 한 번(−6dB) |
| | 무한 웨이브 전투, 결투 | **띄우지 않는다.** 전투에서는 다음 야영 화면의 한 줄 소식으로, 결투에서는 결과 화면 뒤로 미룬다 | 없음 |
| +13 달성 | 광장 | 알림 띠 6초(금 테두리). 알림 띠는 느루의 까마귀(32×32, `world-characters.md` 10.2절의 그림)가 물고 화면 위 가장자리로 들어온다. 느루의 흔들의자에서 느루가 한쪽 눈을 뜬다(`world-characters.md` 2.5절). 광장 하늘에 그 속성색 빛띠 6초. 모닥불이 그 속성색으로 6초 탄다. 대화창에 시스템 줄 | 큰 종 + 속성 주제 선율 2마디 |
| | 메인 메뉴, 강화 화면, 그 밖의 메뉴 | 한 줄 소식 6초(금 테두리) | 큰 종(−6dB) |
| | 무한 웨이브 전투, 결투 | 위와 같이 미룬다 | 없음 |

알림 문구:

- +10 ~ +12: "○○○의 끓는 부지깽이가 +11이 되었다."
- +13: "○○○ — **엄청엄청 위대한 달구**가 나왔다. 느루: …그건 나도 못 해 봤다."
- 두 문구의 지팡이 이름, 캐릭터 이름, 스승 이름은 이름 표(`world-characters.md` 0절)에서 읽는다. 지금 캐릭터 표시 이름으로는 "엄청엄청 위대한 제자 1"이 된다.

규칙:

- 알리는 것은 **성공뿐**이다. 실패, 하락, 변이, 도전 중이라는 사실은 누구에게도 가지 않는다.
- +10 ~ +12 알림은 6초에 하나, +13 알림은 10초에 하나씩 차례로 낸다. +13이 줄 맨 앞으로 간다. 밀린 +10 ~ +12 알림이 10개를 넘으면 "방금 +10 이상 성공 14건"처럼 한 줄로 묶는다.
- 대성공으로 두 단계를 한 번에 올라 +10 이상이 되면 알림은 도착한 단계로 한 번만 낸다.
- 알림 띠는 화면 위 가장자리에만 그리고 번쩍과 흔들림을 쓰지 않는다. 전장 위에는 아무것도 그리지 않는다.
- 광장에서 알림 띠가 나오는 차례: 까마귀가 쪽지(32×32, `world-characters.md` 10.2절 "까마귀와 쪽지"의 쪽지 그림)를 물고 화면 위 가장자리를 왼쪽에서 오른쪽으로 1.2초에 지나간다(날기 4프레임). 까마귀가 가운데를 지나는 0.6초 시점에 쪽지가 놓이고 그 자리에서 알림 띠(960×80)가 3프레임에 펼쳐진다. 알림 띠의 4초(+13은 6초)는 펼쳐진 때부터 센다. 같은 때에 흔들의자의 느루가 한쪽 눈을 떴다가(눈 뜨기 2프레임) 알림 띠가 접힐 때 다시 존다. 까마귀, 쪽지, 느루의 그림은 `world-characters.md` 10.2절·10.3절의 것을 그대로 쓰고 이 문서는 새로 그리지 않는다. 까마귀는 화면 위 가장자리 80px 띠 안에서만 날고 전장이나 사람 위를 지나가지 않는다.
- 메인 메뉴, 강화 화면, 그 밖의 메뉴의 한 줄 소식에는 까마귀가 나오지 않는다(틀만 0.2초에 내려온다). 까마귀와 느루의 반응은 광장에만 있다.
- 알림에 싣는 것: 지팡이 아이콘, 지팡이 이름, 속성색, 닉네임. 아이콘은 지팡이 문서의 목록 아이콘 64×64(`world-characters.md` 3.3절의 공통 규격) 한 장을 쓴다. 광장의 알림 띠(높이 80px)에는 1배로, 높이 40px인 한 줄 소식에는 절반(32×32)으로 줄여 넣는다. 알림용 아이콘을 따로 그리지 않는다.
- 설정: "서버 강화 알림 보기"(전체 / +13만 / 끔). 알림에 내 이름을 올릴지는 `online.md`의 공개 범위 설정을 따른다(이름을 가리면 "어느 제자의 …"로 나간다).
- 오프라인 프로필에서는 이 절의 일이 전부 일어나지 않는다. 내 화면의 의식, 결과 카드, 느루의 반응은 그대로 나온다. 결과 카드의 "서버 전체에 알렸다" 줄만 빠진다.

### 9.2 누적 가림 상한 — 내 효과가 예고를 덮지 못하게 하는 규칙

효과 한 장의 불투명도만 제한해서는 소용이 없다. 반경 2칸 폭발이 불투명도 60%로 세 장 겹치면 그 아래는 1 − 0.4³ = 94%가 가려진다. 거대 화염구에 세 갈래와 적중 시 발동을 붙이면 같은 자리에 폭발이 3~9장 겹친다. 그래서 **장 수가 아니라 합친 결과에 상한을 건다.**

방법: 7층과 8층(내 탄, 꼬리 띠, 적중 불꽃, 폭발, 처치 조각, 비기의 효과)을 화면 밖 버퍼 한 장에 모아 그린 뒤, 아래 상한으로 알파를 눌러 **한 번만** 화면에 합친다. 버퍼 안에서 몇 장이 겹쳤든 화면에 닿는 불투명도는 상한을 넘지 못한다.

| 화면의 자리 | 버퍼를 합칠 때의 불투명도 상한 |
|---|---|
| 예고 마스크 밖 | 80% (바닥과 적의 몸이 항상 20%는 비친다) |
| 예고 마스크 안 | **40%** (예고의 채움이 항상 60% 넘게 보인다) |
| 예고 마스크 안, 그 예고가 번쩍이는 마지막 2프레임 | **0%** (구역 안의 내 효과가 2프레임 동안 사라진다) |

- **예고 마스크** = 화면에 떠 있는 모든 예고 구역과 남는 위험 구역(가시밭, 불씨, 포자)의 모양을 바깥으로 0.25칸(16px) 넓힌 것. 예고 그리는 셰이더가 같은 모양을 마스크 버퍼에도 그린다.
- 상한 값은 "내 탄 투명도" 같은 옵션을 곱한 **뒤**에 적용한다. 옵션으로 올릴 수 없다.
- 버퍼를 합친 다음 9층에서 예고의 3겹 테두리와 차오름의 앞선(흰 선 + 검정 선)을 다시 그린다. 그래서 테두리와 "언제 터지는가"는 폭발이 몇 장 겹쳐도 맨 위에 100%로 남는다.
- 적 탄(10층)은 버퍼보다 위라서 가려지지 않는다.
- 3층(내 지대)은 버퍼에 넣지 않는다. 예고 채움보다 아래에 있어 예고를 덮지 못한다.
- 결투에서는 상대의 탄·지대·예고가 "적"이고 내 것이 버퍼에 들어간다(17절).
- 지팡이 문서와 치장 효과는 이 규칙을 따로 다시 정하지 않는다. "예고 구역 안에서 몇 %" 같은 개별 수치는 지팡이 문서에서 지우고 이 절을 가리킨다.

검산(낮 맨흙 바닥의 예고 구역 위에 내 폭발이 상한 40%로 겹쳤을 때): 화염이면 찬 곳이 `#D95726`, 안 찬 곳이 `#814E1F`가 되어 둘의 대비가 1.8:1로 떨어진다(겹치기 전 2.7:1). 다섯 속성 중 가장 나쁜 것은 비전으로 1.4:1이다. 채움만으로는 "어디까지 찼는가"가 약해지므로, 9층에 다시 그리는 **앞선**(흰 2px + 검정 2px. 둘 중 하나는 그 위에서 5.2:1 이상)과 3겹 테두리가 이 정보를 맡는다. 상한이 없으면(세 장에 94% 가림) 채움 자체가 보이지 않는다.

### 9.3 입자 예산 — 유일한 기준

입자 수와 넘쳤을 때의 처리는 이 절이 유일한 기준이다(`DECISIONS.md` 2.8). 지팡이 문서는 여기서 정한 몫 안에서 단계별 **요청량**만 적는다. 지팡이 문서에 자체 상한이나 별도 예산을 두지 않는다.

**무엇을 입자로 세는가**

| 입자다 (1개로 센다) | 입자가 아니다 (예산과 무관) |
|---|---|
| 본체에서 떨어져 혼자 움직이다 사라지는 조각 하나: 불티, 김, 서리 가루, 종이 부스러기, 글자 조각, 적중 불꽃의 낱알, 처치 조각, 연기, 반딧불, 빗방울 | 투사체 그림(내 탄 300, 적 탄 150의 상한은 GDD) |
| | **꼬리**: 탄 1발에 붙는 띠 그림 1장. 다섯 지팡이 모두 꼬리는 입자가 아니라 띠 그림이다 |
| | 총구 섬광: 지팡이 끝에 붙는 그림 1장 |
| | 지팡이 본체의 움직임과 본체에 딸린 부품(공전하는 조각, 뜬 구슬, 낱장) |
| | 셰이더로 그리는 고리, 예고 구역, 열 링, 잔상 |

꼬리 띠의 한도(입자가 아니어도 지킨다): 길이 0.75칸(48px) 이하, 4프레임 이하, 불투명도 70% 이하. 탄당 입자 6개를 흘리는 식의 꼬리는 띠 그림의 프레임으로 바꾼다.

**전투 화면의 예산** (동시에 살아 있는 입자 수)

| 우선순위 | 분류 | 전체 | 줄임 | 최소 | 넘쳤을 때 |
|---|---|---|---|---|---|
| 0 | 예고 구역, 적 탄, 열 링, 피격 표시 | — | — | — | 입자가 아니다. 줄이지 않는다 |
| 1 | 내 비기 (결투에서는 상대 비기에도 같은 몫을 따로 준다) | 400 | 250 | 120 | 일회성 |
| 2 | 적중 (지팡이 단계별 적중 장식, 약점·저항 표시 포함. 지팡이 문서가 "적중 불꽃 몫"이라고 부르는 것이 이 분류다) | 300 | 150 | 60 | 일회성. 같은 적에게 0.05초 안에 3번 넘게 맞으면 큰 불꽃 하나(입자 8)로 합친다 |
| 3 | 처치 조각과 연기 | 300 | 150 | 60 | 일회성. 한 프레임에 5마리 넘게 죽으면 조각을 절반으로 |
| 4 | 탄이 흘리는 입자와 발사 1회의 총구 입자 (불티, 서리 가루 등. 꼬리 띠는 제외) | 240 | 120 | 0 | 반복 |
| 5 | 지팡이 대기 (든 지팡이 둘레의 상시 입자) | 60 | 30 | 0 | 반복 |
| 6 | 환경 (반딧불, 비, 먼지) | 200 | 100 | 60 | 반복 |
| 합계 | | **1,500** | **800** | **300** | |

**넘쳤을 때의 처리 — 하나뿐인 규칙**

1. 입자는 전부 "입자 예산 관리기" 한 곳에서 발급받는다. 분류와 수명을 대고 요청하며, 관리기가 안 주면 그리지 않는다.
2. **반복 효과**(분류 4, 5, 6: 계속 새로 나오는 것)는 몫이 차면 **새로 만들지 않는다.** 이미 나온 입자는 제 수명대로 사라진다. 지우지 않으므로 깜빡이지 않는다.
3. **일회성 효과**(분류 1, 2, 3: 사건 하나에 한 번 나오는 것)는 몫이 차면 그 분류에서 **가장 오래된 것부터 0.1초에 걸쳐 흐려지며** 자리를 내준다. 새 사건은 항상 보인다.
4. 합계가 넘치면 6 → 5 → 4 → 3 → 2 순으로 몫을 줄인다. 1은 마지막이다.
5. 내 탄 수에 따라 자동으로 줄인다. 다섯 지팡이가 같은 문턱을 쓴다.

| 화면의 내 탄 수 | 처리 |
|---|---|
| 100개 이하 | 그대로 |
| 101 ~ 200개 | 탄이 흘리는 입자를 끈다. 꼬리 띠 길이를 절반으로. 적중 장식은 절반 |
| 201개 이상 | 꼬리 띠를 끈다. 적중 장식은 최소형(입자 2개) |

6. 피해 숫자는 입자가 아니고 화면에 40개까지다. 같은 적에게 0.2초 안에 들어간 피해는 합쳐서 한 숫자로 띄운다.

**지팡이 문서가 채우는 몫** — 단계 구간별 요청 상한 (다섯 지팡이 공통, 확정)

지팡이 문서는 이 표의 값 **이하**로 단계별 요청량만 적는다. 표는 다섯 지팡이에 똑같이 적용되고, 지팡이마다 따로 주는 몫은 없다. 다섯 지팡이 문서가 지금 요청하는 양은 전부 이 표 안에 들어온다(아래 대조표). 지팡이 문서가 요청량을 더 낮게 고쳐 적는 것은 언제나 허용된다.

| 단계 구간 | 대기 입자(동시) | 발사 1회의 총구 입자 | 탄 1발이 흘리는 입자(동시) | 적중 1회 | 꼬리 띠 길이 |
|---|---|---|---|---|---|
| +0 ~ +3 | 8 | 2 | 0 | 4 | 16px |
| +4 ~ +6 | 16 | 4 | 1 | 7 | 24px |
| +7 ~ +9 | 30 | 5 | 1 | 8 | 32px |
| +10 ~ +12 | 45 | 6 | 2 | 10 | 40px |
| +13 | 60 | 8 | 2 | 12 | 48px |

열마다 세는 법:

| 열 | 세는 법 | 받는 분류 | 수명 한도 |
|---|---|---|---|
| 대기 입자 | 손에 든 지팡이 한 자루 둘레에 **동시에** 살아 있는 수 | 5 (지팡이 대기) | 2초 |
| 발사 1회의 총구 입자 | J를 한 번 눌러 나가는 발사 1회에 한 묶음. 분열로 여러 발이 나가도 한 묶음이다. 탄 수만큼 곱하지 않는다 | 4 | 0.2초 |
| 탄 1발이 흘리는 입자 | 날아가는 탄 1발 뒤에 **동시에** 살아 있는 수 | 4 | 0.3초 |
| 적중 1회 | 탄 1발이 적 하나에 맞은 사건 하나에 한 묶음 | 2 (적중) | 0.4초 |
| 꼬리 띠 길이 | 탄 1발에 붙는 띠 그림 1장의 길이. 입자가 아니다 | — | — |

- 적중 1회에 덧붙는 것: 임계 사격 +4, 약점 +2, 저항 −2(13.4절). 지팡이 문서의 요청량에는 넣지 않는다.
- "지팡이 효과" 옵션(18절)이 줄임이면 관리기가 요청량을 절반(올림)으로 발급하고, 최소면 대기 0, 총구 0, 탄이 흘리는 입자 0, 적중은 최소형(입자 2개), 꼬리 띠 없음이다. 지팡이 문서는 설정별 수를 따로 적지 않는다.
- 본체에 딸린 그림(성에의 공전 조각·왕관·고리, 그믐의 뜬 조각, 갈피의 낱장, 초롱의 선 벼락과 구름 띠 등 지팡이 문서가 "대기 스프라이트"나 "프레임 그림"이라고 부르는 것)은 입자가 아니므로 이 표와 무관하다. 장수는 지팡이 문서가 적는다.
- +13의 발밑 바닥 효과(그을린 발자국, 도는 빛줄기, 곧은 밑줄, 육각 서리, 둥근 밤)는 2층(바닥 흔적)의 그림이나 셰이더로 만들고 입자를 쓰지 않는다. 예고 채움이 그 위에 그려진다.
- 지팡이가 바닥에 남기는 그 밖의 흔적 그림(쇳물 방울, 서리 자국, 획 등)도 2층의 그림이고 입자가 아니다. 한도: 지팡이 한 자루가 화면에 동시에 남기는 흔적 24장까지(넘치면 새로 남기지 않는다), 한 장은 지름 16px 이하, 불투명도 60% 이하, 0.8초 이하. +13의 발밑 효과만 이 한도와 별개로 지팡이 문서가 적은 크기와 시간을 쓴다.
- 줄임·최소 설정에서도 단계는 구분되어야 한다. 단계 구분은 본체 실루엣이 맡고 입자는 덤이다.

대조표: 다섯 지팡이 문서의 지금 요청량(구간 안의 최댓값)과 위 상한. 표기는 대기 / 총구 / 적중이고, "—"는 그 지팡이가 요청하지 않는 칸이다.

| 단계 구간 | 상한 | 달구 | 초롱 | 갈피 | 성에 | 그믐 |
|---|---|---|---|---|---|---|
| +0 ~ +3 | 8 / 2 / 4 | 2 / 2 / 2 | 1 / — / 3 | 1 / 2 / 3 | 3 / — / 4 | 2 / — / 0 |
| +4 ~ +6 | 16 / 4 / 7 | 4 / 3 / 4 | 3 / — / 4 | 1 / 3 / 4 | 7 / — / 5 | 5 / — / 2 |
| +7 ~ +9 | 30 / 5 / 8 | 6 / 4 / 6 | 6 / — / 6 | 3 / 4 / 6 | 8 / — / 6 | 8 / — / 3 |
| +10 ~ +12 | 45 / 6 / 10 | 9 / 5 / 7 | 10 / — / 7 | 5 / 5 / 7 | 14 / 2 / 7 | 12 / — / 4 |

- 지금 가장 많이 요청하는 값은 총구가 달구·갈피의 6(+13), 적중이 달구·초롱·갈피·성에의 8(+13)이다. 총구와 적중의 상한은 그 위로 여유를 둔 값이다(+13에서 총구 2, 적중 4).
- 탄 1발이 흘리는 입자는 초롱의 +5만 1개를 요청하고(상한 1) 나머지는 전 단계 0이다(다섯 모두 꼬리를 띠 그림으로 그린다). 이 칸의 남는 몫은 서리 변형의 서리 가루(13.3절)와 나중에 더해질 치장 효과가 쓴다.
- 꼬리 띠 길이: 초롱 0~32px, 달구 16px 이하, 갈피 24px 이하, 성에 20px 이하. 모두 구간 상한 안이다.
- 다섯 지팡이 문서가 옮겨 적은 상한은 이 절의 표(총구 2 / 4 / 5 / 6 / 8, 적중 4 / 7 / 8 / 10 / 12)와 같다. 예전 값(총구 2 / 3 / 4 / 5 / 6, 적중 4 / 5 / 6 / 7 / 8)은 쓰지 않는다. 서로 다르면 이 절의 표가 맞다.

- 단계를 알아보는 데 필요한 것(실루엣, 단계 표식, 공전 조각 수)은 본체 그림이라 40명 모두 그대로 보인다.
- "남의 지팡이 효과" 옵션(18절)을 줄임으로 하면 8명의 몫이 0이 된다.

**강화 화면**: 합계 600 / 300 / 100. 충전 입자(4절의 초당 수 × 수명 1초), 성공 고리, 깨지는 조각, 꽃가루가 여기서 나간다. 넘치면 충전 입자(반복)부터 새로 만들지 않는다.

효과음 동시 재생 상한은 19.5절.

## 10. 열, 임계, 잠금

열 링은 캐릭터 발밑 중심, 반지름 44px, 셰이더로 그린다. 링 위에는 그 캐릭터의 임계 시작값 자리에 **눈금**이 하나 있다(캐릭터마다 다르다. 값은 `world-characters.md`).

| 상태 | 조건 | 링 | 덧붙는 것 | 소리 |
|---|---|---|---|---|
| 차가움 | 열 0 | 보이지 않음(눈금만 희미하게) | | |
| 오르는 중 | 임계 시작 −15 미만 | 회청색 `#AEB8C8` 4px, 불투명도 60% | | |
| 임박 | 임계 시작 −15 ~ 임계 시작 | 회청색 6px, 눈금이 초당 2회 숨 쉰다 | | 낮게 깔리는 웅 소리가 올라간다 |
| **임계** | 임계 시작 ~ 100 | **임계 표식**: 흰색 6px + 바깥 검정 2px | 쐐기(`>` 모양 8px) 2개가 링을 돈다. 지팡이 끝에 흰 쐐기 빛 | 웅 소리가 맑은 음으로 바뀐다 |

- 잠금은 빨강이 아니다(0.1절). 발밑의 빨간 원은 적의 원형 예고와 헷갈린다. 꺼진 색과 X, 김, 소리로 알린다.
- 열 링은 9.2절의 버퍼에 들어가지 않는다(11층). 폭발 아래에 묻히지 않는다.

캐릭터별 보조 표시(`world-characters.md`): 달구는 주전자 김의 굵기와 뚜껑, 성에는 얼음 왕관의 크기, 초롱은 등불 알의 밝기. 그믐과 갈피는 링만 쓴다. 고유 능력이 열에 영향을 주는 동안(예: 달구의 불가마 안)에는 링 눈금에 그 능력의 작은 표식(8×8)이 붙는다.

**임계 사격**

| 순간 | 연출 |
|---|---|
| 발사 | 지팡이 끝에 흰 고리 + 검정 테(32×32, 3프레임). 발사음 위에 높은 금속음 한 겹 |
| 탄 | 속성색과 속성 모양은 그대로. **이중 테**(안쪽 흰 2px, 바깥 검정 2px)가 붙고 탄 앞에 **쐐기**(`>` 모양, 흰색 6px + 검정 테)가 달린다. 테는 탄 그림 바깥에 붙고 판정 크기는 같다 |
| 적중 | 흰 쐐기 불꽃 6개(검정 테), 큰 피해 숫자(1.5배, 흰색 + 검정 4px 테 + 느낌표), 맞은 적 그림 정지 0.03초, 흔들림 소 |
| 임계로 처치 | 조각이 흰색 + 검정 테 |

- 임계에는 금색을 쓰지 않는다. 금색은 엘리트와 값진 것의 색이다(0.1절). 화염과 번개의 탄 위에서도 임계가 보이는지는 16.4절의 가독성 판에서 확인한다.
- 그림 정지는 1초에 합계 0.1초까지만 쓴다. 임계 연사 중에도 화면이 끊기지 않는다.
- 임계 흔들림은 0.3초에 한 번만 누적값에 더한다.

**잠금에 들어가는 발사**: 임계 사격 연출 + 지팡이에서 김이 터진다.

**끓어넘침(달구의 패시브)**: 닫힌 원을 쓰지 않는다. 김 색 `#F4F4F4`의 **끊어진 호 6조각**(조각마다 주황 4px 테)이 반경 2.5칸까지 바깥으로 흩어지며 사라진다(5프레임). 선돌지기 내려찍기의 번쩍(반경 2.5칸의 꽉 찬 흰 원)과 같은 자리에 겹쳐도 호 사이가 비어 있고 안쪽이 칠해지지 않아 구분된다. 탄을 지우지 않으므로 소거 연출(12절 ⑦)과도 다르다.

- 뇌광창이 늦어 꿰뚫는 창으로 나가면 저스트 신호가 없다. 연습장에서는 "0.02초 늦음"이 뜬다.
- 만개의 배경 어두워짐은 예고 구역, 적, 탄에는 적용하지 않는다. 오히려 위험이 더 잘 보인다.
- 만개의 번쩍은 한 번이다. 파동마다 번쩍이지 않는다(0.3절).

## 13. 적중, 처치, 피격

### 13.1 내가 적을 맞힐 때

피해의 속성은 맞힌 투사체 블록의 속성이다(`DECISIONS.md` 2.5). 적중 불꽃의 색과 모양도 그 블록의 속성을 따른다. 캐릭터의 속성이 아니다.

| 사건 | 연출 | 소리 |
|---|---|---|
| 일반 적중 | 적이 2프레임 하얗게 번쩍, 2px 밀림. 속성색 불꽃 4개(32×32, 3프레임). 흰 피해 숫자(검정 2px 테) | 짧은 타격음. 음높이를 ±2반음 흩는다 |
| 임계 적중 | 10절 | |
| **약점 속성 적중** (피해 ×1.25) | 13.4절 | |
| **저항 속성 적중** (피해 ×0.8) | 13.4절 | |
| 철갑에 막힘(골렘 정면) | 회색 튕김 불꽃(32×32, 3프레임). 피해 숫자가 회색이고 작다(0.8배) | 금속 "팅" |
| 폭발 | 속성색 **고리**(굵기는 반경의 25%)가 판정 반경까지 퍼지고 안쪽은 속성색 30% 이하로 채운다. 5프레임, 0.25초. 여러 장이 겹쳐도 9.2절의 상한을 넘지 못한다 | 폭발음 |

| 살얼음(성에의 패시브) | 맞을 때마다 적 발밑에 서리 눈금 하나(5개까지). 6번째에 얼음 덩어리가 씌워지고 눈금이 지워진다. 풀릴 때 깨진다. 다시 얼지 않는 동안에는 눈금이 쌓이지 않고 발밑에 녹은 물 자국 한 점만 남는다. 얼지 않는 적(중량, 보스)에게는 얼음 덩어리 대신 감속 표시(13.3절의 발목 고리 두 줄)가 붙는다. 횟수, 어는 시간, 다시 얼기까지의 시간, 적 종류별 차이는 `world-characters.md`의 살얼음과 3.6절이 정하고 그림은 그 값에 맞춘다 | 얼어붙는 "쩍" |
| 넉백, 경직, 기절 | 밀린 방향으로 먼지. 경직은 그림 떨림, 기절은 별(`monsters.md`) | |

- 적중음은 1초에 8번까지 낸다. 넘는 것은 소리 없이 그림만 낸다.
- 적이 번쩍이는 색은 흰색이다. 위험색을 쓰지 않는다.
- 피해 숫자의 색: 일반 흰색 / 임계 흰색 1.5배 + 굵은 검정 테 + 느낌표 / 약점 속성 보조색 1.25배 + ▲ / 저항 회청색 `#8E9AAE` 0.8배 + ▼ / 철갑 회색 0.8배. 금색 숫자는 골드를 얻을 때만 쓴다.

| 소리 | 원래 발사·적중음 위에 유리 겹소리 한 겹(−9dB) |

**잠식** (변형, 암흑: 붙인 탄에 맞은 적이 3초 동안 받는 피해 +15%)

| 순간 | 연출 |
|---|---|
| 붙은 탄 | 원래 탄의 모양과 색은 그대로. 탄 뒤에 짙은 보라 얼룩 꼬리(띠 그림, 16px) |
| 적중 | 원래 적중 효과 + 적의 몸에 **잠식 표시**(아래)가 3초 |
| 소리 | 원래 적중음 위에 낮게 스미는 소리 한 겹 |

**적에게 붙는 상태 표시** (6층, 적의 몸 위. 입자가 아니라 겹그림이다)

| 상태 | 표시 | 남은 시간 | 성에의 살얼음과 구분 |
|---|---|---|---|
| 감속 (얼음 송곳 −30%, 서리 −20%) | 적의 발목에 하늘색 서리 고리(적 그림 너비, 높이 8px). −30%는 고리가 두 줄, −20%는 한 줄. 적의 걷는 프레임이 그만큼 느리게 넘어간다 | 고리가 끝에서부터 녹아 짧아진다 | 살얼음은 발밑의 **눈금 5개 → 얼음 덩어리**, 감속은 발목의 **고리**. 둘이 함께 붙을 수 있다 |
| 잠식 (받는 피해 +15%) | 적의 윤곽에 연보라 `#D9C7FF` 점선 테 2px + 몸 위로 번지는 짙은 보라 금(겹그림 2프레임) | 점선 테가 시계 방향으로 줄어든다 | 잠식 중에 들어간 피해 숫자에는 작은 보라 ▲가 붙는다(약점의 ▲는 속성 보조색이고 숫자가 커진다) |

- 같은 상태가 다시 걸리면 시간만 새로 채운다(표시가 한 번 깜빡이지 않고 다시 길어진다). 감속 두 종류가 겹치면 큰 쪽(두 줄)을 그린다.
- 상태 표시는 적의 공격 부위 물듦(자홍)과 예고를 가리지 않게 발목과 윤곽에만 둔다.
- 엘리트의 금 테와 잠식의 점선 테가 겹치면 금 테를 안쪽, 점선 테를 바깥쪽에 그린다.

### 13.4 약점과 저항

적마다 약점 속성 1개와 저항 속성 1개가 있다(`DECISIONS.md` 2.5).

| | 약점 적중 (×1.25) | 저항 적중 (×0.8) |
|---|---|---|
| 적 | 흰 번쩍 2프레임 뒤에 그 속성색으로 2프레임 더 물든다. 4px 밀림(일반의 2배) | 흰 번쩍 없이 1프레임만 어두워진다. 밀리지 않는다 |
| 불꽃 | 속성 보조색 불꽃 6개 + 큰 불꽃 한 장(64×64, 4프레임) | 무채색 불꽃 2개 + 적 몸 앞에서 속성색 호 하나가 튕겨 나간다(32×16, 3프레임) |
| 피해 숫자 | 속성 보조색, 1.25배, 숫자 앞에 ▲와 속성 문양(16×16) | 회청색 `#8E9AAE`, 0.8배, 숫자 앞에 ▼ |
| 소리 | 타격음에 속성 소리 한 겹, 2반음 위 | 둔탁한 타격음, 3반음 아래, −3dB |
| 입자(적중 몫) | 일반 적중 +2 | 일반 적중 −2 |

- **알려 주기**: 어떤 종에게 약점이나 저항 속성으로 처음 맞힌 순간, 그 적 머리 위에 속성 문양 아이콘(약점은 ▲와 함께 밝게, 저항은 ▼와 함께 회청색)이 1.5초 뜬다. 한 번 본 종은 야영의 "다음 웨이브" 정보와 도감에 약점·저항이 적힌다.
- 철갑에 막힘(회색 불꽃, 금속 "팅")과 저항(속성색 호, ▼, 둔탁한 소리)은 다른 사건이다. 철갑은 방향 문제이고 저항은 속성 문제라는 것이 그림으로 갈려야 한다.
- 임계이면서 약점이면 임계 표식(1.5배, 검정 굵은 테, 느낌표)에 ▲와 속성 문양을 더한다. 숫자 크기는 1.5배에서 더 키우지 않는다.
- 약점·저항 표시는 색각 보조와 무관하게 ▲▼ 기호가 항상 붙는다. 색만으로 알리지 않는다.

## 14. 적의 예고

### 14.1 문법 [개발자: 빨강이 차오른 뒤 흰색으로 번쩍]

| 단계 | 그림 | 뜻 |
|---|---|---|
| 1. 나타남 | **최종 크기의 3겹 테두리**가 처음부터 다 보인다. 구역은 자라지 않는다. 구역 안의 바닥이 어두워진다 | 어디가 위험한가 |
| 2. 차오름 | 빨강 채움이 시작점에서 퍼진다. 채워진 비율 = 지난 시간 ÷ 예고 시간(일정한 속도). 채움의 맨 앞에 **앞선**(흰 2px + 검정 2px)이 함께 움직인다 | 언제 터지는가 |
| 3. 번쩍 | 마지막 2프레임에 구역 전체가 흰색이 된다 | 지금 |
| 4. 판정 | 구역 모양의 자홍·흰 충격 그림(3프레임). 바닥에 0.3초 자국 | 끝났다 |

**테두리는 3겹이다** (합계 8px).

| 겹 | 굵기 | 색 | 하는 일 |
|---|---|---|---|
| 바깥 | 2px | 검정 `#000000` | 밝은 것 위에서 구역의 모양을 지킨다 |
| 가운데 | 4px | 빨강 `#FF3B30` | "위험"이라는 뜻 |
| 안쪽 | 2px | 흰색 `#FFFFFF` (불투명) | 어두운 것 위에서 구역의 모양을 지킨다 |

빨강 한 줄로는 통과하지 못한다. 계산(상대 휘도 대비, 바닥 색은 `world-characters.md`의 현재 값):

| 그 아래의 색 | 빨강 테만 | 흰 선 | 검정 선 | 3겹의 결과 |
|---|---|---|---|---|
| 낮 풀 `#2F4A3A` | 2.7:1 | 9.7:1 | 2.2:1 | 9.7:1 통과 |
| 낮 맨흙 `#4A4034` | 2.9:1 | 10.1:1 | 2.1:1 | 10.1:1 통과 |
| 해질녘 `#3A2E3E` | 3.6:1 | 12.8:1 | 1.6:1 | 12.8:1 통과 |
| 해질녘 흙 `#4A3830` | 3.1:1 | 11.1:1 | 1.9:1 | 11.1:1 통과 |
| 밤 `#161F3A` | 4.6:1 | 16.3:1 | 1.3:1 | 16.3:1 통과 |
| 돌마당 `#2C3442` | 3.5:1 | 12.5:1 | 1.7:1 | 12.5:1 통과 |
| 불가마 안(낮 맨흙 + 주황 20%) `#6E4F30` | 2.1:1 | 7.5:1 | 2.8:1 | 7.5:1 통과 |
| 화염 폭발 `#FF8A1F` | 1.5:1 | 2.4:1 | 8.9:1 | 8.9:1 통과 |
| 번개 효과 `#FFF36B` | 3.1:1 | 1.1:1 | 18.3:1 | 18.3:1 통과 |
| 냉기 효과 `#9FDCFF` | 2.4:1 | 1.5:1 | 14.2:1 | 14.2:1 통과 |

- 빨강 테만으로는 낮과 해질녘의 모든 바닥에서 4.5:1에 못 미친다(2.7~3.6:1). 밤에만 겨우 넘는다(4.6:1).
- 흰 선과 검정 선을 함께 두면 **어떤 색 위에서도** 둘 중 하나가 4.5:1을 넘는다. 흰 선은 상대 휘도 0.183 이하의 색 위에서, 검정 선은 0.175 이상의 색 위에서 4.5:1 이상이고 두 범위가 겹친다. 가장 나쁜 경우는 휘도 0.18 근처의 중간 회색으로, 이때 둘 다 4.6:1이다. 바닥 팔레트가 바뀌어도 이 보장은 그대로다.
- 빨강은 흰 선(3.5:1)과 검정 선(5.9:1) 사이에 끼어 있어 "두 선 사이의 띠"로 읽힌다. 색각에 따라 빨강이 흐려져도 3겹 줄무늬라는 모양이 남는다.
- 3겹 테두리와 앞선은 4층에서 한 번, 내 탄과 폭발을 합친 뒤 9층에서 한 번 더 그린다(9.1절).

**채움은 바닥 색과 무관하게 그린다.**

| 부분 | 그리는 법 | 낮 풀 위의 결과 | 밤 위의 결과 |
|---|---|---|---|
| 구역 안, 아직 안 찬 곳 | 그 아래(바닥, 바닥 흔적, 내 지대)를 40% 어둡게 한다 | `#1C2C23` | `#0D1323` |
| 찬 곳 | 어둡게 한 위에 빨강 `#FF3B30`을 70% 덮는다 | `#BB372C` | `#B62F2C` |
| 앞선 | 찬 곳의 경계에 흰 2px 선, 그 바로 뒤(찬 쪽)에 검정 2px 선 | | |

- 찬 곳의 색은 어느 바닥에서나 채도 75~78%, 명도 72~75%의 같은 빨강이 된다(위험색의 조건인 채도·명도 70% 이상을 지킨다). 예전의 "빨강 35% 알파 혼합"은 이끼색 위에서 흙 갈색 `#784536`이 되어 맨흙과 구분되지 않았다.
- 찬 곳과 안 찬 곳의 휘도 대비는 2.6~3.0:1이다. 여기에 앞선이 경계를 긋는다(흰 선은 찬 곳 위에서 5.6:1 이상. 내 효과가 겹쳐 밝아진 곳에서는 검정 선이 대신 4.5:1을 넘는다). 무채색으로 바꿔 봐도 어디까지 찼는지가 보인다.
- 채움의 진하기 옵션은 70% / 80% / 90%다(18절). 70% 아래로는 내릴 수 없다.

모양별 차오르는 방향(`monsters.md`의 다섯 모양):

| 모양 | 차오르는 방향 | 예 |
|---|---|---|
| 원 | 가운데에서 밖으로 | 골렘 내려찍기, 자폭 |
| 직선 띠 | 적에게서 먼 쪽으로 | 늑대·멧돼지 돌진 |
| 부채꼴 | 꼭짓점에서 호 쪽으로 | 골렘 휩쓸기 |
| 조준선 | 검정 2px 바깥선 사이에서 빨강이 2px → 8px로 굵어진다. 한가운데 흰 2px 심은 처음부터 있다. 방향이 고정되는 순간 선이 한 번 떤다 | 고슴도치 |
| 고리 | 안쪽 테두리에서 바깥 테두리로. 빈 가운데가 안전하다 | 보스 패턴 |

- 차오름이 끝나는 때와 판정이 **같은 프레임**이다. 어긋나면 버그다.
- 예고 시작에는 모양마다 다른 짧은 소리가 나고, 차오르는 동안 올라가는 음이 **판정 순간에 끝난다.** 동시에 여러 개면 가장 먼저 터질 2개만 소리를 낸다.
- 적의 몸에서는 공격하는 부위만 자홍으로 물든다(`monsters.md`). 예고 구역과 같은 순간에 시작한다.
- **남는 위험 구역**(가시밭, 불씨 띠, 포자)은 색각 보조 설정과 무관하게 **항상** 3겹 테두리 + 빗금(빨강 선 4px, 간격 16px, 45도)이고 차오르지 않는다. 사라지기 1초 전부터 초당 2회 흐려졌다 돌아온다. 달구의 불가마(주황 점선 + 벽돌 무늬, 빗금 없음, 흰 선 없음)와는 테두리의 종류와 무늬로 갈린다.
- 등장 예고: 덤불이 0.5초 흔들린다. 색은 덤불색 그대로다(위험이 아니라 알림이다).
- 연습장에서만 구역 바깥 0.6칸에 흰 점선(스쳐 피하기 인정 범위)을 보여 준다.

### 14.2 번쩍 한도와의 관계

예고의 흰 번쩍은 구역 안에서만 일어나고 반복되지 않는다. 다만 무한 웨이브 후반에는 여러 구역이 잇달아 터진다.

- 1초 동안 번쩍인 예고 구역의 넓이 합이 화면의 25%를 넘으면, 그 뒤의 번쩍은 번쩍 관리기가 **테두리 강조**(3겹 테두리의 흰 선이 8px로 굵어진다, 2프레임)로 바꾼다.
- "연출 줄이기 = 줄임·최소"에서는 항상 테두리 강조를 쓴다.
- 번쩍이는 2프레임 동안 그 구역 안의 내 효과는 0%가 된다(9.2절). 번쩍이 테두리 강조로 바뀐 경우에도 같다.
- 색각 보조 옵션에서는 차오르는 채움에도 사선 줄무늬를 넣고, 적 탄의 자홍을 주황 줄무늬 + 흰 중심으로 바꾼다.

| 최종 격노 | HUD: 체력 바 테두리가 빨강, 화면 위에 "최종 격노" 띠 2초, 화면 가장자리에 가는 자홍 테두리(8px, 고정) | 북이 이어지는 박자가 된다 |

## 16. 낮, 해질녘, 밤에서의 가독성

하루는 10웨이브다: 낮(1~4), 해질녘(5~7), 밤(8~9), 보스(10). 그 뒤 다음 날로 반복한다(`DECISIONS.md` 2.3). 시간대는 웨이브 사이 야영에서 바뀌므로 전투 중에 바닥 색이 변하는 일은 없다. 바닥 팔레트의 값은 `world-characters.md`가 정하고, 아래 계산은 그 문서의 현재 값(낮 `#2F4A3A` / 맨흙 `#4A4034`, 해질녘 `#3A2E3E` / 흙 `#4A3830`, 밤 `#161F3A` / 흙 `#222842`, 돌마당 `#2C3442`)으로 했다. 보스 웨이브의 바닥이 따로 정해지면 같은 표에 한 줄을 더해 검산한다.

### 16.1 공통 규칙

| 규칙 | 내용 |
|---|---|
| 색 보정은 바닥만 | 9.1절의 1~2층만 시간대 색을 받는다. 3층 이상의 모든 효과는 낮과 같은 색, 같은 밝기다 |
| 밝은 림 | 플레이어와 적 모두의 윤곽 바깥에 2px 밝은 림(`#EAF2FF`)을 **항상** 켠다. 세기만 바꾼다: 낮 20%, 해질녘 40%, 밤 60%. 밤에도 적은 온전히 보인다. 반투명한 적, 어둠으로 가리는 연출은 쓰지 않는다 |
| **판정 중심은 밝게** | 모든 탄(내 탄, 적 탄, 다섯 속성)의 판정 중심 4×4px은 명도 85% 이상이다. 암흑도 예외가 아니다(16.2절) |
| 탄의 밝기 차 | 탄의 가장 밝은 부분은 세 바닥 어느 것과도 4.5:1 이상이다 |
| 밤과 해질녘의 빛무리 | 내 탄 둘레에 반지름 24px, 불투명도 15%의 빛무리(밤). 암흑 탄은 해질녘에도 켜고 25%로 올린다. 적 탄에는 넣지 않는다(자홍 덩어리가 커지면 판정이 크게 보인다) |
| 환경 입자 | 반딧불은 연두가 아니라 **연노랑**, 4×4px, 가장자리 2칸에만. 빗줄기는 12% 이하. 둘 다 가운데 20×10칸 위에는 그리지 않는다 |

### 16.2 암흑 탄 — 밤에도 판정 위치가 보이게

암흑의 정체는 "가운데가 어둡다"인데, 가운데가 통째로 어두우면 밤 바닥에서 얇은 테만 남고 판정 위치를 알 수 없다. 그래서 **3겹**으로 그린다(아래 굵기는 가장 작은 탄 크기인 16×16 기준이다. 마력탄과 같은 크기라는 뜻일 뿐이고, 마력탄은 비전 블록이라 누가 쏘든 청록 마름모다. 암흑 탄이 되는 것은 암흑 속성의 투사체 블록뿐이다).

| 겹 | 크기 | 색 | 밤 `#161F3A` | 해질녘 `#3A2E3E` | 낮 `#2F4A3A` |
|---|---|---|---|---|---|
| 바깥 테 | 2px | 연보라 `#D9C7FF` | 10.5:1 | 8.3:1 | 6.3:1 |
| 어두운 고리 | 2~4px | 짙은 보라 `#2A1A5E` | 1.1:1 (바닥에 묻힌다. 의도한 것) | 1.2:1 | 1.5:1 |
| 심(판정 중심) | 4×4px | 흰 연보라 `#F1E9FF` (명도 100%) | 13.8:1 | 10.9:1 | 8.3:1 |

- 어두운 고리가 바닥에 묻혀도 **밝은 테 안에 밝은 점이 하나 있는 모양**이 남는다. 테와 심 사이의 대비는 테 대 고리 9.6:1이다. 다른 네 속성은 "밝은 덩어리", 암흑은 "밝은 테 + 점"으로 갈린다.
- 푸른 보라 `#8A5CFF` 한 색으로 칠한 탄은 밤 3.9:1, 해질녘 3.1:1, 낮 2.3:1로 모두 기준에 못 미친다. 주색은 꼬리 띠와 적중 불꽃에만 쓰고, 탄의 몸에는 위 3겹을 쓴다.
- 큰 암흑 탄(그림자 구체, 높은 단계의 장식 탄)도 같은 3겹을 키워 쓴다: 테 4px, 심 8×8px. "검은 원반 + 테"만으로 된 탄은 만들지 않는다. 어느 단계의 어느 탄이든 심이 있어야 한다(`wands/geumeum.md`가 따른다).
- 밤과 해질녘에는 암흑 탄에 연보라 빛무리(반지름 24px, 25%)를 켠다.
- 탄이 100개를 넘어 꼬리가 줄어도(9.3절) 테와 심은 줄이지 않는다.
- 결투에서 상대의 암흑 탄은 테도 몸도 자홍이 되고 심은 흰색이다(17절). 내 암흑 탄(연보라 테, 짙은 보라 고리)과는 몸 전체의 색으로 갈린다. 테 한 줄의 색으로만 갈리지 않는다.

### 16.3 속성별로 겹치기 쉬운 짝

| 팔레트 | 겹치는 것 | 대응 |
|---|---|---|
| 낮 | 비전의 청록 효과 ↔ 풀 | 비전 효과는 흰 민트 중심 + 짙은 테두리 2px. 흔적(바닥 글자)은 불투명도 40%. 적의 몸에는 청록을 쓰지 않는다(0.1절) |
| 해질녘 | 화염의 주황 ↔ 호박색 빛 / 암흑의 보라 ↔ 자두색 바닥 | 불가마 테두리의 점선을 밝은 노랑 `#FFE08A`으로 바꾼다(벽돌 무늬는 그대로). 암흑 탄은 16.2절 |
| 밤 | 냉기의 하늘색 ↔ 달빛 / 암흑 ↔ 남색 바닥 | 얼음 병풍에 흰 윗선 2px. 그림자 웅덩이에 연보라 테두리 2px. 암흑 탄은 16.2절 |
| 모든 팔레트 | 화염의 주황(29도) ↔ 위험 빨강(3도) | 색각에 따라 같은 색으로 보인다. 색이 아니라 문법으로 가른다: 위험은 3겹 테두리 + 차오름 또는 빗금, 화염의 지대는 점선 + 벽돌 무늬. 적의 불씨 띠 같은 남는 위험 구역은 항상 빗금이다(14.1절) |
| 모든 팔레트 | 암흑의 보라 ↔ 적 탄의 자홍 | 암흑 탄은 테 + 점, 적 탄은 꽉 찬 자홍 + 흰 중심. 모양으로 갈린다 |
| 모든 팔레트 | 임계 ↔ 화염·번개의 노랑, 엘리트의 금색 | 임계는 흰색·검정의 이중 테와 쐐기(0.1절). 금색은 적(엘리트)에게만 있다 |

### 16.4 확인 방법: 가독성 판

"가독성 판" 장면을 하나 만든다. 바닥 7종(낮 풀, 낮 맨흙, 해질녘, 해질녘 흙, 밤, 밤 흙, 돌마당) × 5 속성의 모든 탄·비기 위에 다섯 가지 예고 모양, 남는 위험 구역, 적 탄을 겹쳐 놓고 화면을 찍는다. 불가마 안, 사본 마법진 위, 그림자 웅덩이 위, 폭발 9장이 겹친 자리도 넣는다.

통과 기준:

1. 예고의 3겹 테두리 중 한 겹 이상이 그 아래의 무엇과도 4.5:1 이상이다(14.1절의 계산이 화면에서도 맞는지).
2. 무채색으로 바꿔도 예고의 모양, 어디까지 찼는지(앞선), 적 탄이 보인다.
3. 적록 색각 2종과 청황 색각 1종의 시뮬레이션에서도 2번이 성립하고, 불가마와 불씨 띠가 구분된다.
4. 폭발을 9장 겹쳐도 예고 구역 안의 가림이 40%를 넘지 않는다(9.2절). 화면을 찍어 픽셀로 잰다.
5. 다섯 속성 모두에서 임계 탄과 일반 탄이 구분된다. 특히 화염과 번개.
6. 밤과 해질녘 바닥에 암흑 탄 300발을 깔았을 때 탄마다 심이 보인다.
7. 엘리트(금 테) 옆에 임계 탄과 번개 탄이 지나가도 셋이 섞이지 않는다.

|---|---|
| 상대의 탄 | **속성 모양은 그대로, 몸 전체가 자홍 `#FF2E88` + 흰 중심 4×4.** 테만 자홍으로 바꾸지 않는다. 적 탄과 같은 10층에 그린다 |

- **그림자 손의 범위(결투)**: 그믐이 그림자 손을 쓰면 발동 전 0.3초 동안 끌어당기는 범위의 원이 양쪽 화면에 보인다. 상대(끌려갈 사람) 화면에서는 14.1절의 "원" 예고 그대로다: 처음부터 최종 크기의 3겹 테두리, 가운데에서 밖으로 0.3초에 차오르는 빨강, 마지막 2프레임의 번쩍. 그믐 자신의 화면에서는 12.4절의 보라 고리가 같은 0.3초 동안 보인다. 범위의 크기는 `world-characters.md`의 값이다.
- **피뢰침 벼락의 조준 표시(결투)**: 초롱의 스침이 인정되어 벼락이 떨어질 때, 떨어지기 전 0.25초 동안 벼락이 떨어질 자리에 지름 1칸의 "원" 예고(3겹 테두리, 0.25초에 차오름, 번쩍)가 내 화면에 보인다. 그 뒤 피뢰침 벼락 줄기(32×128, 2프레임)가 떨어진다. 초롱의 화면에서는 같은 자리에 레몬색 가는 고리(4px 선, 안을 채우지 않는다)가 0.25초 보인다. 표시는 뜬 순간 상대가 있던 자리에 고정되고 상대를 따라가지 않는다(규칙은 `world-characters.md` 5.4절). 그림은 그 자리에 그린다.
- **얼음 병풍의 파편(결투)**: 상대의 병풍이 깨지거나 4초가 다 돼 사라질 때 파편은 벽 앞쪽 폭 3칸·길이 2칸의 직사각형으로 튄다(12.4절). 상대의 벽이 서 있는 동안 내 화면에는 그 직사각형의 3겹 테두리가 처음부터 바닥에 그려져 있다(안은 40% 어둡게만 하고 빗금은 넣지 않는다. 아직 피해가 없는 곳이기 때문이다). 4초가 다 돼 사라지는 경우에는 마지막 1초 동안(벽에 금이 가는 때와 같다) 빨강이 벽 쪽에서 먼 쪽으로 차오르고 번쩍한 뒤 파편이 튄다. 벽이 탄에 맞아 일찍 부서지는 경우에는 차오름 없이 곧바로 판정 그림(14.1절의 4단계)이 나온다. 어느 쪽이든 어디로 튀는지는 벽이 선 순간부터 알 수 있다.
- **확정 전에 그린 것**: 서버가 확정하기 전에 미리 그린 연출(적중 불꽃, 피해 숫자, 비기의 발동 문양)은 번복되면 0.1초에 걸쳐 흐려진다. 피격 연출과 비기의 발동 소리는 확정된 뒤에 낸다. 한 번 낸 소리는 끊지 않는다. 확정까지의 길이와 방식은 `online.md`가 정한다.
- 환경과 처치의 입자 몫은 쓰지 않고, 상대의 비기가 내 비기와 같은 몫(400)을 따로 받는다(9.3절).
- 번쩍과 흔들림은 양쪽 화면에서 각자의 설정을 따른다. 판정과 무관하다.
- 서버 전체 알림은 결투 중에 뜨지 않는다(8절).

## 20. 만들어야 하는 효과 에셋

크기는 1칸 64px 기준의 px다(기준 화면 1920×1080에서 그림 1픽셀 = 화면 1픽셀). "×5"는 속성별 5벌이다. "셰이더"와 "입자"는 그림을 그리지 않고 코드로 만든다. 지팡이의 단계별 그림(손 그림, 큰 그림 192×192, 목록 아이콘 64×64)은 각 지팡이 문서에, 적의 그림은 `monsters.md` 9절에 있다.

효과 그림(마법진, 빛기둥, 조각, 불꽃, 탄, 비기, 예고)은 이 절이 주인이다. 비고에 "1배"라고 적힌 화면 요소(틀, 글꼴, 칸, 아이콘, 알림 띠)도 연출의 시간표와 배치가 크기를 정하므로 이 절이 크기·프레임·장수를 갖는다. `docs/ui-assets.md`는 0절·5절의 가리키는 표로 이 값을 인용만 하고 장수를 세지 않는다. 그 밖의 화면 그림은 `ui-assets.md`가 주인이다.

이 절이 갖는 화면 요소를 표별로 적으면 이렇다(`ui-assets.md` 0절의 경계와 같다).

| 표 | 이 절이 갖는 화면 요소 |
|---|---|
| 20.1절 | 비고가 "1배"인 것 전부: 제물 칸 틀, 부적 칸 틀, 단계 숫자 글꼴, 화면 균열, 기운 칸, 변이 카드 틀, 변이 아이콘 6종, 칭호 띠(의식용), +13 화면 위 빛띠, 결과 카드 틀, 강화 화면 배경, 흔적 가림 아이콘, 지팡이 고르기 화살표 |
| 20.2절 | 알림 띠, 한 줄 소식 틀 |
| 20.3절 | 체력 칸, 결정(빔, 참, 빚, 금 감), 콤보 숫자 글꼴, 피해 숫자 글꼴, 속성 문양 16×16 |
| 20.4절 | 기술 이름 띠, 발동 문양 고리, 저스트 별 |

- 이 절의 표에 없는 화면 그림은 `ui-assets.md`가 갖는다. 강화 화면의 큰 확률 숫자 글꼴(숫자 높이 128px, `ui-assets.md`의 F-N3)이 그 예다.
- 캐릭터 그림(강화 반응, 서기), 광장의 느루와 흔들의자, 알림 까마귀와 쪽지, 광장 시설의 그림은 `world-characters.md` 10절이 주인이다. 이 절의 표에 그 그림이 나오면 비고에 주인을 적고 장수를 세지 않는다. 강화 화면의 배경(작업대)과 그 구석의 작은 느루(64×64)는 이 절의 것이다(20.1절).

## 22. 개발자 확인 필요

취향이나 방향의 문제만 남겼다. 각 항목의 "지금"이 본문에 적용된 값이다.

1. **가짜 실패의 범위.** 지금: 대성공은 **항상** 실패처럼 시작한다(3.2절). 그래서 진짜 실패의 첫 0.5초에도 "혹시?"가 남는다. 대성공 중 일부만 그렇게 시작하게 하고 싶다면 3.2절의 0.00~0.50 구간을 그 비율로만 쓰면 된다.
2. **하락 흔적 공개의 기본값.** 지금: 끔(비공개). 주인이 지팡이마다 켤 수 있고 거래에서는 항상 보인다(1.3절). 기본을 "켬"으로 하면 광장에서 실패 이력이 기본으로 드러난다.
3. **임계의 색.** 지금: 금색을 버리고 흰색·검정의 이중 테와 쐐기로 했다(0.1절). 임계와 엘리트와 화염·번개를 가르기 위해서다. "임계는 금색"이라는 느낌을 꼭 남기고 싶다면 열 링과 피해 숫자에만 금색을 되돌리고 탄에는 지금의 표식을 두는 절충이 가능하다(그 경우 엘리트의 금색과는 다시 겹친다).
4. **마일스톤 단계.** 지금: 칭호가 바뀌는 +4, +7, +10, +13(3.7절).
5. **+10 이상의 빠른 강화.** 지금: 빠른 강화를 켜도 +10 이상 도전은 전체 의식이 기본이고 설정에서 풀 수 있다(7절).
6. **캐릭터 목소리.** 지금: 대사는 글자로 띄우고 소리는 캐릭터별 짧은 소리 표식만 쓴다(19.1절 E-36).
7. **허상과의 첫 만남의 연출(15.1절).** 지금: 끝까지 버틴 사람에게 나오는 마무리 "되비침" 3초와 쓰러짐 4초는 건너뛸 수 없고, 마무리에는 빨강이 차오르는 예고를 그리지 않는다(피할 수 없는 장면이라서). 쓰러짐에서는 사망 문구 대신 느루의 한마디(자리표시 문구)가 뜬다. 길이를 줄이거나 건너뛸 수 있게 할 수도 있다.
