# 06. 보스 — 구현용 명세서

영역: 보스 공통 규칙, 보스 6종, 스승의 허상 첫 만남과 복수, 격노.

- 원본: `docs/monsters.md` 3.2~3.9절(본문), 같은 문서 1.2절·2.6절·4.2절·4.3절·4.7절·4.8절·5.3절·5.4절·6절·7절·8절·9.3절·10절(교차 확인), `docs/effects.md` 15절(규칙과 수치만), `docs/online.md` 3.2절(허상 정산 규칙)과 7.9절(데이터 모델), `docs/world-characters.md` 0절·3.6절, `docs/GDD.md` 8절·11절.
- 우선순위: `docs/DECISIONS.md` > 이 명세가 옮긴 원본. 이 명세와 원본이 다르면 원본을, 원본끼리 다르면 15절 "충돌"의 선택을 따른다.
- 이 명세는 그림·이펙트·소리를 구현하지 않는다. 붙일 자리(이벤트 이름)만 17절에 둔다.
- 일정·범위 삭감은 다루지 않는다(DECISIONS 1.16). 구현 순서는 0.5절에 의존 관계로만 적는다.

### 0.2 단위와 환산 [조율]

- 길이: 칸(1칸 = 64px). 판정 수치는 칸 단위다 (D 2.1, M 머리말) [확정].
- 시간: 결정론 코어는 고정 60틱이다 (O 3.1) [확정]. **1초 = 60틱, 1틱 = 16.667ms.** 이 명세의 모든 초 값 옆에 틱 값을 적는다. 정확히 나누어떨어지지 않는 값은 [임시] 반올림 규칙(가장 가까운 정수, .5는 올림)을 따르고 그 자리에 표시했다.
- 수: 코어는 고정소수점 Q32.32 정수를 쓴다 (O 3.1) [확정]. 칸 값 `x`의 원시값은 `x × 2^32`. 속도(칸/초) `v`의 틱당 원시값은 `floor(v × 2^32 / 60)` [임시].
- 각도: [임시] 정수 밀리도(1° = 1000 mdeg). 이 문서의 각도(11.25°, 20°, 22.5° …)가 모두 정수로 떨어진다. 삼각함수는 결정론 표(정수 조회표)를 쓴다.
- 비율(%): 정수 백분율 또는 만분율로 든다. 체력 비율 비교는 나눗셈 없이 `hp × 100 ≤ hp_max × pct`로 한다 [임시].
- 난수: 판 씨앗에서 갈라 낸 PCG 계열 난수기만 쓴다 (O 3.1, M 7) [확정]. 보스용 난수기는 `rng.boss`로 갈라 낸다 [임시].
- 히트스톱, 느린 연출, 화면 흔들림은 표시 계층의 일이고 게임 시간은 멈추지 않는다 (M 7, O 3.1) [확정]. 단, 보스 등장 1.2초와 단계 전환 0.6초는 코어의 상태로 다룬다(2.9절, 2.10절).

### 0.3 낱말

| 낱말 | 뜻 |
|---|---|
| 프로필 | 서버 프로필(= 계정)과 기기 안의 오프라인 프로필 각각. 둘은 섞이지 않는다 (D 2.6, M 3.9) [확정] |
| 넘긴다 | 그 웨이브의 적을 전멸시켰다(보스 웨이브는 보스를 잡았다). 첫 만남의 웨이브 10은 예외로 "넘긴 것"으로 센다 (M 6 머리말, M 3.9.3) |
| N일째, `d` | `ceil(w ÷ 10)` (M 4.1, M 6) [확정] |
| 2회차 | 보스 순환의 두 번째 바퀴 이상(웨이브 70 이상) (M 3.2) |
| 예고 문법 | 예고 구역은 빨강이 차오른 뒤 흰색으로 번쩍하고 판정이 나온다 (M 1.1) [확정] |
| 스침 | 스쳐 피하기. 대상은 적의 탄, 돌진, 예고 구역이 터지는 순간 경계 바깥 0.6칸 이내 (M 1.1) [확정] |
| V | 기준 속도 = 가장 느린 캐릭터의 자세 속도 = 3.76칸/초. 서리밭 위 2.63 (M 1.2) |
| R1~R5 | 회피 보장 규칙 (M 1.2). 2.13절에 옮겼다 |
| `S(w)` | 웨이브 계수 `1 + 0.1 × (w − 1)`. 정수로는 `S10(w) = 9 + w` (M 4.8) |
| `H(w)` | 체력 배율. w ≤ 12: `1 + 0.12 × (w − 1)`, w ≥ 13: `2.32 × 1.06^(w − 12)` (M 4.2) [w ≤ 12 부분은 GDD 유지] |

### 0.4 이 명세가 정하지 않는 것(다른 명세의 몫)

일반 적·엘리트의 행동, R5 안전 경로 탐색기의 내부, 주문 컴파일러 `Execute`, 플레이어의 열·콤보·결정·비기 판정, 점수 전체 식, 드랍 표 전체, 정산 서버 API, 화면 배치. 이 명세는 그것들을 **부르는 쪽**의 계약만 적는다.

### 0.5 구현 순서(의존 관계)

1. 결정론 코어의 틱·고정소수점·난수기, 예고 구역(모양 5종)과 R5 검사기, 적 탄과 스침 판정, 꼬리표 반응표 (다른 명세).
2. 보스 공통 틀: `BossDef`/`PatternDef` 데이터 읽기, 보스 웨이브 진입(2.1), 체력 배율(2.2), 상태 기계(2.8), 패턴 고르기(2.11), 격노(2.12), 피해 성장(2.7), 처치 보상 기회 기록(2.15).
3. 보스 6종(3~8절). 서로 독립. 허상(4절)은 `Execute` 복사가 필요하므로 주문 컴파일러 뒤.
4. 첫 만남(9절): 허상(4절) + 보스 공통 + 플레이어 사망 처리 가로채기.
5. 복수(10절)와 추적기(11절): 첫 만남 + 정산(13절).
6. 서버 정산 규칙(13절): 판 제출·검증 파이프라인 뒤.

### 1.2 열거형

```csharp
enum Element { None, Fire, Lightning, Arcane, Frost, Dark }
enum BossTag { Boss, Root, Flying, Burrowed }        // 보스는 항상 Boss. 나머지는 상태에 따라 붙고 떨어진다

```

## 2. 보스 공통 규칙

### 2.1 보스 웨이브와 순환 [확정: 10웨이브마다, 순서대로 (D 2.3)]

- 하루의 열 번째 웨이브(w % 10 == 0)는 보스 웨이브다. 여섯 보스가 정해진 순서로 돌아온다 (M 3.2) [확정].

| 웨이브 | 보스 | 속성 | 약점 | 저항 | 출처 |
|---|---|---|---|---|---|
| 10 (그 프로필이 처음 닿는 한 번만) | 스승의 허상 — 첫 만남. 이길 수 없다 | 비전 | 암흑 | 비전 | M 3.2 [확정: D 1.21] |
| 10 (그 뒤의 모든 판), 70, 130 … | 가마등 | 화염 | 냉기 | 화염 | M 3.2 [제안] |
| 20, 80, 140 … | 스승의 허상. 웨이브 20의 첫 승리가 "복수" | 비전 | 암흑 | 비전 | M 3.2 [확정: D 1.21] |
| 30, 90, 150 … | 천 갓 | 없음 | 화염 | 번개 | M 3.2 [제안] |
| 40, 100, 160 … | 밤눈 | 번개 | 비전 | 번개 | M 3.2 [제안] |
| 50, 110, 170 … | 흰뿔 | 냉기 | 번개 | 냉기 | M 3.2 [제안] |
| 60, 120, 180 … | 밤삼킴 | 암흑 | 번개 | 암흑 | M 3.2 [제안] |

알고리즘:

```
BossKind SelectBoss(int w, RunInfo run):
    assert w % 10 == 0
    k = w / 10                          // 1, 2, 3, ...
    if k == 1 && run.phantomFirst:      // 프로필의 첫 웨이브 10
        return MasterPhantom with mode = FirstEncounter
    idx = (k - 1) % 6                   // 0..5
    return ROTATION[idx] with mode = Normal   // [BoarKiln, MasterPhantom, SporeQueen, StormOwl, FrostGoat, StarSerpent]

int Cycle(int w) = (w/10 - 1) / 6 + 1   // 정수 나눗셈. w=10..60 → 1, 70..120 → 2
```

- 보스 웨이브에는 일반 적 예산이 없다. 보스가 부르는 졸개만 나온다 (M 3.2, M 4.3) [제안]. 엘리트 없음 (M 4.3), 변덕 없음 (M 4.5, G 11) [제안].
- 보스 웨이브 바닥: 밤 바닥 그대로 + 전장 가운데 달빛 원(판정 없음) (M 4.1, M 9.6) [제안]. 밝은 림 세기 60% (M 1.4) [제안].
- 전장 24×14칸, 사방이 막혀 있다 (D 2.3) [확정].

### 2.2 보스 체력 [제안]

- `보스 체력 = 기본 체력 × H(웨이브) ÷ H(10)`. 웨이브 10에서 배율 1 (M 3.2).
- `H(10) = 2.08`, `H(20) ≈ 3.70` (M 4.2 표).
- 정수 계산 [임시]: `Hq(w)`를 Q32.32로 아래처럼 만들고 `hpMax = floor(baseHp × Hq(w) / Hq(10))`.

```
long Hq(int w):                         // Q32.32, ONE = 1L << 32
    if w <= 12: return ONE + (ONE * 12 * (w - 1)) / 100
    h = (ONE * 232) / 100
    repeat (w - 12) times: h = (h * 106) / 100   // 매 단계 내림
    return h
```

- 이 정수 식은 원문 실수 식과 아래 웨이브 전부에서 정수부가 같다(14.2절 테스트 벡터).
- 원문의 대안: 허상만 `H(w) ÷ H(20)`을 쓰면 웨이브 20의 허상이 4000으로 고정된다. QA에서 정한다 (M 10 보충) [제안]. 데이터 필드 `hpScaleAnchorWave`(기본 10, 허상 대안 20)로 바꿀 수 있게 둔다 [임시].
- 첫 만남의 허상: 웨이브 10의 배율 1이라 4000 (M 3.9.2, M 10) [제안].

### 2.3 꼬리표와 반응 [제안 / 기준은 W 3.6]

- 보스는 꼬리표 "보스"를 갖는다 (M 2.6). 졸개(갓버섯 새싹, 허상이 부르는 슬라임)는 꼬리표 없음 (M 2.6).
- 보스는 넉백과 기절에 면역이다. ⑨ 뇌광창의 기절(일반 1초)은 **0.3초(18틱) 동작 멈춤**으로 바꿔 적용한다 (M 3.2, W 3.6, G 8) [확정: G 8의 보스 예외].
- 꼬리표 "보스"의 반응표 (W 3.6):

| 효과 | 보스에게 |
|---|---|
| ② 반동 사격 넉백 2칸 | 없음 |
| ⑨ 뇌광창 기절 1초 | 0.3초 동작 멈춤 |
| 끓어넘침 넉백 2칸 | 없음 |
| 불가마 감속 −20% | −10% |
| 피뢰침 벼락 1T | 그대로 |
| 벼락 질주 경직 0.6초 | 없음 |
| 살얼음 빙결 1.0초 | 감속 −15% 1.0초 |
| 얼음 병풍 | 닿으면 부숨(경직 없이 계속 달린다) |
| 그림자 손 당김 3칸, 경직 0.5초 | 없음 |
| 피해 | 누구에게나 그대로 |

- 감속끼리는 더하지 않고 가장 큰 값 하나만 적용 (W 3.6, G 10.3) [확정].
- ② 반동 사격의 "돌진 예고 취소"는 보스의 돌진에 듣지 않는다 (M 2.6, W 3.6) [확정].
- 보스의 돌진(가마등 삼연 돌진, 밤눈 활강, 흰뿔 뿔 돌진, 밤삼킴 또아리 뒤 무는 돌진)은 설치 벽(얼음 병풍 등)을 경직 없이 부수고 계속 달린다. 설치 벽은 전장의 벽이 아니므로 가마등이 부딪혀도 기절하지 않는다 (M 2.6) [제안].
- 밤눈의 활강은 비행 꼬리표가 있어도 땅 높이로 내려오는 돌진이라 설치 벽을 넘지 않고 부딪힌다. 활강하지 않을 때의 밤눈은 비행 이동이라 얼음 병풍을 넘는다 (M 2.6, W 3.6) [제안].
- 포물선으로 날아가는 것(가마등의 낙석)은 설치 벽을 넘어간다. 직선 탄은 막힌다 (M 2.6) [제안].
- 비행하는 적도 바닥 지대(불가마 등)의 피해와 감속을 받는다. 그림자가 판정 위치다 (M 2.6) [제안].
- 땅속의 적은 피해도 효과도 받지 않는다(밤삼킴은 잠행 패턴 동안만) (M 2.6, W 3.6) [제안]. 살얼음 적중 횟수는 지워지지 않는다 (W 3.6).
- 빙결 내성: 한 번 언 적은 6초 동안 다시 얼지 않는다 (M 2.6). 보스는 얼지 않으므로(감속으로 바뀜) 이 규칙의 영향이 없다 [임시: 감속 −15%는 6초 내성과 무관하게 매번 건다].

`actionHalt` 처리 [임시]:

```
OnStunApplied(boss):                   // ⑨ 뇌광창 적중
    boss.actionHaltTicks = max(boss.actionHaltTicks, 18)
TickBoss():
    if boss.actionHaltTicks > 0:
        boss.actionHaltTicks--
        // 이동, 패턴 타이머(예고 진행, 대기, 빈틈 포함)를 이 틱 동안 멈춘다
        // 이미 발사된 탄, 이미 깔린 구역, 진행 중인 돌진 이동은 멈추지 않는다(돌진 중이면 멈춤을 무시)
        return
```

예고 진행을 멈추면 예고가 길어지는 쪽이라 회피 보장을 깨지 않는다.

### 2.4 보스의 탄과 구역 [제안]

- 보스의 탄은 모두 스쳐 피하기 대상이다 (M 3.2).
- 탄과 구역의 색은 속성과 상관없이 위험색이다 (M 3.2, D 2.2) [확정: 위험색 범위].
- 적 투사체는 화면 전체 150개까지 (M 1.1) [확정]. 상한에 닿으면 새 탄을 만들지 않는다 [임시: 가장 오래된 것을 지우지 않고 새 탄을 생략한다].
- 탄 판정 반지름: 소 0.12칸(16×16), 대 0.18칸(24×24) (M 9.4) [제안]. 플레이어 피격 반지름 0.15 (M 1.2).
- 보스 탄의 피해는 따로 적힌 값이 없으면 1칸 (M 4.2의 "접촉·탄 1") [조율: 15절 C3].
- 접촉 피해는 같은 적에게서 1.5초(90틱)에 1회 (M 1.1) [확정]. 밤삼킴의 머리·마디·꼬리는 "같은 적"이다 [임시].

### 2.5 졸개 [제안]

- 졸개는 점수·골드·드랍이 없다 (M 3.2, M 4.8, M 6.5). 꼬리표 없음, 상성 없음(약점·저항 없음) (M 1.3, M 2.6).
- 졸개 체력에 체력 배율 `H(w)`를 곱하는가는 원문에 없다 → [임시] 곱한다(일반 적과 같은 규칙, M 2.1의 "체력은 4.2절의 체력 배율을 곱한다").
- 보스가 죽으면 남은 졸개는 [임시] 그 틱에 모두 사라진다(점수·드랍 0이므로 결과가 같다). 남은 적 탄은 골드 조각 연출로 바뀌고(표시만, 골드는 보스 처치 골드에 포함) (M 5.4), 남은 예고 구역과 남는 위험 구역은 야영 시작 때 모두 사라진다 (M 4.6).

### 2.6 2회차 [제안]

- 웨이브 70 이상(Cycle ≥ 2)에서 체력 증가 외에 패턴 하나가 강화된다 (M 3.2). 3회차 이상도 같은 강화 하나뿐이다 [임시].

| 보스 | 2회차 강화 | 출처 |
|---|---|---|
| 가마등 | 발구르기 고리가 두 겹(두 번째는 0.5초(30틱) 뒤, 15도 어긋남) | M 3.3 |
| 허상 | 플레이어의 변이도 복사한다(거울상이면 뒤로도 쏜다) | M 3.4 |
| 천 갓 | 포자 구름이 천천히(속도 0.8칸/초 = 0.013333칸/틱) 플레이어 쪽으로 흐른다 | M 3.5 |
| 밤눈 | 낙뢰가 6번 | M 3.6 |
| 흰뿔 | 기둥이 깨질 때 파편이 12방향 | M 3.7 |
| 밤삼킴 | 어둠 침이 5발 | M 3.8 |

### 2.7 피해의 성장과 상한 [제안]

| 구간 | 접촉·탄 | 보스의 예고 공격 | 출처 |
|---|---|---|---|
| 웨이브 1~30 | 1 | 종별 값(1 또는 2) | M 4.2 |
| 웨이브 31~60 | 1 | 종별 값 +1 | M 4.2 |
| 웨이브 61 이상 | 1 | 종별 값 +1 | M 4.2 |

- 최종 격노(2.12절): 보스의 모든 공격 피해 +1칸 (M 3.2).
- **어떤 공격도 한 번에 3칸을 넘지 않는다**(최종 격노의 +1을 더해도 3칸에서 멈춘다) (M 4.2). 이 상한은 공격 쪽 수치에 걸린다. 빚이 있는 그믐이 받는 +1칸은 그 뒤에 더해져 최대 4칸 (M 4.2, W 4.5) [제안].
- 가마등의 접촉 피해 2는 종별 값이다 (M 3.3). 접촉 피해는 웨이브 성장을 받지 않는다 [조율: 15절 C3].

```
int BossHitDamage(PatternDef p, BossRuntime b, bool isTelegraphed, bool isContactOrBullet):
    dmg = p.damage                      // 종별 값. 탄은 따로 없으면 1
    if isTelegraphed && b.wave >= 31: dmg += 1
    if b.finalRage: dmg += 1            // [조율 C4] 접촉·탄 포함
    return min(dmg, 3)
// 플레이어 쪽: 그믐의 빚 +1은 이 값 뒤에 더한다(상한 4)
```

"예고 공격"의 판정: 패턴 표의 "예고" 열이 구역(원·띠·부채꼴·고리)이고 그 구역이 피해를 주는 것. 예고 뒤에 나오는 탄(발구르기 고리 탄, 도약 8방향 탄 등)은 "탄"이라 성장하지 않는다 [임시]. 남는 위험 구역(불씨 띠, 포자 안개)은 "접촉 규칙"이라 적혀 있으므로 접촉으로 본다 (M 3.3, M 3.5) [임시].

### 2.8 보스 상태 기계 [임시: 상태 이름과 전이의 세부. 규칙은 원문]

```
                ┌──────────────┐
  웨이브 시작 ─▶ │ Intro (72틱) │
                └──────┬───────┘
                       ▼
                ┌──────────────┐  패턴 선택(2.11)  ┌───────────┐
           ┌──▶ │   Waiting    │ ─────────────────▶ │ Telegraph │
           │    └──────┬───────┘                    └─────┬─────┘
           │           │ R5 실패                         │ 예고 끝
           │           ▼                                  ▼
           │    ┌──────────────┐                    ┌───────────┐
           │    │  R5Blocked   │                    │  Execute  │
           │    └──────────────┘                    └─────┬─────┘
           │                                              ▼
           │                                        ┌───────────┐
           └──────────────────────────────────────  │ Recovery  │ (빈틈. 없으면 0틱)
                                                    └───────────┘
  어느 상태에서든:
    hp가 다음 단계 경계 이하 ─▶ PhaseTransition (36틱) ─▶ Waiting
    hp == 0 (Normal) ─▶ Dead
    첫 만남 종료 조건 ─▶ 9절의 FirstEncounterEnding
```

| 상태 | 들어가는 조건 | 하는 일 | 나가는 조건 |
|---|---|---|---|
| `Intro` | 보스 웨이브 시작 | 1.2초(72틱) 동안 화면이 멈추고 이름 띠가 나온다. 플레이어는 **무적이고 움직일 수 있다** (M 3.2) [제안]. 보스는 공격하지 않는다. 격노 시계는 돌지 않는다 [임시] | 72틱 경과 → `Waiting` (`fightTicks = 0`) |
| `Waiting` | 등장 끝, 빈틈 끝, 단계 전환 끝 | 이동 AI. 대기 시간(기본 1.5초 = 90틱, 격노로 줄어듦)이 지나면 패턴을 고른다 | 대기 끝 + 패턴 고름 + R5 통과 → `Telegraph` / R5 실패 → `R5Blocked` |
| `R5Blocked` | 고른 패턴의 첫 예고가 R5를 통과하지 못함 | 예고를 시작하지 않고 기다린다 (M 1.2). 3틱마다 다시 검사 [임시] | 통과 → `Telegraph`. 120틱 넘게 막히면 같은 단계의 다른 패턴으로 다시 고른다 [임시] |
| `Telegraph` | | 하위 예고를 차례로 보여 준다. 다음 하위 예고마다 R5 검사(실패하면 그 하위 예고 앞에서 기다린다) | 마지막 하위 예고의 판정 → `Execute` |
| `Execute` | | 판정, 탄 발사, 돌진 이동 등 | 행동 끝 → `Recovery` |
| `Recovery` | | 빈틈. 보스가 공격하지 않는다. 가마등의 기절처럼 받는 피해가 바뀔 수 있다 | `recoveryTicks` 경과 → `Waiting` |
| `PhaseTransition` | `hp × 100 ≤ hpMax × 다음 단계.enterAtHpPct` | 0.6초(36틱) 멈춤, 이 동안 **보스는 공격하지 않는다** (M 5.3) [제안]. 진행 중인 패턴은 중단한다: 아직 판정하지 않은 예고는 지운다, 이미 발사된 탄과 깔린 구역은 그대로 [임시] | 36틱 → `Waiting` |
| `Dead` | `hp == 0`(Normal 모드) | 처치 처리(2.15절) | 웨이브 끝 |

- 단계는 뒤로 가지 않는다. 한 틱에 두 경계를 넘으면 마지막 단계로 바로 가고 전환은 한 번만 한다 [임시].
- `PhaseTransition` 중에도 보스는 피해를 받는다 [임시].
- 첫 만남은 단계 전환이 없다(처음부터 3단계 행동 전부, 9.3절).

### 2.9 등장 [제안]

- 화면이 1.2초(72틱) 멈추고 이름 띠가 나온다. 이 동안 플레이어는 무적이고 움직일 수 있다 (M 3.2).
- 플레이어의 발사 가능 여부는 원문에 없다 → [임시] 이동만 허용하고 발사·비기 입력은 무시한다(보스는 이 동안 피해를 받지 않는다).
- 격노, 최종 격노, 첫 만남 45초의 시계(`fightTicks`)는 등장이 끝난 틱부터 센다 [임시: 15절 C11과 16절].
- 복수 전(Pursuing)의 허상이면 이름 띠에 "복수" 꼬리표가 붙는다 (M 3.9.2, E 15.2) [제안].

### 2.10 단계 전환 표시 [제안]

0.6초 멈춤, 화면 흔들림, 보스의 강조 색이 밝아짐. 이 동안 보스는 공격하지 않는다 (M 5.3). 번쩍은 쓰지 않는다 (E 15). 소리: 포효 (E 15, N-07).

### 2.11 패턴 고르기 [제안]

```
PatternDef ChoosePattern(BossRuntime b):
    list = b.def.phases[b.phase].patternIds
    cand = [p in list where p != b.lastPatternId && Eligible(b, p)]   // Eligible: 보스별 규칙(3~8절)
    if cand.empty:

    if forced != null: return forced
    return cand[b.rngBoss.NextInt(cand.Count)]         // 균등 [임시]

int WaitTicks(BossRuntime b):
    return 90 * (10 - b.rageStacks) / 10               // [임시: 가산식 −10%/스택] 90,81,72,63,54,45
```

- 바위가 놓인 뒤에는 R5가 바위를 벽으로 보고 다음 돌진을 검사한다.
- 바위 장애물의 판정 크기는 원문에 없다 → [임시] 반지름 0.5칸 원(그림 64×64).
- 돌진이 바위를 지나가면 바위가 깨지고 파편 6발(속도 6, 60도 간격, 3칸 지점 3.14칸)이 퍼진다(2단계). 파편 피해 1(탄) [임시].
- 낙석은 포물선이라 설치 벽을 넘는다 (M 2.6).
- 돌진은 매 돌진 예고 시작 틱의 플레이어 위치를 향해 방향을 고정한다 [임시: 대상 = 플레이어 피격 원 중심].

- 마지막이 아닌 돌진이 벽에 닿으면 멈춘다(기절 없음) [임시]. 마지막 돌진만 2.5초 기절, 기절 중 받는 피해 ×1.5.
- 설치 벽은 전장의 벽이 아니므로 부딪혀도 기절하지 않는다 (M 2.6).
- 2회차: 발구르기 고리가 두 겹(두 번째는 0.5초 뒤, 15도 어긋남).
- 공략(참고): 벽을 등지고 유인해 기절시키고 임계 사격. 얼음 송곳이 약점, 화염구는 저항.

### 7.5 서리 숨결을 피하는 길(셋 중 하나는 항상 열려 있다) [제안] (M 3.7)

1. **줄기 사이**: 이어지는 탄 중심 사이가 거리 2칸에서 1.43칸, 4칸에서 1.58칸, 8칸에서 2.09칸(R3 1.0 이상). 쓸어 오는 줄기를 거슬러 탄 사이로 지나간다.
2. **바깥으로 따돌리기**: 줄기가 옆으로 움직이는 속도는 거리 d에서 `d × 0.785`. 달구(3.76)는 4.8칸 안, 갈피(4.25)는 5.4칸 안에서 줄기와 같은 방향으로 걸어 끝까지 따돌린다.
3. **기둥 뒤**: 숨결 전에 기둥이 2개 미만이면 기둥을 먼저 쓴다. 숨결 직전에 뿔 돌진을 고르지 않는다(기둥을 깨고 바로 숨결을 쓰지 못한다).

## 9. 스승의 허상 — 첫 만남 [확정: D 1.21 / 제안: 세부 수치와 절차]

확정된 것은 네 가지 (D 1.21, M 3.9):

1. 첫 보스는 스승의 허상이다.
2. 계정(이 명세에서는 프로필, 15절 C1)이 처음 만나는 허상은 이길 수 없다.
3. 그 싸움에서 쓰러져도 판은 끝나지 않고, 체력을 회복해 다음 웨이브로 간다.
4. 그 뒤 허상은 웨이브 20의 진짜 보스로 나오고, 처음 이기면 "복수" 보상을 받는다.

그 밖의 수치와 절차는 [제안]이다(M 개발자 확인 1번, G 69번).

### 9.1 언제 나오는가 [제안] (M 3.9.1)

| 항목 | 규칙 |
|---|---|
| 조건 | "허상을 만난 적 없음" 표시가 켜진(`phantomMet == false`) 프로필이 일반 판에서 웨이브 10에 닿았을 때. 어느 캐릭터로 닿든 같다. 새 프로필은 표시가 켜진 채로 시작 |
| 횟수 | 프로필마다 한 번. 캐릭터마다가 아니다. 달구로 첫 만남을 치렀으면 초롱의 첫 웨이브 10은 가마등 |
| 표시가 꺼지는 때 | 첫 만남을 끝까지 치르고 웨이브 10을 넘긴 것으로 정산된 판에서 꺼진다 |
| 표시가 남는 때 | 싸움 도중에 판이 비정상으로 끝나면(마지막 중간 지점이 웨이브 5) 표시는 그대로이고, 다음에 웨이브 10에 닿는 판에서 처음부터 다시 치른다. 일시정지 메뉴의 "판 포기"로 싸움 도중에 나가도 같다 |
| 건너뛰기 | 시작 웨이브 고르기는 최고 웨이브 15부터 열리므로 첫 만남 전에 웨이브 10을 건너뛸 수 없다 (M 4.7) |
| 주간 도전 | 첫 만남을 넣지 않는다(`phantomFirst = false`). 주간 도전은 첫 만남을 치른 프로필에만 열린다. 주간 도전 판의 웨이브 10은 언제나 가마등 (M 3.9.1, M 7, O 3.3) |
| 서버 프로필 | 서버가 출발 때 판 정보에 "이 판의 웨이브 10은 첫 만남" 값을 넣는다. 클라이언트가 정할 수 없다. 코어는 이 값으로 웨이브 10을 정하고 재실행 검증도 같은 값(`run.phantom_first`)으로 돈다 (M 3.9.1, M 7, O 3.2) |
| 오프라인 프로필 | 기기의 저장 파일에 같은 표시가 있고 기기가 판 정보에 넣는다. 규칙과 연출은 똑같다 |

### 9.2 첫 만남의 설정 (M 3.9.2) [제안]

허상의 생김새, 복사 규칙, 탄의 수치는 4절 그대로다. **새 공격은 없다.**

| 항목 | 첫 만남의 값 | 웨이브 20의 진짜 허상 |
|---|---|---|
| 등장 | 보스 공통 등장(1.2초 멈춤, 이름 띠 "스승의 허상"). 야영 화면의 다음 웨이브 칸에도 보스 이름이 그대로 뜬다. **이길 수 없다는 것은 미리 알리지 않는다** | 같다. 복수 전이면 이름 띠에 "복수" 꼬리표 |
| 행동 | **처음부터 3단계까지의 행동을 전부 쓴다.** 복사 사격 + ③·④·⑧ 따라 쓰기(**해금과 무관하게 셋 다**. 쓰기 0.8초 전에 머리 위 커맨드 화살표) + 만개 흉내(예고 1.2초, 끝나면 2.0초 빈틈) | 체력에 따라 1 → 2 → 3단계 |
| 격노 | **5스택(최대)으로 시작.** 대기와 연사 간격이 처음부터 가장 짧다. 예고 시간은 줄지 않는다. **최종 격노(180초)는 없다** | 20초마다 1스택 |
| 졸개 | 부르지 않는다 | 30초마다 이끼 슬라임 6마리 |
| 체력 | 4000(웨이브 10의 배율 1). 맞으면 피해 숫자가 뜨고 체력 바가 깎인다. 약점(암흑)과 저항(비전)도 그대로. **체력 바는 50%(2000)에서 멈춘다.** 50%에 닿는 순간 거울에 금이 갔다가 메워지고 마무리로 넘어간다 | `4000 × H(20) ÷ H(10)` ≈ 7,100. 0이 되면 죽는다 |
| 길이 | 싸움은 **최대 45초(2,700틱)** | 제한 없음(최종 격노 180초) |
| 회피 보장 | R1~R5, 탄 사이 1.0칸, 한 번에 3칸 상한을 그대로 지킨다. 공격 하나하나는 피할 수 있다. 이길 수 없는 까닭은 체력 바닥과 시간 제한에 있다 | 같다 |

첫 만남의 패턴 집합 [임시: 4.3절 모델링 적용]:

- 상시: `copy_fire`(간격 = 플레이어 간격 × 2.5 × 0.5, 하한 10틱).
- 패턴: `mimic_art`(③, ④, ⑧ 순환. 같은 기술 연속 금지), `bloom_mimic`. 대기 45틱(1.5초 × 0.5).
- 단계 전환 없음. `phase = 3`으로 시작.

플레이어가 할 수 있는 것: 평소와 전부 같다. 이동, 발사, 자세, 임계 사격, 해금한 비기 전부, 스쳐 피하기. 스치면 콤보와 결정이 평소대로 쌓이고 결정으로 비기를 쓴다. 맞으면 평소대로 체력 1칸을 잃고 1초 무적이다. **연출용 무적이나 약한 탄을 쓰지 않는다**(진 것이 "싸워서 진 것"이 되게) (M 3.9.2) [제안].

### 9.3 체력 바닥 처리 [임시: 절차, 규칙은 M 3.9.2]

```
ApplyDamageToBoss(b, dmg):
    if b.mode == FirstEncounter:
        b.hp = max(b.hpFloor, b.hp - dmg)      // hpFloor = 2000
        b.hpMin = min(b.hpMin, b.hp)
        if b.hp == b.hpFloor && b.firstEnding == null:
            b.firstEnding = Reflection; Emit("phantom_first.mirror_crack")
        return
    b.hp = max(0, b.hp - dmg); b.hpMin = min(b.hpMin, b.hp)
    if b.hp == 0: b.state = Dead
```

- 피해 숫자는 바닥에 걸려 실제로 깎인 양이 아니라 계산된 피해를 그대로 띄운다 [임시].

### 9.4 끝나는 길과 상태 기계 [제안 + 임시: 상태 이름]

### 9.5 마무리 "되비침" (3.0초, 180틱) [제안] (M 3.9.2, E 15.1)

- 입력을 받지 않는다(코어가 정해진 틱 동안 입력을 무시하는 고정 구간. 재실행 검증에서도 같은 결과).
- 남은 적 탄이 사라진다(코어: 진입 틱에 모든 적 탄 제거).
- 허상이 플레이어의 조립으로 만개를 쏘고(그림은 만개 흉내: 8방향, 0.5초 간격 세 번), 플레이어의 체력이 0이 된다. **피할 수 없다.** 공격이 아니라 연출이고 회피 보장 규칙이 적용되지 않는 유일한 장면. **예고 문법을 쓰지 않는다**(빨강이 차오르는 예고를 그리지 않는다).
- 코어에서 이 구간의 탄은 [임시] 실제 충돌 판정 없이 표시용으로만 만들고, 체력은 +114틱(1.90초)에 0으로 만든다(E 15.1의 1.90에 체력 칸이 깨지는 시각). 쓰러짐은 +180틱에 시작한다 (E 15.1).
- 이 구간에는 피격 무적·결정·스침이 쌓이지 않는다 [임시].
- 프로필마다 한 번만 나온다(첫 만남이 한 번이므로).

### 9.6 "쓰러짐" (4.0초, 240틱) [제안] (M 3.9.2, E 15.1)

- 판이 끝나지 않는다. 사망 문구("오늘은 여기까지 위대했다.")와 정산 화면이 나오지 않는다 (E 13.2 사망 줄).
- 싸우다 쓰러졌으면 체력이 0이 된 틱부터, 마무리를 거쳤으면 마무리 180틱이 다 끝난 틱부터 잰다. 연출 내용은 두 경우가 같다.
- 허상이 다가와 내려다보고, 느루의 한마디가 뜨고, 허상이 사라진다.
- 느루의 한마디: 자리표시 문구 `phantom_first.master_line` = 느루: "거울도 못 이기면서 위대하긴." (문구는 나중에 정한다. 이름 표와 같은 문자열 표에 둔다) (M 3.9.2, W 0).
- 입력은 받지 않는다 [임시: E 15.1·ui-assets의 "그동안 입력이 잠겨 있고"].
- 쓰러짐 동안 화면에는 예고도 탄도 없다 (E 15.1).
- 마무리와 쓰러짐은 **건너뛸 수 없다.** 합쳐 7초(180 + 240틱). 일시정지 메뉴도 [임시] 이 동안 열지 않는다.

```
    revengeTrackerShowFirstNote = true    // 일어난 직후 복수 추적기가 처음 나타난다(11절)
```

- 이어서 웨이브가 끝난 것으로 처리한다: 드랍 회수(1.0초), 모닥불, 남은 예고 구역 제거, 전리품 선택(4장 중 2장) → 새벽 야영(전리품 카드, 조립, 비기) → 출발하면 웨이브 11 (M 3.9.2, M 4.6).
- 판의 "체력 0" 종료 판정은 첫 만남 동안 가로챈다. 첫 만남의 쓰러짐은 사망이 아니다(정산 `end_kind`의 "체력 0"이 아니다).

### 9.8 점수와 보상(첫 만남의 웨이브 10) [제안] (M 3.9.3)

## 10. 복수 [확정: D 1.21의 "처음 이기면 복수 보상" / 제안: 세부]

### 10.1 웨이브 20의 허상 (M 3.9.4) [제안]

- 웨이브 20의 허상은 4절 그대로다. 복수 전과 후의 전투 규칙은 같고, 체력은 `4000 × H(20) ÷ H(10)`(약 7,100).
- 복수 전에는 웨이브 20을 건너뛸 수 없다. 20웨이브를 건너뛰려면 최고 웨이브가 29 이상이어야 하고(29 × 0.7 = 20.3), 웨이브 21을 넘겼다면 이미 허상을 잡은 것이다 (M 4.7).
- 이름 띠: 복수 전(Pursuing)이면 "복수" 꼬리표, 그 아래 첫 만남 때 느루의 한마디가 작은 글씨로 1.2초 다시 뜬다 (E 15.2).

### 10.2 지급 조건 [제안]

- 그 프로필이 웨이브 20의 허상을 **처음** 잡으면 그 판의 정산에서 복수 보상을 받는다. 어느 캐릭터로 잡든 같고, 프로필마다 한 번이다.
- 보스를 잡은 뒤 그 판에서 죽어도 받는다.
- 웨이브 20의 보스 처치 보상(골드 580, 카드 5장, 표 6.3-C 2일째 줄)은 평소대로 따로 받는다.
- 같은 판에서 첫 만남(웨이브 10)과 복수(웨이브 20)가 함께 일어날 수 있다(첫 판에 웨이브 20까지 간 경우) [임시: 원문이 막지 않으므로 허용].
- 코어는 전투 중 "이 판에서 허상(복수 전)을 잡았다" 기회(`revengeKillTick`)만 기록한다. 보상 지급은 정산이 한다 [임시].

```
OnBossKilled(b, run):
    if b.def.id == boss.master_phantom && b.mode == Normal && run.revengePending:
        run.revengeKill = true          // 정산 요약에 싣는다
        Emit("revenge.kill_begin")
```

- 판 정보의 `revengePending`은 출발 때의 상태다. 판 안에서 첫 만남을 치른 경우(출발 때 BeforeMeeting) 첫 만남 뒤부터 `revengePending = true`로 바꾼다 [임시].

## 11. 복수 추적기 [제안] (M 3.9.5)

### 11.1 상태

| 상태 | 조건 | 추적기 |
|---|---|---|
| `BeforeMeeting` (만나기 전) | 새 프로필 | 없다. 첫 만남을 미리 알리지 않는다 |
| `Pursuing` (복수 중) | 첫 만남을 치른 뒤부터 웨이브 20의 허상을 처음 잡을 때까지 | 보인다 |
| `Done` (복수 완료) | 웨이브 20의 허상을 처음 잡은 뒤 | 그 판의 정산에서 "복수 완료"로 한 번 바뀐 뒤 사라진다. 기록 화면에 날짜와 걸린 판 수가 남는다 |

전이:

```
BeforeMeeting --(첫 만남이 든 판이 웨이브 10을 넘긴 것으로 정산)--> Pursuing
Pursuing      --(허상(복수 전) 처치가 든 판의 정산)-------------> Done (서버: 검증 대기)
Done(대기)    --(재실행 검증 실패)-------------------------------> Pursuing (보상 회수)
Pursuing      --(검증 실패)--> 되돌리지 않는다(phantomMet은 다시 켜지 않는다) (O 3.2)
```

- 판 안의 HUD 표시는 정산을 기다리지 않는다: 첫 만남의 일어남 직후 추적기가 처음 나타나고(쪽지), 그 판의 웨이브 11~19에 HUD 한 줄이 보인다 [임시: M 3.9.2의 "일어난 직후 화면에 복수 추적기가 처음 나타난다"].

### 11.2 적는 값

| 줄 | 값 | 계산 [임시 부분 표시] |
|---|---|---|
| 목표 | "복수: 웨이브 20의 스승의 허상을 쓰러뜨려라" (`revenge.tracker.goal`, 이름 "스승의 허상"은 이름 표에서) | 고정 |

## 12. 격노 연출의 규칙 수치 (E 15) [제안]

격노는 "공격"이 아니라 "상태"이므로 **전장 안에서는 위험색을 쓰지 않는다.** 격노는 예고 시간을 줄이지 않으므로 연출도 예고를 가리지 않아야 한다.

| 사건 | 수치(표시 계층에 넘길 값) |
|---|---|
| 스택 +1 | 보스 윤곽의 밝은 림이 0.3초(18틱) 한 번 굵어졌다 돌아온다(2px → 6px). 체력 바 옆 격노 칸 하나 켜짐 |
| 스택 유지 중 | 검은 김이 초당 `2 × 스택`개(5스택 = 초당 10개). 32×48, 4프레임, 검정 `#1B0D1A` + 회색 테. 보스 몸 위(6층)에만, 환경 몫(9.3절)에서 입자. 눈 색은 바꾸지 않는다 |
| 단계 전환 | 짧은 멈춤, 흔들림 대, 강조 색이 밝아짐. 번쩍 없음 |
| 최종 격노 | HUD: 체력 바 테두리 빨강, "최종 격노" 띠 2초(480×64, 3프레임), 화면 가장자리 가는 자홍 테두리(8px, 고정, 깜빡이지 않음, HUD 층) |

첫 만남 연출 규칙(E 15.1)에서 코어·데이터와 닿는 값:

- 등장: 배경음 끊김, 번쩍 없음. 싸움 중 배경음은 타악만.
- 거울 금: 체력 바 50%에서 2프레임 + 되감기, 0.4초(24틱).

## 13. 서버 정산 규칙(허상 관련) [제안] (O 3.2, O 3.3, O 7.9, M 7)

### 13.1 출발

1. 서버가 `run_id`, 씨앗, 지팡이·조립 상태, 시작 웨이브, 코어 버전, **이 판의 웨이브 10이 허상과의 첫 만남인지**(`!account.phantom_met`)를 내려 준다. 클라이언트가 보낸 능력치는 믿지 않는다. 지팡이는 "원정 중"으로 잠긴다.
2. 서버는 이 값을 `run.phantom_first`에 적는다. 재실행 검증은 계정의 지금 표시가 아니라 이 값으로 돈다.
3. 주간 도전 판: `phantom_first = false`. 주간 도전은 `phantom_met == true`인 프로필만 시작할 수 있다. 그 전에는 메뉴에 "첫 밤을 넘기면 열린다".
4. **동시 판 막기**: `phantom_met == false`인 계정은 정산되지 않은 판(진행 중이거나 종료 요약을 내지 못한 판)이 하나라도 있으면 새 판을 시작할 수 없다. 원정 화면이 그 판의 제출이나 [원정 정리]를 먼저 요구한다. (원정 잠금은 지팡이 한 자루에만 걸리고 지팡이 개수 제한이 없으므로, 이 규칙이 없으면 판마다 첫 만남(웨이브 10 확정 통과, 체력 전부 회복, 하급 강화석 1)을 받을 수 있다.)

### 13.2 진행과 종료

- 첫 만남이 든 판은 웨이브 10에서 체력이 0이 되어도 끝난 판이 아니다. 코어가 정해진 틱(쓰러짐 240틱 뒤, 마무리를 거쳤으면 180 + 240틱 뒤)에 체력을 채우고 웨이브 11로 넘어간다.
- 5웨이브마다 중간 지점을 올린다(지급이 아니라 기록). 중간 지점 "웨이브 10" = 웨이브 10을 넘긴 직후의 상태 [임시].

### 13.3 1차 검사(즉시)

- 첫 만남이 든 웨이브 10의 점수(3,648)와 골드(20, 결정 환전 제외)는 고정값으로 확인한다.
- 보스 웨이브의 점수 상한 `(3000+200+240+100+200) × S(w)`, 골드 상한 `200 × S(w) + 20`.

### 13.4 표시 끄기와 복수

| 사건 | 처리 | 검증 실패 시 |
|---|---|---|
| "허상을 만난 적 없음" 끄기(`phantom_met = true`) | 웨이브 10을 넘긴 것으로 정산된 때(정상 종료, 또는 웨이브 10 중간 지점까지 정산한 원정 정리). **정산(1차 검사 통과) 시점**, 재실행 검증을 기다리지 않는다 | 다시 켜지 않는다(보상만 회수) |
| 복수 보상 | 웨이브 20의 허상을 처음 잡은 판의 정산에서 한 번. 칭호, 귀속 머리 장식, 귀속 재료. "검증 대기"로 지급 | 보상과 "복수 완료"(`revenge_done_at`)를 함께 되돌린다 |
| 추적기 값 | `phantom_tries`, `phantom_best_dent`, `revenge_runs`는 재실행 검증을 통과한 판의 것만 계정에 적는다 | 적지 않는다 |

- 정산은 `run_id`당 한 번(멱등 키). 같은 제출이 다시 오면 처음 결과를 돌려준다.
- 판이 끝나는 길: (1) 정상 종료(체력 0 또는 "판 포기") — 첫 만남의 쓰러짐은 체력 0 종료가 아니다, (2) 비정상 종료 → 원정 정리(마지막 중간 지점까지, 중간 지점이 없으면 보상 없이 잠금만), (3) 14일 무소식 → 서버가 (2)와 같이 정리.
- 대기 중인 보상(귀속 재료 포함)은 강화에 쓸 수 있지만 거래·장터·선물에는 못 쓴다(귀속 재료는 원래 못 쓴다).
- 한 계정에 판이 여러 개 동시에 있고(Pursuing 상태는 동시 판 막기 대상이 아니다) 둘 다 허상을 잡은 경우: 복수 보상은 먼저 정산된 판 하나에만 준다(트랜잭션 안에서 `revenge_done_at IS NULL` 확인) [임시]. 먼저 판이 검증 실패로 되돌려져도 나중 판에 소급해 주지 않는다 [임시: 다음에 허상을 잡은 판이 받는다].
