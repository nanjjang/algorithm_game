# 엄청엄청 위대한 마법사 키우기 — 화면 그림 목록 (UI · 화면 에셋)

이 문서는 게임의 모든 화면에 필요한 화면 그림(판, 버튼, 칸, 아이콘, 글꼴, 화면 배경)을 한 목록으로 모은다. 화면마다 무엇이 어디에 몇 px로 놓이는지, 그 화면만을 위해 새로 그려야 하는 그림이 무엇인지 적는다.

- `docs/DECISIONS.md`가 이 문서를 포함한 모든 문서보다 우선한다.
- 기준: 1칸 = 64px, 기준 화면 1920×1080, 그림 1픽셀 = 화면 1픽셀(`DECISIONS.md` 2.1).
- 모든 크기와 좌표는 시작값이다. 이 값으로 먼저 만들고 QA에서 조정한다.
- 범위를 줄이지 않는다. 서버 프로필에서만 열리는 화면, 결제를 붙였을 때만 보이는 재화 그림도 전부 목록에 넣었다.

## 0. 이 문서가 갖는 것과 갖지 않는 것

같은 그림을 두 문서가 세지 않게 경계를 먼저 적는다. 아래 표의 오른쪽 문서가 주인인 그림은 이 문서가 **크기만 인용하고 장수를 세지 않는다**(5절에 가리키는 표가 있다).

| 내용 | 주인 |
|---|---|
| 화면의 판·버튼·칸·테, 메뉴 아이콘, 블록 아이콘 16종, 속성 문양(32px, 64px), 등급 테, 리그 휘장, 비기 아이콘 15종, 재료·부적·재화 아이콘, 글꼴 요건, 화면 배경(타이틀, 메뉴, 결과 등), 머리 위 닉네임 판·칭호 띠·말풍선, 트라이 그림의 부품 | **이 문서** |
| 무엇이 HUD에 있어야 하는가(구성), 조작 키 | `GDD.md` 3절, 13절. 이 문서는 그 구성을 1920×1080에 px로 놓는다 |
| 강화 화면의 구성(세 칸 480 / 960 / 480, 위 띠 80, 아래 띠 160)과 그 안의 연출용 그림(마법진, 제물 칸 틀, 부적 칸 틀, 기운 칸, 결과 카드 틀, 변이 카드 틀, 변이 아이콘 6종, 단계 숫자 글꼴, 흔적 가림 아이콘, 지팡이 고르기 화살표, 칭호 띠(의식용)) | `effects.md` 1.2절, 20.1절 |
| 서버 전체 알림의 띠와 한 줄 소식 틀 | `effects.md` 8절, 20.2절 |
| 전투 HUD 중 연출과 붙은 것(열 링, 체력 칸, 결정 칸, 콤보 숫자 글꼴, 피해 숫자 글꼴, 속성 문양 16×16, 기술 이름 띠, 발동 문양 고리) | `effects.md` 10~13절, 20.3절, 20.4절 |
| 드랍 그림, 변덕 아이콘 8종, 틀 아이콘 5종, 시간대 아이콘 4종, "빌림" 꼬리표, 꾸러미 여는 연출, 엘리트 머리 표식 | `monsters.md` 5.3절, 5.4절, 9.5절 |
| 캐릭터 초상(64×64)과 큰 그림(192×192), 광장·돌마당·전장의 시설과 타일, 느루, 까마귀 | `world-characters.md` 10절 |
| 지팡이 손 그림(32×64), 큰 그림(192×192), 목록 아이콘(64×64), 흔적·변이·슬롯 표식 | `wands/*.md` (규격은 `world-characters.md` 3.3절) |
| 값과 규칙(가격, 수수료, 리그 경계, 귀환 가방 칸수, 확률, 방 옵션의 선택지 등) | `online.md`, `monsters.md`, `GDD.md`. 이 문서는 숫자를 옮겨 적지 않고 그 숫자가 **몇 자리까지 들어가야 하는지**만 칸 크기로 잡는다 |

표기:

- 에셋 표의 "장수"는 그려야 하는 그림 파일의 장수다(상태와 프레임을 모두 센 값). 코드·셰이더·글꼴로 만드는 것은 0이다.
- "9조각"은 네 모서리와 네 변, 가운데를 나눠 늘려 쓰는 틀이다. 원본 한 장이 어떤 크기의 판도 만든다.
- ID의 머리글자: K 공용 부품, I 아이콘, F 글꼴, S 화면 전용 그림.
- **이름은 그림에 넣지 않는다 [DECISIONS 1.25].** 이 문서에 적힌 캐릭터·지팡이·스승·장소의 이름(달구, 그믐, 느루, 한뎃벌, 첫모닥 야영지 …)은 전부 작업용 이름이다. 화면에 찍는 이름은 글꼴로 쓰고, 문자열은 이름 표(`world-characters.md` 0절)에서 id로 읽는다. 지금 캐릭터의 표시 이름은 "제자 1"~"제자 5"다. 이름이 들어가는 칸(캐릭터 카드, 초상 옆, 칭호 띠, 순위 줄, 알림)은 한글 8자까지 들어가는 폭으로 잡아 두었으므로 이름이 바뀌어도 그림을 다시 그리지 않는다. 직접 그리는 글씨는 게임 제목(S-0202)과 "대"(S-0902)뿐이고 둘 다 캐릭터 이름이 아니다.

## 1. 공통 규칙

### 1.1 배율과 격자

| 항목 | 규칙 |
|---|---|
| 화면 | 1920×1080. 화면 그림은 전부 1배(그림 1픽셀 = 화면 1픽셀)로 그린다 |
| 확대 | 키울 때는 정수 배(2배, 3배, 4배)만 쓴다. 보간하지 않는다(점 필터) |
| 격자 | 판과 버튼의 위치·크기는 8px의 배수. 아이콘 안의 여백은 2px 단위 |
| 안전 여백 | 화면 가장자리 48px 안쪽에 글자와 누를 수 있는 것을 둔다. 전투 HUD만 가장자리 16px까지 쓴다 |
| 누를 수 있는 것의 최소 크기 | 32×32px. 목록 줄은 높이 48px 이상 |
| 다른 해상도 | 2560×1440은 여백을 늘리고 그림은 1배, 3840×2160은 전체 2배. 1920보다 작은 창은 전체를 내려 그리지 않고 1920×1080 창을 최소로 둔다 |
| 흔들림 | 화면 그림(HUD와 메뉴)은 화면 흔들림을 받지 않는다(`effects.md` 0.2절) |

### 1.2 화면의 재료와 색

화면의 틀은 "느루가 버린 물건"으로 만든다: 어두운 나무판, 누런 쪽지, 분필 글씨, 놋쇠 못. 금속 광택이나 유리 느낌의 매끈한 틀은 쓰지 않는다.

| 이름 | 색 | 쓰는 곳 |
|---|---|---|
| 먹 | `#12131C` | 판의 바깥 외곽선 2px, 글자 외곽선. 순수 검정은 쓰지 않는다 |
| 나무 어두움 | `#1F2130` | 화면 바탕, 눌린 칸 |
| 나무 | `#2A2D40` | 기본 판 |
| 나무 밝음 | `#3A3F5A` | 판의 윗변 1px, 올림 상태의 테 |
| 회청 | `#8E9AAE` | 보조 글자, 꺼진 선택 괄호, 일반 등급 테의 밝은 면 |
| 분필 흰색 | `#F2EDE0` | 본문 글자, 아이콘의 기본 선 |
| 쪽지 | `#E8DDBF` / 그늘 `#C9BB96` | 밝은 판(우편, 결과 카드, 말풍선) |
| 쪽지 위 글자 | `#2B2A33` | 쪽지 판 위의 글자 |
| 선택 노랑 | `#FFE94A` | 선택 괄호(1.3절) 전용 |
| 금색 | `#FFD24A` | 골드, 영웅 등급, +13, 후계자. `effects.md` 0.1절의 "값진 것" 그대로 |
| 희귀 파랑 | `#4F8CFF` | 희귀 등급 테 |
| 일반 회색 | `#9AA0AE` | 일반 등급 테 |
| 알림 호박색 | `#F2A33A` | 화면의 경고와 오류(경고 삼각, 오류 문구, "크게 손해 보는 거래"). 빨강을 쓰지 않기 위한 색 |
| 좋음 초록 | `#6FD36B` | 접속됨, 준비 완료, 마감 여유 넉넉 |
| 속성색 | `effects.md` 0.1절의 주색·보조색 | 속성 문양, 캐릭터 이름 밑줄, 강화 버튼의 색 입힘 |

지켜야 하는 색 규칙:

- **위험색(빨강 `#FF3B30`, 자홍 `#FF2E88`)은 메뉴와 창에 쓰지 않는다.** HUD에서 위험색이 허용되는 곳은 `effects.md` 0.1절이 적은 세 곳(피격 시 화면 가장자리, 체력 1칸 귀퉁이, 최종 격노 표시)뿐이다. 삭제·포기·신고 같은 "조심할 버튼"은 빨갛게 칠하지 않고 호박색 테 + 경고 삼각으로 표시한다.
- 연두 `#B8F04A`는 폭주 변이 전용이다. 화면에서는 변이 아이콘과 변이 칸에만 쓴다.
- 청록 `#4FE3C1`은 비전 속성 전용이다. "켜짐"이나 "성공"의 일반 표시로 쓰지 않는다.
- 금색은 값진 것에만 쓴다. 보통 버튼의 강조에 금색을 쓰지 않는다.
- 색으로만 구분하지 않는다. 등급은 테의 모양, 속성은 문양, 상태는 아이콘이 같이 알려 준다.

### 1.3 상태 규약

모든 누를 수 있는 것(버튼, 탭, 칸, 목록 줄, 카드)이 같은 규약을 쓴다.

| 상태 | 언제 | 보이는 모습 |
|---|---|---|
| 기본 | 아무 일도 없을 때 | 그린 그대로 |
| 올림 | 마우스가 위에 있을 때(마우스 전용) | 테가 "나무 밝음"으로 한 단계 밝아지고 안쪽에 1px 밝은 선. 선택 괄호는 **붙지 않는다** |
| 선택 | 키보드 커서가 있는 것, 또는 지금 고른 것 | **노란 모서리 괄호**(아래). 마우스로 눌러 고른 것에도 붙는다 |
| 누름 | 누르고 있는 동안 | 그림 전체가 2px 아래로 내려가고 아랫변의 그늘 2px이 사라진다 |
| 켜짐 | 탭·토글·거르기가 켜져 있을 때 | 바탕이 "나무 밝음"으로 차고 아랫변에 분필 흰색 4px 줄 |
| 꺼짐 | 지금 쓸 수 없을 때 | 채도 0, 밝기 60%, 글자는 회청. 커서는 갈 수 있고, 그때 괄호는 회청이며 아래 한 줄에 이유를 적는다("골드가 모자란다" 등) |

**선택 괄호**(`GDD.md` 13절: 선택 표시는 노란 모서리 괄호로 통일):

- 모양: 대상의 네 모서리 바깥에 붙는 ㄱ자 네 개. 선 굵기 4px, 선택 노랑 `#FFE94A`, 바깥에 먹색 2px 테.
- 대상과의 간격: 대상의 가장자리에서 4px 바깥.
- 크기 3종: 작은 것(팔 길이 12px, 한 변 64px 이하의 대상), 보통(20px, 한 변 65~240px), 큰 것(28px, 그보다 큰 카드와 판).
- 커서(지금 가리키는 것)는 0.5초 주기로 2px 벌어졌다 오므라든다(2프레임). 번쩍이지 않는다.
- 이미 고른 것(확정)은 괄호가 멈추고 오른쪽 위 모서리에 확정 체크(K-41)가 붙는다. 커서와 확정이 같은 화면에 함께 있을 수 있다(캐릭터 선택에서 고른 캐릭터와 지금 보는 캐릭터).
- 선택 노랑은 금색·번개 레몬과 색상각이 가깝다. 그래서 색이 아니라 **모양(네 모서리의 ㄱ자 + 먹색 테)** 으로 읽게 하고, 괄호는 화면 그림 층에만 그린다. 전장 안의 적, 탄, 지팡이에는 괄호를 그리지 않는다.
- 한 모서리만 그리고 나머지 셋은 뒤집어 쓴다.

마우스와 키보드가 같이 쓰일 때: 마지막으로 쓴 쪽을 따른다. 키보드를 누르면 올림 표시가 사라지고 괄호가 나타나며, 마우스를 움직이면 괄호는 고른 것에만 남는다.

### 1.4 글꼴

한글 도트 글꼴 한 집안을 쓴다. 아래 요건을 만족하는 글꼴을 고르거나, 고른 글꼴의 빠진 글자를 채워 넣는다.

| 요건 | 내용 |
|---|---|
| 글자 범위 | 현대 한글 완성형 11,172자 **전부**(닉네임과 채팅에 어떤 글자가 올지 모른다. 2,350자만 있는 글꼴은 쓰지 않는다), 한글 자모 낱자(ㄱ~ㅎ, ㅏ~ㅣ. 채팅과 갈피 지팡이의 글자 조각), 영문 대소문자, 숫자, 문장 부호, 기호 `… · — ~ + − × ÷ % ▲ ▼ ◀ ▶ ● ○ ◆ ◇ ★ → ←` |
| 원본 크기 | 12px급과 16px급 두 벌. 각 크기에서 획이 1px로 떨어지는 비트맵 글꼴(윤곽선 글꼴을 작게 줄인 것이 아니다) |
| 숫자 | 폭이 같은 숫자(고정폭). 골드, 점수, 시간이 바뀔 때 자리가 흔들리지 않는다 |
| 사용 조건 | 게임 빌드에 넣어 직접 배포할 수 있고, 상업 이용과 글자 수정이 허용되는 것(SIL OFL 같은 조건). 결제를 나중에 붙이므로 "비상업 전용"은 쓰지 않는다 |
| 그리는 법 | 정수 배로만 키운다. 점 필터, 부드럽게 하기(안티에일리어싱) 끔. 글자 위치는 정수 px에 맞춘다 |
| 아틀라스 | 글자당 여백 1px을 넣어 12px급은 14×14, 16px급은 18×18로 계산하면 11,172자 + 기호가 각각 2048×2048 한 장에 들어간다(한 줄 146자, 113자). 처음부터 전부 구워 둔다 |
| 후보(확인 필요) | 갈무리 계열(12px급), 네오둥근모(16px급). 글자 범위와 사용 조건은 넣기 전에 원문으로 다시 확인한다 |

글자 크기는 여섯 가지만 쓴다. 12px보다 작은 글자는 없다.

| ID | 이름 | 크기 | 만드는 법 | 줄 높이 | 쓰는 곳 |
|---|---|---|---|---|---|
| F-12 | 작은 글 | 12px | 12px급 1배 | 16 | 꼬리표, 수량 숫자, 머리 위 닉네임, HUD의 "지금 K" 줄, 채팅 시각 |
| F-16 | 본문 | 16px | 16px급 1배 | 24 | 본문, 목록, 채팅, 툴팁, 입력 칸 |
| F-24 | 버튼 글 | 24px | 12px급 2배 | 32 | 버튼, 탭, 판의 제목, 거래 최종 확인의 지팡이 정보 |
| F-32 | 제목 | 32px | 16px급 2배 | 40 | 화면 제목, 캐릭터 이름, "N일째 웨이브 M" |
| F-48 | 큰 제목 | 48px | 16px급 3배 | 56 | 결과의 승패, 정산의 기록 줄, 카운트다운 |
| F-64 | 타이틀 글 | 64px | 16px급 4배 | 72 | 결투 시작 화면의 이름, 큰 숫자가 필요한 곳 |

- 글자색은 1.2절의 분필 흰색(어두운 판)과 쪽지 위 글자(밝은 판) 둘이 기본이다.
- 전장 위에 뜨는 글자(머리 위 닉네임, HUD의 글)에는 먹색 1px 외곽선을 코드로 두른다. 외곽선을 포함해 그림 영역을 넘지 않게 줄 높이에 2px 여유가 있다.
- 폭 계산: 한글 한 자 = 글자 크기, 숫자와 영문 한 자 = 글자 크기의 절반.
- 글자가 칸을 넘으면 줄이지 않고 끝을 "…"로 자른다. 전체 글은 툴팁으로 보여 준다.
- 숫자 세 자리마다 쉼표를 찍는다(48,200).

## 3. 아이콘

아이콘은 분필 흰색 선 + 먹색 2px 외곽을 기본으로 하고, 뜻이 색에 걸린 것(속성, 재화, 등급)만 색을 쓴다. 한 아이콘을 여러 크기로 쓸 때는 큰 것을 줄이지 않고 **크기마다 따로 그린다**(24px 이하에서 획이 뭉개지기 때문). 2배로 키워 쓰는 것은 따로 그리지 않는다.

### 3.1 주문 블록 아이콘 16종

블록 16종은 `GDD.md` 10.3절의 표가 기준이다. 아이콘은 세 가지를 한눈에 알려 준다: **종류**(바탕 판의 모양), **속성**(색과 오른쪽 아래의 속성 문양), **등급**(테. K-66~K-68).

| 종류 | 바탕 판 | 블록 |
|---|---|---|
| 투사체 | 둥근 판 | 마력탄, 거대 화염구, 연쇄 번개, 부메랑, 얼음 송곳, 그림자 구체 |
| 제어 | 육각 판 | 2갈래 분열, 3갈래 분열, 적중 시 발동 |
| 변형 | 모서리를 깎은 네모 판 | 벽 튕김, 탄환 크기 2배, 관통 +2, 서리, 유도, 과열 3배, 잠식 |

| 블록 | 속성 | 그림 |
|---|---|---|
| 마력탄 | 비전 | 청록 마름모 탄 하나와 짧은 꼬리 |
| 거대 화염구 | 화염 | 판을 거의 채우는 주황 원, 위로 일렁이는 노랑 꼬리 |
| 연쇄 번개 | 번개 | 점 셋을 잇는 꺾인 레몬 선 |
| 부메랑 | 비전 | 청록 ㄱ자 조각과 돌아오는 굽은 화살 |
| 얼음 송곳 | 냉기 | 비스듬히 놓인 뾰족한 하늘색 육각 조각 |
| 그림자 구체 | 암흑 | 푸른 보라 고리: 밝은 테, 어두운 고리, 밝은 심(전투의 3겹 구조 그대로) |
| 2갈래 분열 | 무 | 한 줄기가 둘로 갈라지는 가지 |
| 3갈래 분열 | 무 | 한 줄기가 셋으로 갈라지는 가지 |
| 적중 시 발동 | 무 | 과녁 점에서 새 화살이 꺾여 나간다. 왼쪽에 여는 묶음표 `{` |

## 6. 파일 이름과 묶음

| 항목 | 규칙 |
|---|---|
| 폴더 | `art/ui/kit/`(K), `art/ui/icon/`(I), `art/ui/font/`(F), `art/ui/screen/<화면 이름>/`(S) |
| 파일 이름 | `<ID 소문자>_<영문 이름>_<폭>x<높이>[_<상태>].png`. 예: `k-20_button_large_48x64_hover.png`, `i-b1_block_fireball_48x48.png` |
| 상태 이름 | `normal`, `hover`, `selected`, `pressed`, `on`, `disabled` |
| 프레임 | 한 파일에 가로로 이어 그린다. 프레임 수는 이름 끝에 `_f4` |
| 9조각 | 원본 한 장 + 모서리 값(px)을 옆의 자료 파일에 적는다 |
| 아틀라스 | 공용 부품과 아이콘은 2048×2048 한 장씩, 화면 전용 그림은 화면별로 묶는다. 1920×1080 배경은 묶지 않는다 |
| 색 입힘 | 분필 흰색으로 그린 그림에 코드로 색을 곱한다. 색을 입히는 그림은 회색 단계만 쓴다 |
| 필터 | 전부 점 필터, 밉맵 없음, 압축 없음 |

## 8. 다른 문서와 맞춰야 하는 것, 개발자 확인 필요

**다른 문서가 맞춰야 하는 것**

지금 남은 것은 없다. 앞서 여기에 적었던 여섯 가지는 모두 주인 문서의 값으로 맞춰졌다.

- 감정표현 8종(I-F10): `online.md` 5.1절의 목록이 기준이고 `world-characters.md` 10.1절도 같은 목록이다.
- 오프라인 프로필의 서버 전용 메뉴: 흐리게 두지 않고 묶어 둔다(`GDD.md` 13절, `online.md` 8.1절, `world-characters.md` 2.5절이 같다. 이 문서 4.4절·4.5절).
- 닉네임 길이: `online.md` 7.3절(2~8자). 이 문서는 한글 8자 폭으로 칸을 잡았다(4.20절).
- 강화 화면의 큰 확률 숫자 글꼴: `effects.md` 20절 머리말이 이 문서의 F-N3으로 적었다.
- 결투 "마감 여유 표시"의 색: `GDD.md` 13절과 `online.md` 4.12절도 초록·노랑·호박색이다(4.9절).
- 귀환 가방의 칸수: `monsters.md` 6.2.4절 하나가 기준이다(4.16절).
- DECISIONS 1.21~1.25를 받아 고친 곳: 가입에 이메일 칸, 이메일 확인 판, 비밀번호 찾기와 다시 정하기, 복구 메일 꺼짐 안내(4.3절. 복구 코드 판은 없앴다. `online.md` 7.3절), 지팡이 목록의 스크롤·정렬·거르기·여러 자루 떠나보내기(4.6절, 4.12절, 4.23절. `online.md` 1.6절), 복수 추적기와 복수 보상 줄, 첫 만남의 대사 판(4.8절, 4.16절, 4.26절. `monsters.md` 3.9절, `effects.md` 15.1절·15.2절), 이름은 이름 표에서 읽는다는 규칙(0절. `world-characters.md` 0절). 새로 그리는 그림은 거울 표식(S-2603) 3장뿐이다.

**개발자 확인 필요**

1. 선택 괄호의 노랑을 `#FFE94A`로 잡았다. 금색 `#FFD24A`(값진 것)과 가깝다. 모양(네 모서리의 ㄱ자 + 먹색 테)으로 구분하게 했는데, 색도 더 벌리고 싶으면 분필 흰색 괄호로 바꿀 수 있다.
2. 화면의 경고와 "조심 버튼"에 빨강을 쓰지 않고 호박색을 썼다. 위험색을 적의 공격 전용으로 지키기 위해서다. 메뉴에서는 빨강을 허용할지.
3. 한글 도트 글꼴의 후보(갈무리 계열, 네오둥근모)를 그대로 쓸지, 제목용 글씨만 직접 그릴지. 지금은 제목 그림(S-0202)과 "대" 글씨(S-0902)만 직접 그리고 나머지는 글꼴이다.
4. 결투의 체력을 칸이 아니라 바(720×32, 100마다 눈금)로 그렸다. 결투 체력이 `100 × 체력 칸`이라 칸으로는 깎이는 양이 보이지 않아서다. 무한 웨이브와 같은 칸 모양을 원하면 칸 하나를 100으로 보고 칸 안이 줄어드는 방식으로 바꿀 수 있다.
5. 별빛(유료 재화) 아이콘을 지금 그려 둘지. 목록에는 넣었고(I-C1~I-C3의 4종 중 1종), 유료 상품이 0개인 동안 화면에는 전혀 나오지 않는다.
6. 복수 추적기를 어디까지 보일지. 지금은 메인 메뉴의 원정 카드, 원정 준비, 야영, 전투 HUD(웨이브 11~19의 한 줄), 정산, 기록 화면이다(4.26절). 전투 HUD의 한 줄은 뺄 수 있다.
7. 지팡이 목록의 모양. 지금은 세로 스크롤 목록에 정렬 넷과 거르기 넷이다(4.12절). 개수 제한이 없어졌으므로 격자(칸 80×80을 여러 열로)로 바꿔 한 화면에 더 많이 보이게 할 수도 있다.
