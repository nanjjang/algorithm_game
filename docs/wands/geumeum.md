# 그믐의 지팡이: 눈 뜬 옹이 지팡이 (+0 ~ +13)

우선 문서: `docs/DECISIONS.md`(이 문서와 다르면 그쪽이 맞다).
참조 문서: `docs/world-characters.md`(그믐 4.5절, 공통 지팡이 그림 규격 3.3절, 색 규칙 2.4절, 돌마당 2.6절), `docs/effects.md`(강화 화면 연출 A부, 속성별 강화 연출 5절, 층 순서 9.1절, 누적 가림 상한 9.2절, 입자 예산 9.3절, 그림자 구체의 탄 13.3절, 암흑 탄 16.2절, 결투 표시 17절, 옵션 18절), `docs/online.md`(강화 비용, 거래, 리그), `docs/ui-assets.md`(살펴보기·거래 화면의 그림과 배치).
이 문서가 정하는 것은 이 지팡이의 14단계 모양과 효과뿐이다. 공통 규격과 수치는 위 문서가 주인이고, 이 문서는 그 값을 그대로 옮기거나 절 번호로 가리킨다.
기준 그림: `art/player/dark_wizard/idle-reference-details.png`. **이 그림의 지팡이가 +0이다** [확정, DECISIONS 2.2].

표기: **[확정]** 은 DECISIONS.md에 있는 것이다. 표시가 없는 단계 이름·모양·색·효과·수치는 이 문서의 제안이고, 수치는 QA에서 조정할 시작값이다.

픽셀 읽는 법 [확정, DECISIONS 2.1]: 1칸 = 64px, 캐릭터 캔버스 64×64. **손에 든 지팡이 캔버스는 32×64px, 강화 화면용 큰 그림은 192×192px**다. 이 문서의 픽셀 수는 전부 이 배율의 실제 픽셀이다. 나머지 그림 규격은 `world-characters.md` 3.3절의 공통 그림 규격을 그대로 쓴다: 손잡이 기준점 (16, 48)(손 위로 48px, 아래로 16px. 이 문서의 치수는 이 점에 맞춰 검산했다), **목록·장터용 아이콘 64×64px**, 방향 3(아래·옆·위), 자세 2(들기, 내밀기), 이웃 단계는 윤곽선에서 4px 이상 차이.

## 1. 설계 생각

이 지팡이는 도구가 아니라 **잠든 눈**이다. 검은 나무 뿌리의 옹이가 손가락처럼 보라 결정을 움켜쥐고 있고, 강화는 그 손을 펴는 일이다. 꽉 쥔 주먹(+0)에서 손끝이 떨어지고(+1), 손이 벌어지고(+2), 결정이 둥근 알이 되어 실눈이 생기고(+3), +4에서 처음으로 눈을 뜬다. 지팡이 이름이 그때 완성된다. 눈을 뜬 지팡이는 쥐고 있던 것을 하나씩 **놓는다.** 막대 끝이 먼저 떨어져 뜨고(+5), 구슬이 손을 떠나고(+10), 머리가 막대를 떠나고(+11), 손가락마저 손바닥을 떠난다(+12). 놓을수록 구슬은 밝아지는 것이 아니라 **어두워진다.** +13에서 구슬은 가운데가 검고 테두리만 빛나는 검은 달, 곧 그믐이 된다. 그 어둠은 그믐의 후드 속 어둠과 같은 색이고, 암흑 주문(어두운 고리)과 같은 모양이다. 말도 얼굴도 없는 소심한 제자가 무엇을 들고 있었는지를, 지팡이가 눈을 뜨고 손을 놓는 과정으로 보여 준다. 그리고 +13이 되어도 주인이 맞으면 눈을 질끈 감는다. 엄청엄청 위대해져도 겁은 그대로다.

### 1.1 이 지팡이만의 성장 문법: 놓아서 띄우고, 빛을 먹는다

다섯 지팡이가 높은 단계에서 "색만 다른 같은 물건"이 되지 않도록 지팡이마다 성장 축을 하나씩 나눠 가진다. 그믐의 축은 **떼어 띄우기(부유)와 빛 먹기(어둠)** 다.

| | 내용 |
|---|---|
| 그믐만 쓰는 것 | ① **틈**: 부품이 몸에서 떨어져 뜨고, 그 사이로 뒤가 보인다. 검은 실루엣으로 놓으면 그믐의 지팡이만 **끊어진 덩어리**다. ② **어둠**: 단계가 오를수록 구슬이 어두워진다. 다른 네 지팡이는 머리가 밝아지는데 이 지팡이만 반대다. +13의 머리는 빛나는 덩어리가 아니라 **검은 구멍 + 가는 테**다 |
| 그믐이 쓰지 않는 것 | 둘레를 도는 조각(공전은 성에의 것), 같은 부품의 개수 늘리기와 위로 쌓기(초롱의 것), 옆으로 펼치는 낱장·깃발(갈피의 것), 굵어지고 녹아 흐르는 덩어리(달구의 것), 길이로 자라기(성에의 것). 전체 높이가 느는 것은 틈이 벌어진 만큼뿐이고 막대 자체는 길어지지 않는다 |
| 앞 원고에서 바꾼 것 | 곁구슬(작은 구슬이 늘어나 머리 둘레를 도는 것)과 도는 고리를 모두 뺐다. 개수와 공전이 다른 지팡이의 축과 겹치기 때문이다. 결정 수 표시는 +13의 발밑 별이 맡는다(4.2절) |

### 1.2 한 물건으로 읽히게 하는 고정 요소

| 고정 요소 | 내용 |
|---|---|
| 굽은 막대 | 아래로 갈수록 캐릭터 쪽으로 휘는 막대. 14단계 내내 휘어 있다 |
| 금테 | 머리 바로 아래의 금색 띠. 어떤 단계에서도 없어지지 않는다. 어두운 바닥에서 지팡이 머리의 위치를 알려 주는 점이다 |
| 구슬 하나 | 구슬은 언제나 1개다 |
| 한 단계에 한 가지 | 각 단계는 앞 단계에서 **한 부위를 바꾸거나 한 조각을 떼어 낸 것**이다. 그래서 하락은 "마지막에 바뀐 것이 되돌아가는 것"으로 그릴 수 있다(5.2절) |

## 2. 기준 그림에서 잰 것

기준 그림(64×64)의 지팡이 부분을 픽셀로 잰 결과다.

- 위치와 크기: 지팡이 전체가 x 41~56, y 21~59, 곧 **16×39px**(외곽선 포함)이다. 머리(결정과 옹이 손가락)는 x 47~56, y 21~34의 10×14 덩어리, 금테는 y 35~36에 폭 3px, 손은 y 41~46, 막대 아래 끝은 (42, 59)다. 32×64 캔버스에 여유 있게 들어간다.
- 모양: 머리는 둥근 구슬이 아니라 **위가 뾰족한 보라 결정**(폭 4, 높이 8)이다. 옹이 손가락 둘이 좌우에서 결정을 쥐고 있다.
- 색(실측, 가장자리 번짐을 묶은 대표값):

| 부위 | 색 | 색상각 / 채도 / 명도 |
|---|---|---|
| 외곽선 | `#1B0D1A` | 304° / 52% / 11% |
| 나무 | `#774A5A` | 339° / 38% / 47% |
| 나무 그늘 | `#3F1F2C` | 336° / 51% / 25% |
| 금 | `#F2C268` (그늘 `#CA8F44`) | 39° / 57% / 95% |
| 결정 | `#9B45DE` | 274° / 69% / 87% |
| 결정 그늘 | `#7230A6` | 274° / 71% / 65% |
| 결정 빛 | `#D58CF9` | 280° / 44% / 98% |
| 반짝임 | `#FDF6FF` | — |

- 원본은 가장자리 번짐 때문에 색이 수백 가지이고 알파가 섞여 있다. 게임에 넣을 때는 위 값으로 묶고 알파를 0/255로 정리한다(그믐 전체 16색 이하, DECISIONS 2.2).
- 지금 그림은 몸과 지팡이가 한 장이다. 지팡이를 14가지로 바꾸려면 **지팡이를 몸에서 떼어 따로 그린 층**으로 만들어야 한다. 몸 그림에서는 지팡이를 지우고 손 소켓만 남긴다(`world-characters.md`의 그림 목록에 올라가는 작업).

### 2.1 나무색과 위험색 규칙

위험색은 "색상각 330~15°이면서 채도 70% 이상, 명도 70% 이상"이다 [확정, DECISIONS 2.2]. 나무색 `#774A5A`는 색상각만 범위 안이고 채도 38%·명도 47%라 **위험색이 아니다.** 같은 절이 허용한 "탁하고 어두운 자주색"에 해당한다. 그래서 색을 옮기지 않고 원본 나무색을 그대로 쓴다. 지키는 선은 하나다: **이 지팡이의 어떤 색도 색상각 330~15° 안에서 채도 70%와 명도 70%를 동시에 넘지 않는다.** 나무에 밝은 하이라이트를 넣을 때는 금색이나 연보라로 넣고 나무색을 밝히지 않는다.

결정의 색들(274~280°)은 범위 밖이라 제한이 없다.

## 3. 색

### 3.1 몸 색 이름표

| 기호 | 색 | 쓰임 |
|---|---|---|
| K | `#1B0D1A` | 외곽선. +9부터는 구슬 속 어둠으로도 쓴다(후드 속 어둠과 같은 색) |
| W1 | `#3F1F2C` | 나무 그늘 |
| W2 | `#774A5A` | 나무 |
| B1 | `#241A38` | 검은 뿌리 |
| B2 | `#5A4C8C` | 검은 뿌리의 빛 받는 면 |
| G | `#F2C268` | 금테, 금 가락지, 초승달 장식 |
| O1 | `#7230A6` | 깊은 구슬 |
| O2 | `#9B45DE` | 구슬 |
| O3 | `#D58CF9` | 구슬의 빛 |
| E1 | `#8A5CFF` | 푸른 보라 (암흑 주문 주색) |
| E2 | `#D9C7FF` | 연보라 (암흑 주문 보조색) |
| H | `#FDF6FF` | 흰 연보라 테 (+13) |

### 3.2 색 규칙

- **몸은 단계마다 6색 이하**(외곽선 포함). 단계별 6색은 4.1절 표에 적는다.
- **효과 층은 따로 센다.** 눈동자 빛, 반짝임, 입자처럼 움직이거나 빛나는 것은 몸 그림 위의 효과 층에 그리고, 색은 E1·E2·H 세 가지만 쓴다.
- 위험색(2.1절)은 몸에도 효과에도 쓰지 않는다.
- 어두운 바닥에서 보이게: 어느 단계든 명도 85% 이상인 색이 몸에 2개 이상 있어야 한다(G와 O3·E2·H 중 하나). 막대는 빛 받는 쪽 2px 줄을 명도 45% 이상으로 둔다. 검은 뿌리(B1)만으로 된 줄은 만들지 않는다. 밝은 테두리 셰이더(`world-characters.md` 2.4절 규칙 5, `effects.md` 16.1절)는 캐릭터와 똑같이 지팡이에도 걸리고, **떠 있는 조각마다 따로** 걸린다. 구슬이 어두워질수록 이 테두리와 금테가 머리 위치를 알려 준다.
- 구슬의 밝기는 그믐의 눈빛과 같이 움직인다. 가진 결정이 0개면 효과 층 밝기 60%, 7개면 100%(패시브 "그림자 계약"의 표시).

### 3.3 구슬 색의 흐름

끝은 원본대로 **보라 결정에서 시작한다** [확정, DECISIONS 2.2]. 그 뒤는 빛 먹기 축을 따른다.

| 구간 | 구슬 |
|---|---|
| +0 ~ +2 | 밝은 보라 결정 (O2 + O3) |
| +3 ~ +6 | 둥근 보라 구슬, 눈의 빛은 연보라 (O2 + E2) |
| +7 ~ +8 | 깊은 보라로 가라앉는다 (O1). 구슬이 테보다 어둡다 |
| +9 | 가운데가 어둠(K), 앞쪽 반만 보라 |
| +10 ~ +12 | 어두운 중심 + 푸른 보라 테 (K + E1) |
| +13 | 검은 달: 검은 원반 + 흰 연보라 테 (K + H) |

## 4. 단계표

표가 넓어서 둘로 나눴다. 4.1은 모양과 색, 4.2는 효과와 소리다. ★는 큰 변화 단계다(4.3절).

### 4.1 모양과 색

"한눈에"는 손에 든 크기에서 그 단계를 알아보게 하는 한 가지다. "손"의 치수는 32×64 캔버스 안의 실제 픽셀(머리 가로×세로, 지팡이 전체 높이)이고, "큰 그림"은 192×192에서만 보이는 세부다.

| 단계 | 별명 | 한눈에 | 모양: 손 (앞 단계에서 바뀌는 것) | 큰 그림에서 더 보이는 것 | 몸 6색 (바뀐 것) |
|---|---|---|---|---|---|
| +0 | 꽉 쥔 옹이 | 닫힌 덩어리 위로 뾰족한 끝 하나 | 머리 10×14, 전체 39. 기준 그림 그대로. 옹이 손가락 둘이 결정을 좌우에서 쥐고, 위로 결정의 뾰족한 끝만 나온다. 금테 한 줄 | 손가락 마디, 나뭇결, 닳은 막대 끝 | K W1 W2 G O2 O3 (원본을 6색으로 정리) |
| +1 | 손끝 뗀 옹이 | 머리 앞쪽으로 갈고리 하나가 삐져나왔다 | 머리 14×14, 전체 39. **앞쪽 손가락이 결정에서 떨어져 바깥으로 4px 꺾인다.** 손가락과 결정 사이에 2px 틈 | 떨어진 손끝과 결정 사이로 새는 빛, 결정 면의 흰 점 | 같음 |
| +2 | 벌어진 옹이 | 머리가 V자로 벌어지고 가운데에 결정이 우뚝 | 머리 18×18, 전체 43. **뒤쪽 손가락도 4px 벌어져 V자가 되고, 결정이 4px 솟아 전체(6×12)가 드러난다.** 금테 두 줄 | 결정 아랫면, 손바닥 안쪽의 결 | 같음 (금 면적 2배) |

| **+4 ★** | 눈 뜬 옹이 | 머리에 가시 셋이 돋았고 눈동자가 이쪽을 본다 | 머리 18×20, 전체 45. **구슬이 12×12로 커지고 눈을 뜬다**(세로 눈동자 빛 2×6). 손가락이 셋이 되어 구슬 위·뒤·아래로 6px씩 속눈썹처럼 뻗는다. 구슬 앞면은 가리는 것 없이 시야 방향을 본다. 막대 위 1/3이 검게 변한다 | 눈동자와 홍채 고리, 눈꺼풀 구실을 하는 손가락, 검은 부분과 나무의 경계에 번지는 결 | K **B1** W2 G O2 E2 (나무 그늘이 푸른 검정으로) |

| 사이 | 달라지는 윤곽 | 부위 |
|---|---|---|
| +0 → +1 | 앞 손가락이 앞으로 4px 튀어나온다 | 머리 앞 |
| +1 → +2 | 뒤 손가락이 뒤로 4px, 결정 꼭대기가 위로 4px | 머리 뒤·위 |
| +2 → +3 | 뾰족한 꼭대기가 4px 낮아지며 둥글어지고, 손가락이 4px 줄어든다 | 머리 위 |
| +3 → +4 | 가시 셋이 6px씩 뻗고 구슬이 2px 커진다 | 머리 전체 |
| +4 → +5 | 막대 아래에 4px 틈이 뚫린다 | 막대 아래 끝 |

| +6 → +7 | 머리 뒤에 20px 높이의 테가 붙어 머리가 4px 넓어지고 2px 높아진다 | 머리 뒤 |
| +7 → +8 | 막대 뒤에 길이 10px 줄기가 나란히 늘어진다 | 막대 가운데 뒤 |

| +9 → +10 | 구슬 아래 4px 틈, 손가락이 세로에서 가로로 눕는다 | 머리 가운데 |
| +10 → +11 | 금테 아래 4px 틈, 그 위 전체가 4px 오른다 | 머리와 막대 사이 |
| +11 → +12 | 손가락 셋이 각각 4px 틈을 두고 떨어져 폭이 4px 는다 | 머리 아래 |
| +12 → +13 | 꼭대기 4px 상승, 구슬 2px 확대, 아래 토막이 가는 줄기로 바뀐다. 색은 밝은 테 구슬에서 검은 구멍으로 뒤집힌다 | 머리 위, 막대 아래 끝 |

색만 바뀌는 단계는 없다. 큰 변화 단계 사이의 두 단계는 서로 **다른 부위**를 건드린다(머리 → 막대 → 머리 순). 같은 부위가 연달아 바뀌면 작은 크기에서 차이가 묻히기 때문이다. 통과 기준은 `world-characters.md` 3.3절의 실루엣 대조표(아래·옆·위 세 방향 각각에서 14단계를 검은 실루엣으로 맞히기)다. "위" 방향에서는 막대가 몸에 가리므로, 머리 쪽 변화가 없는 +5·+6·+8은 위 방향 그림에서 뜬 토막·초승달 장식·그림자 줄기를 몸 옆으로 2px 더 빼서 그린다.

틈 수로 구간을 읽는 법: 틈 없음(+0~+4) / 아래 끝에 하나(+5~+9) / 구슬 밑에 하나 더(+10) / 머리 밑에 하나 더(+11) / 손가락마다(+12~+13).

### 4.2 효과와 소리

"가만히"는 들고 있을 때의 효과, "탄"은 이 지팡이가 그믐의 투사체에 입히는 장식이다. 탄 본체의 색과 모양은 그 탄을 만든 투사체 블록의 속성을 따른다(GDD 4절, `world-characters.md` 2.4절). 그믐이 쏴도 마력탄은 청록 마름모, 거대 화염구는 주황 화염구, 연쇄 번개는 레몬 꺾인 선이다. 암흑 블록(그림자 구체)의 탄만 암흑 탄의 세 겹(바깥 연보라 테 + 어두운 고리 + 한가운데 밝은 심)이다. 세 겹의 색과 굵기는 `effects.md` 16.2절이 기준이고(16×16 탄 기준 테 2px `#D9C7FF`, 고리 2~4px `#2A1A5E`, 심 4×4px `#F1E9FF`. 큰 탄은 테 4px, 심 8×8px), 이 문서는 값을 따로 두지 않는다. 단계는 꼬리·총구 섬광·적중 효과만 바꾼다. 아래 표의 '탄 바깥 테 교체'(+7)와 '탄 교체'(+13)는 암흑 블록의 탄에만 적용하고, 다른 속성 블록의 탄 본체는 건드리지 않는다. **가운데 밝은 심은 어떤 단계에서도 지우지 않는다**(판정 중심 표시). "검은 원반 + 테"만으로 된 탄은 어느 단계에도 없다. 푸른 보라 `#8A5CFF`는 탄의 몸이 아니라 꼬리 띠와 적중 효과에만 쓴다. 꼬리는 입자가 아니라 탄에 붙은 띠 그림 한 장이고, 총구 섬광도 지팡이 끝에 붙는 그림 한 장이다(`effects.md` 9.3절). 이 지팡이는 총구 입자와 탄이 흘리는 입자를 쓰지 않는다. 각 칸은 앞 단계의 것에 **더해지는 것**만 적는다(바뀌는 것은 "교체").

장식이 붙는 방식: 꼬리 띠와 총구 섬광은 어느 속성의 블록을 쏘든 이 지팡이의 색(3.2절의 효과 3색)으로 붙는다. 그믐이 쏜 거대 화염구는 "주황 화염구 + 그림자 꼬리"다. 적중 칸은 블록의 속성 적중 불꽃(`effects.md` 13.1절) **위에 얹는** 지팡이 장식이고, 블록의 적중 불꽃을 지우거나 바꾸지 않는다. 표의 "교체"는 앞 단계의 지팡이 장식을 바꾼다는 뜻이다. 그림자 구체는 `effects.md` 13.3절대로 꼬리가 없는 탄이므로 단계 꼬리 띠도 달지 않는다. 그림자 구체에서는 +7부터의 탄 테 변형이 꼬리 대신 단계를 보여 준다.

| **+10 ★** | **구슬이 뜬다.** 구슬이 3초 주기로 2px 오르내리고, 걸으면 반 박자 늦게 따라온다. 멈추면 한 번 출렁인다. 발밑에 손 모양 그림자(16×8)가 손가락을 꼼지락거린다. **빛 먹기 시작**: 이 지팡이의 대기 입자가 구슬 둘레 8px 안에 들어오면 구슬로 빨려 들어가 꺼진다 | 총구 교체: 바닥의 그림자 손이 튕겨 보내는 동작 6프레임 / 적중 교체: 작은 월식(어두운 고리 16px + 테, 안이 비어 있다) 6프레임 | 발사음 교체: 깊은 "둥" + 긴 잔향. 가만히 있을 때 광장에서만 아주 낮은 지속음 |
| +11 | 뜬 머리가 구슬과 엇박자로 오르내린다(틈 둘이 번갈아 넓어졌다 좁아진다). 그믐이 맞으면 머리가 막대에 "탁" 붙었다가 0.5초 뒤 다시 뜬다 | 꼬리 교체: 가운데가 끊긴 두 토막 띠 / 적중에 연보라 조각 4개가 튄다 | 발사음에 반 박자 늦은 메아리 한 번 |
| +12 | 뜬 손가락 셋이 제각기 느리게 오므렸다 편다(공전하지 않고 제자리에서). 밤 조각 안의 별이 따로따로 깜빡인다 | 탄 3개 중 1개꼴로 꼬리에 별 가루(띠 그림의 2px 깜빡임) / 적중 자리에 별 2개가 든 밤 자국 0.5초(바닥 흔적 층) | 적중음에 높은 유리 "팅" 여러 개가 흩어진다 |
| **+13 ★** | **검은 달.** 테가 숨 쉬듯 밝아졌다 어두워지고 빛살 4개가 제자리에서 길어졌다 짧아진다. 대기 입자는 전부 달 쪽으로 휘어 빨려 들어간다. 금테의 달 쪽 면은 빛이 죽는다. **발밑 둥근 밤**: 지름 1칸의 어두운 원(가장자리가 풀리는 선 고리, 면은 30% 어둠)에 별이 뜨는데, **그믐이 가진 결정 수만큼만 켜진다**(최대 7, 지팡이가 결정 칸을 겸한다). 걸으면 별이 뒤로 흐른다. 맞으면 여전히 눈을 감는다 | 탄 교체(암흑 블록의 탄만): 어두운 고리가 굵어지고 바깥 테가 흰 연보라가 되는 작은 월식(가운데 밝은 심 유지) / 꼬리 교체: 별이 섞인 어둠의 띠 / 총구 교체: 검은 달 섬광 28px + 가는 빛살 6프레임(속이 빈 고리) / 적중 교체: 테가 32px까지 벌어졌다가 한 점으로 오므라듦 8프레임 / 임계 적중: 테가 일곱 조각으로 끊겨 안으로 빨려 든다 / 처치: 적의 그림자가 바닥으로 가라앉음 6프레임 | 발사음 교체: 소리가 아주 짧게 비었다가 낮은 "쿵"이 오는 구성(다른 소리를 줄이지는 않는다). 광장에서는 가까이 가면 낮은 합창 같은 지속음 |

그믐의 눈빛과 맞추는 것: 강화에 성공하면 그믐의 눈이 반달이 되고 실패하면 점이 된다. 지팡이의 눈도 같은 순간 같은 모양을 한다(+4 이상).

탄 본체(단계와 무관)는 블록의 것 그대로다: 마력탄·부메랑은 비전, 거대 화염구는 화염, 연쇄 번개는 번개, 얼음 송곳은 냉기, 그림자 구체는 암흑(3겹 큰 고리 40×40, `effects.md` 13.3절). 암흑 블록(그림자 구체, 잠식)은 이 지팡이와 속성이 같다. 단계 장식은 이 위에 얹는다.

### 4.3 큰 변화 단계: +4, +7, +10, +13

| 단계 | 바뀌는 것 | 이 단계인 이유 |
|---|---|---|
| +4 | 눈을 뜬다. 지팡이가 "물건"에서 "보는 것"이 된다 | 지팡이 이름이 완성되는 단계. 칭호가 "말 없는" → "그늘진"으로 바뀐다. 실패하면 처음으로 잃을 수 있는 구간에 들어선다 |
| +7 | 그믐달 테가 걸린다. 머리 윤곽이 처음으로 구슬보다 커지고 구슬이 어두워지기 시작한다 | 칭호 "달 없는 밤의". 기본 확률이 32%로 1/3 아래에 들어서는 첫 도전이다 |
| +10 | 구슬이 손을 떠난다. 쥐는 지팡이에서 놓는 지팡이로 | +10 이상 성공은 서버 전체에 알린다 [확정, DECISIONS 2.4]. 칭호 "꽤 위대한 그림자" |
| +13 | 구슬이 검은 달이 된다. 유일하게 발밑 바닥 효과를 가진다 | 최대 단계. 서버 전체 알림. 느루: "…그건 나도 못 해 봤다." |

### 4.4 외상(빚 결정)의 표시

지팡이 특성 "외상"이 걸려 있는 동안 지팡이에도 보인다. 결정 칸의 "보라 테두리의 빈 칸"과 같은 기호를 쓴다. 외상의 규칙 자체는 `world-characters.md` 4.5절이 정한다.

- 빚 1개당 **속이 빈 연보라 고리(6×6)** 하나가 지팡이 머리 위에 떠서 천천히 깜빡인다(최대 2개, 제자리).
- 빚이 있는 동안 그림자가 위로 오르지 않고 **아래로 흘러내린다**(+4 이상). 눈은 반쯤 감긴다.
- +13에서는 발밑 밤의 꺼진 별 중 빚만큼이 속 빈 고리로 바뀐다.
- 빚을 다 갚으면 고리가 구슬로 빨려 들어가고 눈이 다시 뜬다(4프레임).
- 색은 연보라만 쓴다. "받는 피해 +1칸"의 경고는 결정 칸과 체력 칸이 맡는다.

## 5. 강화하는 순간, 실패, 하락, 변이, 슬롯

강화는 **강화 화면**에서만 한다 [확정, DECISIONS 1.7, 2.4]. 메인 메뉴와 광장 메뉴에서 들어가는 별도 화면이고, 캐릭터를 조작하는 공간이 아니며, 판 중에는 하지 않는다. 화면 구성, 한 번의 시도 시간표, 결과별 길이, 건너뛰기, 번쩍임 한도는 `effects.md` A부가 정한다. 이 절은 그 틀 안에서 **이 지팡이가 어떻게 보이는지**만 적는다. 연출은 192×192 큰 그림으로 한다. 서버에 연결하지 못했을 때도 오프라인 프로필로 같은 화면과 같은 연출이 돌아간다 [확정, DECISIONS 2.6].

### 5.1 한 번의 시도

| 순서 | 화면 |
|---|---|
| 1. 제물 | 블록이 그림자 가루로 풀려 구슬로 빨려 든다. 눈이 있는 단계면 눈이 제물을 따라간다. 암흑 블록이면 가루가 더 짙다 |
| 2. 달이 찬다 | 지팡이 뒤의 그믐달이 반달 → 보름으로 차오르고 그림자가 가운데로 모인다(6프레임. 그림은 `effects.md` 20.1절 "충전 중 지팡이 끝 변화"의 달 겹그림 96×96이고, 차오르는 방향은 `effects.md` 5절의 그믐 칸). 떠 있던 조각이 모두 제자리로 내려앉고, 옹이 손가락이 구슬을 꽉 쥐고, 눈이 실눈으로 가늘어진다. 화면 가장자리가 어두워진다 |
| 3. 숨 멈춤 | 보름달이 뜬 채 모든 것이 멈춘다. 지팡이 윤곽만 검게 남는다 |
| 4. 결과 | 아래 표 |

달의 방향은 `effects.md` 5절이 정한 그대로다: 충전은 그믐달이 보름으로 차오르고, 성공은 보름달이 뜨고 구슬이 눈을 뜨고, 실패는 달이 그믐으로 돌아가고 구슬 눈이 감긴다. 눈이 없는 단계(+0~+2)에서는 결정의 빛이 눈 구실을 한다(성공하면 켜지고 실패하면 꺼진다). 순서 2는 `effects.md` 2절의 충전, 순서 3은 숨 멈춤 구간이고 길이는 그 절과 4절의 값을 쓴다.

| 결과 | 화면 | 그믐(화면 구석의 초상) | 소리 |
|---|---|---|---|
| 성공 | 검은 윤곽이 부풀었다가 새 단계의 모양으로 걷힌다(6프레임. `effects.md` 3.1절. +12 → +13만 12프레임). 새로 바뀐 부위가 마지막에 자리 잡는다. 놓는 단계(+5, +10, +11, +12)는 조각이 "툭" 하고 떨어져 뜨는 것으로 끝난다. 연보라 선 고리 하나가 퍼진다. 보름달이 환해지고 구슬이 눈을 뜬다 | 눈이 반달 | 낮은 "둥" + 맑은 종 한 번 |
| 큰 변화 단계 성공 | 위 대신 전용 연출: +4 손가락이 하나씩 펴지고 눈이 뜬다 / +7 구슬 뒤에서 그믐달이 돋는다 / +10 손이 펴지고 구슬이 떠오른다 / +13 구슬이 보름달을 삼키고 화면이 한밤이 된 뒤 가는 테 하나만 남는다 | 눈이 반달, +13은 두 눈이 처음으로 크게 떠진다 | 단계마다 전용 음 |
| 대성공 (+2, 슬롯 확장) | `effects.md` 3.2절대로 실패처럼 시작한다: 달이 그믐으로 돌아가고 눈이 감긴 채 먼지가 오르다가, 보름달이 다시 차오르며 눈이 번쩍 더 크게 뜬다. 모양이 두 번 연달아 바뀌고 고리가 둘 퍼진다. 금 가락지 하나가 막대를 타고 내려가 "딸깍" 끼워진다(5.4절) | 눈이 점 → 놀라서 동그래짐 | 성공음 두 번 + 금속 "딸깍" |
| 실패 (하락 없음) | 달이 그믐으로 돌아가고 눈이 감긴다(순서 2의 6프레임을 거꾸로 재생). 회보라 먼지(`effects.md` 20.1절의 공용 "실패 먼지"에 회보라를 입힌 것)가 한 번 피어오르고 지팡이가 0.5초 동안 2px 처진다 | 눈이 점 | 마른 "픽". 느루: "원래 그런 거다." |
| 실패 (하락) | 달이 그믐으로 돌아가고 눈이 감긴 뒤 5.2절 | 눈이 점, 떨어지는 것을 눈으로 좇는다 | 단계별 |
| 부적이 막음 | 달이 그믐으로 돌아가다 멈춘다. 막대에 묶인 종이 부적에서 종이 띠가 그림자에서 나와 지팡이를 받치고(6프레임), 부적이 끝에서부터 타 없어진다(6프레임. 순서와 프레임 수는 `effects.md` 3.4절, 그림자에서 나오는 띠는 5절). 되돌아가려던 부위가 제자리를 지킨다 | 눈이 점 → 깜빡 | 종이 타는 "사락" |
| 변이 제시 | 눈이 엉뚱하게 뜬다(눈동자가 떨리며 변이 무늬 모양이 된다). 받으면 변이 조각이 붙고(5.3절), 거절하면 일반 실패 연출로 넘어간다 | 눈이 한쪽만 커짐 | 어긋난 화음 한 번 |

강화 실패는 빨강으로 그리지 않는다(`effects.md`). 이 지팡이의 실패색은 회보라다.

장인의 기운(0~3): 강화 화면과 살펴보기에서만 보인다. 금테의 눈금 3개가 쌓인 수만큼 은은히 켜진다. 손에 든 그림에는 표시하지 않는다.

### 5.2 하락: 놓았던 것을 도로 쥔다

각 단계는 앞 단계에서 한 부위를 바꾼 것이므로, 하락은 **그 변화가 되돌아가는 것**으로 그린다. 놓는 단계의 하락은 떠 있던 조각이 도로 붙는 것이다. 겁먹은 손이 다시 움켜쥐는 모습이라 이 캐릭터에 맞는다.

| 하락 | 되돌아가는 것 |
|---|---|
| +13 → +12 | 검은 달에 빛이 돌아오며 테 두른 구슬로 줄어든다. 발밑의 밤이 걷히고 별이 꺼진다 |
| +12 → +11 | 뜬 손가락 셋이 손바닥으로 돌아가 붙는다. 밤 조각이 연기로 흩어진다 |
| +11 → +10 | 뜬 머리가 막대에 "탁" 내려앉아 붙는다 |
| +10 → +9 | 뜬 구슬이 손바닥으로 내려앉고 손가락이 다시 세워져 쥔다 |
| +9 → +8 | 달 테의 뿔 끝 둘이 부러져 떨어진다. 구슬 속 어둠이 물러난다 |
| +8 → +7 | 그림자 줄기가 말라 끊어져 떨어진다 |
| +7 → +6 | 그믐달 테가 깨져 조각으로 흩어진다. 구슬이 다시 밝은 보라로 돌아온다 |
| +6 → +5 | 초승달 장식이 떨어진다. 검은 뿌리가 아래부터 나무색으로 돌아오고 굽이가 펴진다 |
| +5 → +4 | 뜬 토막이 막대에 도로 붙는다 |
| +4 → +3 | 눈이 감겨 실눈이 된다. 손가락 하나가 말라 떨어진다 |

- 떨어지는 조각은 중력을 받아 떨어져 바닥에서 한 번 튀고 그림자로 풀린다(6프레임).
- 유리 지팡이 변이의 판 안 임시 하락(`online.md`): 전투 중에도 같은 방식으로 한 단계 아래 모양이 되고 금 간 무늬가 겹쳐진다. 판이 끝나면 3프레임 연출과 함께 원래 단계로 돌아온다. 이것은 흔적이 아니다.

**하락 흔적과 공개 여부** [확정, DECISIONS 1.15]: 현재 단계가 역대 최고 단계보다 낮은 지팡이에는 흔적이 남는다. 누구에게 보이는가는 `effects.md` 1.3절이 정하고, 이 문서는 흔적의 **모양**만 정한다. 아래 두 번째 표는 그 절의 규칙을 이 지팡이에 그대로 옮긴 것이다.

| 흔적 | 모습 |
|---|---|
| 아문 자국 | 되돌아간 자리에 회보라 흉 4px(도로 붙은 이음매, 부러진 뿔의 그루터기, 깨진 테의 조각 하나). 역대 최고보다 낮은 단계 수만큼 1~2개. 손에 든 그림에서도 보인다. 역대 최고 단계를 되찾으면 사라진다 |
| 역대 최고 윤곽 | 큰 그림에서 지팡이 뒤에 역대 최고 단계의 윤곽을 15% 점선 그림자로 겹친다. 하락 바닥(역대 최고 −2)이 어디인지 그림으로 알 수 있다 |

| 누가 보나 | 규칙 |
|---|---|
| 본인 | 설정과 무관하게 항상 보인다(강화 화면, 손에 든 그림, 자기 살펴보기). 끔일 때는 흔적 옆에 공용 가림 표시(눈을 가린 아이콘 16×16)가 붙는다 |
| 남 (광장, 결투, 살펴보기, 순위표 프로필) | **본인이 고른다.** 강화 화면 왼쪽 칸의 "흔적 공개 [켬 / 끔]"이고 **지팡이마다 따로** 저장한다. 계정 전체 설정이 아니다. 주인이 언제든 바꾼다. 켬이면 아문 자국과 역대 최고 윤곽, "역대 최고 +N"이 보인다. 끔이면 남에게는 흔적 없는 현재 단계 그림과 현재 단계 숫자만 보이고, 역대 최고 단계와 이력 꼬리표도 보이지 않는다. 결투의 상대 화면도 이 설정을 그대로 따른다. **기본값은 끔** |
| 거래 상대 | **설정과 무관하게 항상 보인다.** 직접 거래 창, 장터 목록과 미리보기(상세), 최종 확인 화면에서 아문 자국, 역대 최고 윤곽, "역대 최고 +N, 지금 +M" 글자를 보여 준다. 거래 창에 올리는 순간 주인 화면에 "거래 상대에게는 흔적이 보인다" 한 줄이 뜬다 |

### 5.3 변이 6종의 모습

변이는 지팡이의 **서로 다른 부위**에 붙는다. 그믐은 최대 2개이고, 어떤 두 개를 골라도 자리가 겹치지 않는다. 손에 든 그림에서 알아볼 수 있는 표식을 하나씩 가진다. 색은 몸 6색과 효과 3색 안에서만 쓴다.

| 변이 | 붙는 부위 | 손에 든 그림 | 큰 그림 | 전투 중 효과 |
|---|---|---|---|---|
| 뒤틀린 총열 | 손 위쪽 막대 | 금테 아래 막대가 한 번 꼬여 머리가 4px 옆으로 어긋난다(+11 이상은 뜬 머리가 어긋난 채 뜬다) | 막대가 타래처럼 한 바퀴 반 꼬임. 눈이 있으면 눈동자가 가늘게 떨린다 | 탄이 날아가며 좌우로 찌그러진다(2프레임. 블록의 탄 그림을 좌표로 누르는 것이고 판정은 그대로) |
| 불안정 핵 | 구슬 겉면 | 구슬에 흰 금 한 줄. 구슬이 불규칙하게 2px 부풀었다 줄어든다 | 금 사이로 빛이 새고 작은 빛 조각이 튄다 | 자폭 0.3초 전 구슬이 흰 연보라로 2번 깜빡인다(예고). 자폭은 연보라 선 고리로 그린다 |
| 과민 회로 | 막대 겉면 + 눈꺼풀 | 구슬에서 막대로 내려오는 연보라 실선 한 줄이 깜빡인다. 눈이 깜빡이지 않는다 | 손가락(눈꺼풀)이 뒤로 젖혀져 고정됨. 신경 같은 가는 줄이 막대 전체에 퍼지고 틈을 건너뛴다 | 임계 구간에서 실선이 빠르게 깜빡인다 |
| 탐식 | 금테 바로 아래 옹이 | 금테 아래 옹이가 벌어져 이빨 같은 지그재그 6px | 뿌리 이빨이 난 입. 가끔 입맛을 다신다 | 처치 때 입이 2프레임 씹고, 죽은 적에서 그림자 가루 3개가 지팡이로 날아온다 |
| 거울상 | 막대 아래 끝 | 아래 끝(+5 이상은 뜬 토막)에 4×4 작은 구슬과 반짝임 | 아래 끝에 눈을 감은 작은 옹이 머리가 거꾸로 달림 | 뒤로 나가는 탄은 아래 구슬에서 나오고 총구 섬광도 거기서 난다 |
| 유리 지팡이 | 막대 재질 | 막대가 반투명 연보라(뒤가 60% 비침)가 되고 흰 빛 줄이 주기적으로 훑는다 | 속이 비치는 유리 뿌리, 안에 그림자가 갇혀 흐름 | 임시 하락 때마다 금이 한 줄씩 는다(5.2절) |

- 변이가 밀려나거나 제거되면 그 조각이 그림자로 풀려 사라진다.
- 살펴보기에서는 변이 이름과 변이 아이콘을 함께 적는다. 변이 아이콘은 다섯 지팡이가 같이 쓰는 공용 그림 6종이고 크기와 장수는 `effects.md` 20.1절의 "변이 아이콘" 행이 정한다. 이 문서는 변이 아이콘을 따로 그리지 않는다. 그림만으로 알아맞히게 하지 않는다.

### 5.4 슬롯 확장

- 확장 1칸마다 **금 가락지 1개**가 손 아래쪽 막대에 끼워진다(지팡이당 최대 3개, `online.md`).
- 손에 든 그림: 손 아래 막대에 금색 2px 눈금이 4px 간격으로 최대 3개. 머리 아래의 금테(항상 있음)와는 위치가 달라 헷갈리지 않는다. +5 이상의 틈보다 위쪽에 끼운다.
- 큰 그림: 가락지마다 작은 뿌리 싹이 돋아 빈 받침(블록을 끼울 자리)을 받들고 있다. 그 칸에 블록을 끼우면 받침에 불이 켜진다.
- 조립 화면의 슬롯 줄에서는 확장된 칸에 금테를 두른다.

## 6. 가독성 규칙

지팡이 효과는 전부 겉모습이다. 판정, 피해, 탄의 크기는 단계와 상관없이 같다.

### 6.1 그리는 순서

층 순서는 `effects.md` 9.1절이 정한다. 이 지팡이의 효과가 들어가는 층은 아래와 같고, 어떤 단계의 어떤 효과도 적 예고의 테두리(9층)와 적 탄(10층)보다 위에 가지 않는다. 바닥에 까는 것은 전부 적 예고의 채움(4층)보다 아래다. 내 효과가 예고 구역과 겹칠 때의 불투명도는 `effects.md` 9.2절의 누적 가림 상한 하나만 따르고, 이 문서는 따로 수치를 두지 않는다.

| 이 지팡이의 효과 | `effects.md` 층 |
|---|---|
| 적중 얼룩, 방울 자국, 밤 자국, +13의 발밑 둥근 밤, 손 모양 그림자 | 2 (바닥 흔적) |
| 손에 든 지팡이와 뜬 조각, 빚 고리 | 6 (몸) |
| 탄, 꼬리 띠 | 7 (내 탄) |
| 총구 섬광, 적중 효과, 임계·처치 효과 | 8 (터지는 것) |

### 6.2 이 지팡이가 지키는 선

| 규칙 | 값 |
|---|---|
| 색 | 탄 장식과 입자는 E1·E2(색상각 250~270°)와 흰 연보라 H만. 위험색, 주황, 금색 없음(금색은 임계 표시와 겹친다) |
| 흰색 | 흰색으로 꽉 찬 닫힌 도형은 적 예고의 번쩍 전용이다. 이 지팡이의 흰색은 한 덩어리 4px 이하의 점과 2px 이하 굵기의 선으로만 쓴다 |
| 속이 빈 모양 | 적중 효과와 섬광은 고리·호·선으로 그린다. 꽉 찬 밝은 원을 쓰지 않는다. 아래 깔린 예고 구역이 고리 안으로 보여야 한다 |
| 어두운 면 | 이 지팡이가 암흑 블록의 탄에 얹는 테 변형(+7, +13)에서, 탄 하나의 어두운 고리 안쪽 어둠은 지름 10px 이하. 그보다 큰 탄(그림자 구체)은 안쪽 어둠을 50% 투명으로. 가운데 밝은 심(4×4px, 큰 탄 8×8px. `effects.md` 16.2절)은 항상 남긴다. 다른 속성 블록의 탄에는 어두운 면을 얹지 않는다 |
| 크기 | 적중 효과는 그 탄의 실제 판정 범위보다 크게 그리지 않는다. 폭발 블록이 아닌 탄의 적중 효과는 지름 32px 이하 |
| 길이 | 꼬리 띠는 탄 지름의 2배 이하이면서 `effects.md` 9.3절의 단계 구간별 꼬리 띠 길이(+0~+3 16px, +4~+6 24px, +7~+9 32px, +10~+12 40px, +13 48px) 이하. 띠 그림은 4프레임 이하, 불투명도 70% 이하. 적중 효과 0.35초 이하, 바닥 자국 0.5초 이하 |
| 발밑 둥근 밤(+13) | 면을 칠하지 않는 선 고리 + 30% 어둠. 지름 1칸을 넘지 않는다. 전투 중 예고 구역과 겹치면 예고가 위에 그려진다(층 2 대 4) |
| 화면 번쩍임 | 없음. 지팡이 효과는 화면 전체 밝기를 바꾸지 않는다(+13의 한밤 연출은 강화 화면과 광장 감정표현에서만) |
| 캐릭터 가림 | 지팡이 머리와 뜬 조각은 그믐의 말린 후드 끝과 두 눈을 가리지 않는다. 뜬 구슬이 후드 끝과 겹치는 방향("위" 방향 그림)에서는 구슬을 몸 바깥쪽으로 4px 옮겨 그린다 |
| 소리 | 발사음은 적의 예고음보다 작게 섞는다. 다른 소리를 줄이는 처리는 전투에서 쓰지 않는다 |

### 6.3 설정

이 지팡이 전용 옵션은 없다. `effects.md` 18절의 옵션("지팡이 효과" 전부/줄임/최소, "지팡이 효과 투명도", "남의 지팡이 효과", "탄 꼬리", "바닥 흔적", "내 탄 투명도")을 그대로 받는다. 값마다 입자 몫이 얼마로 줄어드는지는 `effects.md` 9.3절의 전체/줄임/최소 열이 정하고, 아래는 "지팡이 효과"의 각 값에서 이 지팡이의 **그림**이 어떻게 되는지만 적는다.

| "지팡이 효과" 값 | 이 지팡이에서 |
|---|---|
| 전부 | 4.2절 그대로 |
| 줄임 | 꼬리 띠와 적중 효과는 남긴다. 임계 장식(잔상 조각, 끊긴 테)과 별 가루는 뺀다. 대기 입자와 적중 입자는 9.3절의 줄임 몫 안에서만 나온다. 뜬 조각의 오르내림은 남는다 |
| 최소 | 단계와 상관없이 +0의 탄 장식. 꼬리 없음. 대기 입자 0(9.3절의 최소 몫이 0이다) |

지팡이 몸 모양과 틈, 눈, 달 테, 발밑 둥근 밤의 선 고리와 별은 어느 값에서도 그대로다. 단계 구분은 본체 실루엣이 맡는다.

### 6.4 단계별 입자 요청량

**입자 예산과 넘쳤을 때의 처리는 `effects.md` 9.3절이 유일한 기준이다** [확정, DECISIONS 2.8]. 이 문서는 상한을 따로 두지 않고, 9.3절의 "지팡이 문서가 채우는 몫" 표 안에서 예산 관리기에 요청하는 양만 적는다. 발급받지 못한 입자는 나오지 않을 뿐이고, 지팡이 몸과 탄 그림은 영향을 받지 않는다. 탄 수가 100발, 200발을 넘을 때 꼬리와 적중 장식이 줄어드는 문턱도 9.3절의 것을 그대로 따른다.

- "대기"는 손에 든 지팡이 하나가 동시에 띄우려는 입자 수(그림자 실오라기, 방울, 반짝임). `effects.md` 9.3절의 분류 5 "지팡이 대기" 몫에서 받는다.
- "적중"은 탄 한 발이 맞았을 때 요청하는 입자 수. 9.3절의 분류 2 "적중" 몫에서 받는다. 임계 사격의 추가분(적중 1회에 +4까지)도 9.3절을 따른다.
- **총구 입자와 탄이 흘리는 입자는 모든 단계에서 0**이다. 총구 섬광은 지팡이 끝에 붙는 그림 한 장, 꼬리는 탄에 붙는 띠 그림 한 장이라 입자가 아니다.
- 뜬 조각, 눈, 달 테, 밤 조각, 발밑 둥근 밤과 별은 입자가 아니라 본체에 딸린 그림이다(9.3절: +13의 발밑 바닥 효과는 2층의 그림이나 셰이더로 만들고 입자를 쓰지 않는다).
- 탐식 변이의 처치 가루 3개(5.3절)는 분류 3 "처치" 몫에서 받는다.

아래 값은 전부 9.3절의 구간별 요청 상한(대기 8 / 16 / 30 / 45 / 60, 적중 4 / 7 / 8 / 10 / 12) 이하다.

| 단계 | 대기 | 적중 1회 | | 단계 | 대기 | 적중 1회 |
|---|---|---|---|---|---|---|
| +0 | 0 | 0 | | +7 | 6 | 2 |
| +1 | 1 | 0 | | +8 | 7 | 3 |
| +2 | 1 | 0 | | +9 | 8 | 3 |
| +3 | 2 | 0 | | +10 | 10 | 3 |
| +4 | 3 | 1 | | +11 | 10 | 4 |
| +5 | 4 | 1 | | +12 | 12 | 4 |
| +6 | 5 | 2 | | +13 | 16 | 6 |

빛 먹기 축 덕분에 이 지팡이는 높은 단계에서 입자가 적다. 대기 입자는 구슬로 빨려 들어가 수명이 짧고, +13의 화려함은 입자가 아니라 "주변이 어두워지는 그림"에서 나온다.

## 7. 남이 보는 지팡이: 광장, 살펴보기, 결투

### 7.1 광장

- 손에 든 지팡이는 현재 단계의 모양과 "가만히" 효과 그대로 보인다. 하락 흔적은 본인이 공개로 둔 경우에만 보인다(5.2절).
- 멀리서 단계 구간을 읽는 법:

| 보이는 것 | 구간 |
|---|---|
| 눈이 없다 | +0 ~ +3 |
| 뜬 눈, 구슬은 손에 쥐여 있다 | +4 ~ +6 |
| 구슬 뒤에 그믐달 테 | +7 ~ +9 |
| 구슬이 손에서 떨어져 떠 있다 | +10 ~ +12 |
| 구슬이 **검다** + 발밑이 둥근 밤 | +13 |

- **+13만의 표식** (다른 단계에는 하나도 없다): 검은 구슬, 발밑 둥근 밤과 결정 별, 대기 입자가 달로 빨려 드는 움직임. 이 셋은 치장 겉모습을 덧씌워도 꺼지지 않는다.
- 광장에서 남의 지팡이 효과를 얼마나 그릴지와 입자 합계는 `effects.md` 18절의 "남의 지팡이 효과" 옵션과 9.3절의 광장 표를 따른다(나는 요청량 전부, 가까운 8명은 절반, 나머지는 입자 0). 입자가 0이 되어도 틈, 눈 깜빡임, 달 테, 발밑 둥근 밤은 본체에 딸린 그림이라 그대로 그린다.
- 감정표현 "지팡이 들어 올리기": 단계 효과를 크게 한 번 재생한다. +4~+6은 눈이 크게 뜨이며 둘러본다. +7~+9는 머리 위에 그믐달이 2초 걸린다. +10~+12는 구슬이 머리 위 1칸까지 떠올랐다 돌아온다. +13은 그믐 주변 반경 3칸이 2초 동안 한밤이 되고 검은 달이 뜬다(광장 연출 전용, 그 원 안에서만 어두워진다).
- 눈은 광장에서 지나가는 가장 가까운 플레이어를 따라본다(+4 이상). 누가 살펴보기를 열면 그쪽을 본다.

### 7.2 살펴보기와 거래

| 요소 | 내용 |
|---|---|
| 큰 그림 | 192×192, "가만히" 효과가 움직이는 채로 |
| 단계 표시 | 단계 숫자와 단계 묶음 테(`ui-assets.md` I-G1, 다섯 지팡이 공통) |
| 별명 | 지팡이 이름 옆에 그 단계의 별명("엄청엄청 위대한 그믐") |
| 변이 | 공용 변이 아이콘(`effects.md` 20.1절) + 이름, 최대 2개 |
| 슬롯 | 기본 4칸 + 금 가락지 수(0~3) |
| 기운 | 금테 눈금 0~3 |
| 하락 흔적 | 그 지팡이의 "흔적 공개"가 켬일 때만: 아문 자국, 역대 최고 윤곽, "역대 최고 +N". 끔이면 남의 살펴보기에는 아무것도 나오지 않는다(5.2절) |
| 이력 | "주인 n번째"(`online.md`) |
| 조립 | 공개 설정일 때만 |

살펴보기와 거래 화면의 배치와 화면 그림(틀, 칸, 단계 묶음 테, 흔적 딱지)은 `ui-assets.md` 4.22절과 3.3절이 주인이다. 위 표는 그 화면에 이 지팡이의 무엇이 나오는지만 적고, 이 지팡이만의 단계 줄 같은 화면 그림은 따로 두지 않는다.

거래 창과 장터 목록에서는 64×64 아이콘(`world-characters.md` 3.3절) + 단계 숫자 + 변이 아이콘 + 가락지 수를 한 줄로 보여 준다. **거래에서는 하락 흔적이 설정과 무관하게 항상 보인다**(5.2절): 목록 줄에 "역대 최고 +N, 지금 +M" 표시가 붙고, 상세와 최종 확인 화면에 큰 그림의 흔적이 그대로 나온다. 최종 확인 화면에서는 단계·변이·슬롯·역대 최고를 글자로 크게 다시 적는다. 받은 지팡이는 그믐으로만 쓸 수 있다 [확정, DECISIONS 2.4].

### 7.3 결투

DECISIONS 2.7을 따른다. 상대 화면에서의 표시 규칙은 `effects.md` 17절과 9.3절의 결투 표가 기준이고, 아래는 그 규칙이 이 지팡이에서 무엇을 뜻하는지다.

- **지팡이 본체의 모양은 실제 단계 그대로 보인다.** 틈, 눈, 달 테, 검은 달 모두 그대로다. 상대가 무엇을 들고 왔는지 보이는 것이 육성의 보상이다. 리그 제한으로 강화가 깎여 적용될 때도 모양은 실제 단계다.
- **상대 화면에서 내 탄 장식은 가장 단순한 형태로 보인다** [확정, DECISIONS 2.7]. 내 강화 단계나 덧씌운 겉모습과 상관없이 **꼬리 띠 없음, 탄이 흘리는 입자 0, 적중은 최소형(입자 2개)** 이다(`effects.md` 9.3절·17절의 정의 그대로). 총구는 +0의 고리 연기 2프레임만 쓴다. 단계 장식(그믐달 테, 잔상 고리, 별 가루, 눈·초승달·검은 달 섬광, 초승달 베기, 월식 적중, 임계·처치 장식)과 바닥 흔적(얼룩, 방울 자국, 밤 자국)은 상대 화면에 하나도 그리지 않는다. +13의 월식 탄(그림자 구체)도 상대 화면에서는 블록의 기본 탄 모양이다.
- 상대 화면에서 내 탄의 색은 `effects.md` 17절을 따른다: 블록의 속성 모양은 그대로 두고 몸 전체가 자홍 `#FF2E88` + 흰 중심 4×4다. 이 문서는 상대 화면용 탄 그림을 따로 만들지 않는다.
- 상대 화면에서 내 지팡이의 대기 입자는 요청량의 절반까지만 나온다(`effects.md` 9.3절의 결투 표). 뜬 조각, 눈, 달 테는 본체라서 그대로다.
- 내 화면에서 내 탄 장식은 내 설정대로 보인다(6.3절). 판정과 크기는 같으므로 유불리가 없다.
- +13의 발밑 둥근 밤은 결투에서 양쪽 화면 모두 **테두리 선 고리와 별만** 그리고 면의 어둠은 뺀다. 상대의 예고 구역과 탄을 읽는 데 영향을 주지 않게 하기 위해서다.
- 리그 제한으로 깎여 적용될 때는 금테에 **흰 봉인 끈**이 묶이고 끈에 달린 표에 적용 단계("+9")가 적힌다. 눈은 뜬 채다. 살펴보기에도 "적용 +9 / 실제 +11"로 적는다(10절 확인 4).
- 상대 화면의 그믐에게는 **1px 흰 외곽선**이 항상 켜진다(`world-characters.md` 2.6절. 몸 색이 위험색과 색상각으로 가깝기 때문이다). 굵기는 그 절의 값 1px을 그대로 쓰고, 손에 든 지팡이와 뜬 조각 하나하나에도 같은 1px 외곽선이 걸린다. 외곽선은 지팡이 그림 바깥에 붙으며 단계 실루엣을 바꾸지 않는다.
- 하락 흔적이 상대 화면에 보이는지는 그 지팡이의 "흔적 공개" 설정을 그대로 따른다(5.2절).
- 결투 시작 소개에서 지팡이의 큰 그림과 단계 숫자를 나란히 보여 준다.

결제는 지금 연결하지 않고, 연결하지 않아도 전부 동작해야 한다 [확정, DECISIONS 1.14]. 그림과 효과를 아래처럼 자료로 떼어 둔다.

| 항목 | 내용 |
|---|---|
| 기본 겉모습 | 이 문서의 14단계. 강화로만 얻는다. 단계는 성취의 표시이므로 돈으로 건너뛰는 길을 두지 않는다 |
| 조회 | `(지팡이 종류, 덧씌운 겉모습 id 또는 없음, 단계) → 그림·효과 묶음`. 덧씌운 겉모습에 그 단계 그림이 없으면 기본으로 돌아간다. 다섯 지팡이가 같은 형식을 쓴다 |

## 9. GDD 2판에서 달라진 곳 (기록)

GDD는 3판에서 아래 내용에 맞춰졌다. 왼쪽 칸은 2판의 문장이고 지금의 GDD에는 없다. 기록으로만 둔다.

| GDD 2판 | 이 문서 |
|---|---|
| 10절: 지팡이 3종, 겉모습 규정 없음 | 전용 지팡이 하나가 14가지 모양과 효과를 가진다 |
| 9절: 변이·슬롯 확장·실패에 겉모습 없음 | 변이 6종의 덧그림, 금 가락지, 놓았던 것을 도로 쥐는 하락 연출, 하락 흔적과 공개 설정 |
| 9절: 하락 바닥 "이번 판 최고 단계" | "역대 최고 단계"(`online.md`)를 따르고 그 윤곽을 그린다 |
| 9절·13절: 강화가 정비 화면 안 | 전용 강화 화면에서만 한다 |
| 13절: 효과음 15개 안팎 | 이 지팡이만 약 35개 |
| 14절: 캐릭터 32×32, 그림 한 장 | 캐릭터 64×64, 지팡이는 몸에서 뗀 32×64 별도 층. 기준 그림에서 지팡이를 분리해야 한다 |

## 10. 개발자 확인 필요

모두 추천안을 본문에 이미 적용했다. 바꾸고 싶은 것만 알려 주면 된다. 다섯 지팡이와 다른 문서의 질문을 합친 목록은 `GDD.md` 맨 끝의 "개발자 확인 필요"이고, 아래는 그중 이 지팡이에 관한 것이다.

1. **하락 흔적 공개의 기본값.** 본인이 지팡이마다 고른다는 것은 정해졌고, 처음 값은 `effects.md` 1.3절대로 "끔(남에게 안 보임)"이다(5.2절). 켜 둔 채 시작하는 쪽을 원하는지. 다섯 지팡이가 같은 값을 쓴다(`GDD.md` 개발자 확인 필요 23번).
2. **구슬이 끝까지 밝아지지 않고 어두워지는 방향.** 보라 결정에서 시작해 +13에 검은 달 + 흰 연보라 테로 끝난다(3.3절). 마지막이 푸른 구슬이나 밝은 보라 구슬이기를 원하는지.
3. **곁구슬을 뺀 것.** `world-characters.md`의 성장 방향 참고에는 "작은 구슬이 늘어남"이 있었지만, 개수는 초롱, 공전은 성에의 축과 겹쳐서 뺐고 "떼어 띄우기"로 바꿨다(1.1절). 작은 구슬을 되살리고 싶은지.
4. **리그 제한 때의 봉인 끈.** 모양은 실제 단계로 두고, 깎여 적용되는 단계를 금테의 흰 끈과 표로 알린다(7.3절). 표시 없이 살펴보기 글자로만 알릴지.
5. **+13의 발밑 둥근 밤을 전투 중에도 켜 두는 것.** 결정 수를 별로 보여 주는 기능이 있어 전투 중에도 켰고, 결투에서는 선 고리와 별만 남겼다(4.2절, 7.3절). 전투 중에는 끄고 광장에서만 보일지.
