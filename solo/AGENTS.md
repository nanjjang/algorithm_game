# AGENTS.md — solo/ 작업 규칙 (Codex, OpenCode 등 모든 에이전트용)

이 파일은 `CLAUDE.md`와 같은 규칙이다. 작업 순서와 단계별 지시는 `Docs/HANDOFF.md`에 있다.

옛 .NET 하네스(루트 `src/`·`server/`·`tools/`·`tests/`)는 2026-11-22에 지웠다(git 태그 `archive/harness`에 남아 있다). 아래 규칙만 따른다.


이 폴더는 "엄청엄청 위대한 마법사 키우기"의 **솔로(오프라인) 플레이 + 지팡이 강화**와, 그 위에 얹는 **인터넷 온라인(협동 · 1대1 결투 · 광장)** 을 순정 Unity(6000.3.20f1, 2D URP, C#)로 만드는 별도 프로젝트다. 사용자 지시로 하네스 없이 만든다. 온라인 설계는 `Docs/11-online.md`가 정본이다.

## 옛 하네스 규칙 중 따르지 않는 것

- 작업 카드, `owned_paths`, 작업 트리(`$WT`), `tasks.json`, `ci.sh`, 벡터 대응 검사, 결과 보고 양식, 계약 변경 요청 절차.
- 결정론 규칙: `float`, `Dictionary`, `UnityEngine`을 자유롭게 쓴다. Fix64, 분석기 없음.
- `netstandard2.1` 어셈블리 의존 순서, `IBackend`·`ILedger`. 온라인 코드는 `solo/` 안에 둔다(아래 "온라인" 절).
- "뷰는 코드로만" 같은 기존 Unity 프로젝트 규칙은 강제가 아니다(다만 배치 모드로 검증하기 쉽도록 화면은 코드로 만든다).
- `command git`, `/bin/ls` 같은 zsh 우회. 이 PC는 Windows다. 평범하게 쓴다.

## 여기서도 지키는 것

- **`solo/` 밖은 고치지 않는다.** `data/`, `art/`, `docs/`는 읽기만 한다. 필요한 데이터와 그림은 `solo/Assets/` 아래로 복사해서 쓴다. 온라인용 서버 코드도 `solo/` 안(`solo/Server/`)에 둔다. `docs/online.md`, `docs/spec/09~12`는 규칙 원문으로 읽는다.
- **게임 규칙 불변식**(옛 루트 CLAUDE.md 2.5절: 강화는 강화 화면에서만, 다섯 지팡이 같은 확률, 위험색은 적 전용, 오프라인 프로필은 서버로 옮기지 않음, 결제 없음 등).
- 화면에 보이는 글자는 이름 표에만 둔다. 원본 `data/names/names.ko.json`의 사본과, 원본에 없는 열쇠를 담는 `names.solo.ko.json`을 쓴다. 코드에 한국어 문자열 리터럴을 넣지 않는다.
- 기획 수치는 JSON에 둔다(`data/sim/*.json` 사본 + 솔로용 보충 JSON). 수치를 "더 좋아 보이게" 바꾸지 않는다. 명세 값 그대로, [임시] 값은 그대로 쓴다.
- 코드·데이터의 id는 정본 id(`char.1`~`char.5`, `block.fireball`, `art.burst` …). 작업용 이름(달구·초롱 등)을 코드에 쓰지 않는다. 그림 폴더 이름(dalgu 등)은 에셋 경로 대응표 한 곳에만 둔다.
- 일정·마감·범위 삭감을 제안하지 않는다.
- 그림과 소리를 새로 만들지 않는다. 있는 에셋을 쓰고, 없는 것은 글자나 단순 도형으로 대신한다.
- 돌려 보지 않은 것을 통과했다고 적지 않는다.
- 커밋은 사용자가 맡길 때만 한다.

## 온라인 (사용자 결정, 2026-11-15)

- 모드는 네 가지다: **솔로**(오프라인, 지금 것 그대로 남는다) · **협동**(온라인 2~4명 웨이브) · **결투**(온라인 1대1) · **광장**(온라인). 솔로를 없애거나 협동으로 바꾸지 않는다. 만드는 순서는 협동 → 결투 → 광장, 계정·접속 뼈대는 공통으로 먼저.
- **서버 권위.** 판은 서버가 돌리고 클라이언트는 입력을 보내고 상태를 받는다. 전투 서버는 solo를 화면 없이 빌드한 Unity 헤드리스 서버(같은 `Wizard.Solo.Sim` 코드)다. 솔로 시뮬은 float라 기기 사이 결정론(락스텝·서버 재검증)을 가정하지 않는다.
- 시뮬은 오프라인과 온라인이 같은 코드다. 온라인 때문에 솔로 규칙을 바꾸지 않는다. 시뮬에 소켓·시계를 넣지 않는다(통신은 App/Net 층이 입력을 `InputQueues[slot]`에 넣고 상태를 읽는다).
- 오프라인 프로필과 서버 프로필은 **따로다.** 서로 옮기지 않는다(2.5절 불변식 유지). 온라인 진행은 서버 프로필에만 쌓인다.
- 결제 없음은 온라인에도 그대로.
