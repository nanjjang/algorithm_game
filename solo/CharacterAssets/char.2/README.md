# 제자 2 에셋

`manifest.json`에서 에셋 경로, 픽셀 좌표, 클립, 소켓과 단계별 자료를 찾을 수 있다. 좌표 원점은 왼쪽 위이고 기본 해상도는 64 PPU다. 픽셀 아트 텍스처는 Point, 무압축, 밉맵 끔으로 가져온다.

| 구성 | 파일 및 규격 |
| --- | --- |
| 선택 일러스트 | `selection_1024x1024.png` 원화, `selection_192x192.png` UI용 |
| 인물 | `body_64.png` 768×832, 37클립, 147칸. `combat_64.png`는 그중 전투 22클립을 담은 기존 내보내기 |
| UI | `portraits_64x64_f4.png` 표정 4종, `silhouette_32x32.png`, `ui/`의 패시브·속성·비기 아이콘 |
| 반응과 야생 물 | `layers/`의 모자 등불 9프레임, 등불을 제거한 몸 시트, 야생 물 2~4단계 |
| 깜빡이 등불대 | `wand/`의 +0~+13 손 스프라이트, 검사 이미지, 단계 아이콘, 분리 본체와 등불. 손 시트는 3방향×2자세. 등불 8종은 4프레임과 꺼짐 상태가 각각 있으며 지팡이별 소켓은 manifest에 있다 |
| 전투와 강화 효과 | `fx/`의 피뢰침 벼락·벼락 질주·단계별 발사 효과, `enhancement/`의 강화 연출과 13개 단계 전환. 단계 하락 시 전환 시트를 역재생한다 |
| 소리 | `audio/`의 44.1kHz 모노 PCM WAV 32개. 깜빡이 등불대 29개, 피뢰침 체질 2개, 벼락 질주 1개. `audio/audio.json`에 반복 재생 여부와 이벤트 매핑이 있다 |

선택 일러스트, 캐릭터 포즈와 표정, 등불, 효과 원화는 ImageGen으로 만들었다. 일부 움직임은 대표 자세를 조합했다. 단계별 지팡이의 기존 윤곽에 새 등불을 합성했고, 기존 번개 속성 공용 효과·UI 아이콘과 야생 물을 함께 담았다. 소리는 파형을 합성해 만들었다.

이 폴더는 교체용 에셋 묶음이다. Unity에서 사용할 때는 그래픽 시트를 가져온 뒤 기존 캐릭터·지팡이·효과 매니페스트에 필요한 항목을 연결한다. 소리를 들으려면 현재의 무음 재생기 대신 오디오 클립을 재생하는 경로가 필요하다.
