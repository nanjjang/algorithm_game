# 제자 3 에셋

- 선택 일러스트와 몸체 동작 37개는 `Assets/Resources/Art/players`에서 불러온다. 표정 순서는 기본, 미소, 긴장, 눈 감기다.
- 지팡이 +0~+13 손 그림, 살펴보기, 목록 아이콘은 `Assets/Resources/Art/wands`에 있다. 손 시트는 아래, 오른쪽, 위 × 들기, 내밀기 순서다.
- 지팡이의 대기, 단계 전환, 책장·깃털, 색인 꼬리표, 변이, 글자 조각과 베껴 쓰기 사본은 지팡이 폴더의 `animation/manifest.json`을 참조한다. 목록은 제작용 프레임 자료이며 개별 연출 재생은 별도 연결이 필요하다.
- 효과음 39개는 `audio/manifest.json`에 있다. 마찰·종이·금속·소리굽쇠 계열을 절차적으로 합성했다. 현재 앱 재생기는 무음 구현이다.
- 캐릭터 원화, 표정, 지팡이, 비기와 장식의 소재는 ImageGen으로 제작했다. 정해진 픽셀 규격과 투명도를 맞춰 게임용 시트를 구성했다.

지팡이는 참나무 자와 펜촉에서 시작해 낱장과 접책, 두루마리를 거쳐 펼친 책과 깃펜으로 커진다. 비기 효과는 청록 글자 고리 두 겹과 흩날리는 아이보리 책장을 사용한다.
