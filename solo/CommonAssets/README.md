# 공통 픽셀아트 에셋

`Magenta-PNG.zip`에는 키 색상 `#FF00FF`를 사용한 원본 PNG가 들어 있습니다. `failure_cracks_1920x1080.png`는 알파 투명 배경입니다. `bloom_glow`와 `light_ray`는 마젠타를 제거한 뒤 가산 합성할 수 있도록 밝기를 RGB에 담았습니다.

Unity용 알파 PNG와 슬라이스 설정은 `Assets/ArtVariants/Common`에 있습니다. Point 필터와 원본 해상도를 사용합니다. 크기를 키울 때는 2×, 3×처럼 정수배로 확대합니다. 파일명의 `WxH`는 한 프레임 크기이고, `fN`은 프레임 수입니다. 애니메이션 시트는 한 줄에 최대 4프레임이며, 각 줄은 왼쪽에서 오른쪽 순서로 읽습니다.

| 파일명 접두사 | 한 프레임 크기 | 프레임 | 구성 |
|---|---|---:|---|
| `hit_spark` | 32×32 | 4 | 흰색, 노랑, 얼음색 |
| `muzzle_flash` | 32×32 | 3 | 불, 얼음, 번개, 그림자. 오른쪽으로 발사 |
| `kill_burst` | 64×64 | 6 | 일반, 정예 |
| `shockwave_ring` | 128×128 | 5 | 비기 충격파 |
| `bloom_glow` | 64×64 | 1 | 가장자리가 흐린 흰색 광원 |
| `level_wave_pillar` | 64×256 | 4 | 레벨업·웨이브 클리어 빛기둥 |
| `success_burst` | 256×256 | 8 | 강화 성공 폭발 |
| `aura` | 128×128 | 6 | +7 파랑, +10 보라, +13 무지개 금. 반복 재생 |
| `failure_cracks` | 1920×1080 | 1 | 강화 실패 균열 오버레이 |
| `result_banner` | 480×120 | 1 | 성공 금색, 실패 보라 회색 |
| `light_ray` | 32×512 | 1 | 빛줄기. 아래쪽 중앙 피벗 |
| `panel_9slice` | 48×48 | 1 | 네 변 12px |
| `gauge` | 256×32 | 1 | 공용 틀과 채움. 채움은 회색조로 제작해 용도별로 착색 가능 |
| `boss_nameplate` | 512×64 | 1 | 보스 이름판 |
| `icon` | 24×24 | 1 | 골드, 점수, 처치(칼), 시계 |

게임에서 사용하려면 화면이나 이펙트의 스프라이트 참조에 연결합니다. 9-slice 패널은 Unity UI의 `Sliced` 이미지로, 게이지 채움은 틀과 같은 크기로 포개고 가로 마스크를 적용해 사용합니다.
