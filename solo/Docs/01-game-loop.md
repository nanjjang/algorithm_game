# 01. 게임 전체 루프와 솔로 판 구조 — 구현 요약서

게임: "엄청엄청 위대한 마법사 키우기". 순정 Unity(MonoBehaviour, float 사용 가능) 솔로판 구현용 요약.
이 문서만 보고 메인 메뉴 → 캐릭터 선택 → 판 → 웨이브/야영/보스 → 판 종료 → 정산 → 강화로 이어지는 흐름 전체를 코딩할 수 있게 적었다.

- 출처 약어: D = `docs/DECISIONS.md`, G = `docs/GDD.md`, S09 = `docs/spec/09-run-verify-ranking-season.md`, S01 = `docs/spec/01-sim-core.md`, W = `docs/world-characters.md`, M = `docs/monsters.md`, O = `docs/online.md`. `(G 2.2)` = GDD 2.2절.
- 우선순위(CLAUDE.md 1절): D > spec > 그 밖의 기획 문서. 어긋나는 곳은 19절에 모았다.
- 표시: [확정] 개발자 확정 / [조율] D 2절 공통 규격 / [제안] 설계안(값은 그대로 쓴다) / [임시] 원문에 없어 명세가 넣은 기본값 / **미정** 값 없음.
- 시간: 게임 시간 1초 = 60틱(G 머리말). 순정 Unity에서는 `Time.deltaTime` 기반 초 단위로 써도 되지만, 아래 표의 틱 값은 같은 길이다. 거리 단위 1칸 = 64px(D 2.1).
- 화면 글자는 `data/names/names.ko.json` 열쇠로만 찍는다(15절). 캐릭터 표시 이름은 `char.1`~`char.5` = "제자 1"~"제자 5"(D 1.25).

## 2. 화면 흐름 전체 (상태 기계)

```
[부팅] → [타이틀] ─(J)→ [프로필 고르기*] → [메인 메뉴]
                                            ├ 원정 → [원정 준비] → (첫 판이면 [튜토리얼]) → [판] → [정산] → 메인 메뉴 | 강화 화면 | 다시 원정
                                            ├ 강화 → [강화 화면] → 메인 메뉴
                                            ├ 조립과 서고 → [조립·서고] (출발 조립 편집)
                                            ├ 연습 → [허수아비 연습]
                                            ├ 기록 → [기록]
                                            ├ 옷장 → [옷장]
                                            ├ 상점 → [골드 상점] (부적, +0 새 지팡이, 골드 꾸미기)
                                            ├ 설정 → [설정·키 재설정]
                                            └ 나가기
  * 솔로판은 오프라인 프로필 하나. 프로필 고르기는 생략하거나 오프라인 카드만 둔다.
```

### 2.3 원정 준비 (G 2.2-1·2, O 1.2-1·2, `str.expedition_prep.*`)
1. 캐릭터 고르기(5명 전부 처음부터 고를 수 있음, G 10.1).
2. 그 캐릭터의 지팡이 중 한 자루 고르기(여러 자루면 목록, `str.expedition_prep.wands`, `str.expedition_prep.wand_count`). 판 중에는 바꾸지 않는다.
3. 그 지팡이의 **출발 조립** 확인·수정(`str.expedition_prep.loadout`, `str.expedition_prep.change_loadout`).

4. 시작 웨이브 고르기(4.6절). 선택지가 0뿐이면 칸을 숨긴다(처음 하는 사람에겐 안 보임, M 4.7).

### 2.4 판 안의 흐름
```
판 시작(시작 웨이브 w0; w0>1이면 새벽 야영에서 시작)
  → 웨이브 w 전투 (Combat)
      ├ 적 전멸 → 웨이브 클리어(WaveEnd 처리 8절) → 드랍 흡수 1.0초 → 모닥불
      │          → 전리품 카드 선택 → 야영(Camp) → 출발(J 1초) → w+1
      ├ 플레이어 체력 0 → (첫 만남 웨이브 10이면 5.2절 쓰러짐→일어남→새벽 야영→웨이브 11)
      │                  → 아니면 판 종료(HpZero) → 정산
      └ 일시정지 → [계속 | 조작 보기 | 설정 | 판 포기(→ 정산) | 메인 메뉴로*]
```

\* `str.pause.to_menu`는 판을 끝내지 않고 나가는 버튼이라 솔로에선 **미정**(19절 Q4). 판 포기와 같게 처리하는 것을 권함.

### 2.5 정산 → 다음 (G 2.2-8, `str.settlement.*`)
- 정산 화면 쪽: 기록(점수 내역) `str.settlement.page.record` / 귀환 가방 `str.settlement.page.return_bag` / 가져가는 것 `str.settlement.page.takeaways`.
- 끝 버튼: 다시 원정 `str.settlement.again`, 강화 화면으로 `str.settlement.to_enhance`, 메인 메뉴 `str.settlement.to_menu`.
- 강화 화면 첫 안내 [제안] (G 13): 하급 강화석을 처음 받은 정산(까마귀 보따리 = 그 프로필에서 처음 웨이브 3을 넘긴 판) 뒤 강화 화면을 한 번 안내. 첫 판에서 웨이브 3을 못 넘기면 그 판이 나올 때까지 미룬다.

- 저장 시점: 판이 끝날 때(정산), 강화할 때, 조립을 바꿀 때.

## 4. 판의 구조

### 4.1 하루와 시간대 [조율] (D 2.3, G 2.2-6, W 2.2, `data/sim/waves.json`의 `day_length`, `tod_ranges`)
| 하루 속 순번 `slot = (w−1) % 10 + 1` | 시간대 id | 이름 열쇠 | 바닥 팔레트(W 2.4) | 연출 |
|---|---|---|---|---|
| 1~4 | `tod.day` | `tod.day` 낮 | 이끼 `#2F4A3A` / 맨흙 `#4A4034` | 기준 |
| 5~7 | `tod.dusk` | `tod.dusk` 해질녘 | 자두빛 `#3A2E3E` / 흙 `#4A3830` | 그림자 길어짐, 가장자리 윗면 호박색 빛 |
| 8~9 | `tod.night` | `tod.night` 밤 | 남색 `#161F3A` / 흙 `#222842` | 비네트, 달빛 테두리 `#5A6CA8` |
| 10 | `tod.boss` | `tod.boss` 보스 | 밤 팔레트 + 달빛 원 | 보스 등장. 처치하면 동이 트고 새벽 야영 → 다음 날 웨이브 1(누적 w+1) |

- N일째 = 올림(w ÷ 10) = `(w + 9) / 10`. 표기 "3일째 웨이브 23"(`str.battle_hud.day_wave` / `str.format.day_wave`). **웨이브 번호는 누적**이고 체력 배율·예산도 누적 웨이브로 오른다(W 2.2).
- 시간대 전환은 **야영 중 4초**에 걸쳐(웨이브 4·7·9·10 뒤의 야영). 전투 중에는 바뀌지 않는다(G 2.2-6, W 2.2).
- 밤의 어둠은 연출뿐. 시야·판정·적 속도·예고 시간은 낮과 같다. 밤에만 다른 것: 스폰 가중치(tod.json)와 별똥 결정(7.3절)(G 2.2-6).
- 예고 구역, 적 탄, 플레이어 탄, 열 링, 시야 화살표는 비네트·색 보정보다 위 층(W 2.2, W 2.4 규칙 4).

### 6.2 웨이브 점수 (직접 넘긴 웨이브) — 정수 계산 권장 (S09 8.3)
```
WaveScore(w):
  if phantom_first and w == 10: return 3648
  kill  = Σ cost(e) × 10 × (처치 틱 > 7200 ? 1/2 : 1)        // 졸개·낳은 개체·불러낸 개체 0
  boss  = 보스 처치 ? 3000 : 0
  clear = 200
  fastT = (w % 10 == 0) ? 7200 : 3600                          // 틱
  fast60 = max(0, fastT − 걸린 틱) × 2                         // 단위 1/60점
  nohit = 무피격 ? 100 : 0
  graze = 5 × min(스침 수, 보스 ? 40 : 20)                     // 보스 최종 격노(180초) 이후 스침 제외
  base60 = (kill + boss + clear + nohit + graze) × 60 + fast60
  s = floor(base60 × (9 + w) / 600)                            // 한 번만 나눠 내림
  for m in 변덕 배율(115|120|125): s = floor(s × m / 100)      // 2개면 차례로 [임시]
  return s
```
- 걸린 시간 = 그 웨이브 `Combat` 시작 ~ 마지막 적 처치. 야영 시간은 넣지 않는다.
- 판 점수 `RunScore = Σ WaveScore(직접 넘긴 웨이브) + Σ SkipScore(1 .. start_wave − 1)`. 죽은 웨이브(못 넘긴 웨이브)는 점수 없음 [해석: "직접 넘긴 웨이브의 합"].

### 6.3 건너뛴 웨이브 점수 (M 4.7, S09 8.3)
```
B(w) = 10 + 6w                       (w ≤ 12)
     = min(200, 82 + 4(w − 12))      (w ≥ 13)          // waves.json budget_linear / budget_late
SkipScore(w) = floor((w % 10 == 0 ? 3200 : B(w) × 10 + 200) × (9 + w) × 6 / 100)
```

## 8. 웨이브 종료 처리 (S01 10.6, G 7, G 12)
마지막 적이 죽은 틱에, 그 틱 처리가 끝난 뒤:
1. 남은 결정 × 5골드 → 원정 지갑. 결정 0. (그믐: 빚은 이미 결정 0이므로 별도 처리 없음)

4. 웨이브 결과 기록: 점수 내역(처치/보스/클리어/빠른 처리/무피격/스침/변덕), 걸린 틱, 엘리트 수, 보스 처치 여부.

## 10. 정산 (판 종료 → 프로필) (G 2.2-8, O 1.2-6, S09 8.1 중 오프라인 해당분, M 6)

오프라인은 기기가 정산한다(S09 10). 순서:

### 10.1 골드
- 원정 지갑 잔액 → 프로필 골드. 지갑 = 처치·클리어 골드 + 결정 환전 + 버린/남은 블록 환전 − 회복 − 다시 뽑기 (≥ 0) (S09 3.7 GoldBreakdown).

| 항목 | 규칙 |

| 칸수 | `min(12, 직접 넘긴 웨이브 수 / 3)` (몫). 기본 칸 없음 |
| 영웅 한도 | `직접 넘긴 웨이브 수 / 10` (몫), 칸수 안에서 |

| 세는 웨이브 | 이번 판에서 직접 넘긴 웨이브만(건너뛴 웨이브 제외) |

### 10.3 강화 재료 추첨 (G 12, O 2.2, M 6.3)
- 재료(강화석)·부적은 판 씨앗이 아니라 **정산 때 기기 난수**로 뽑는다(판 중에 쓴 "기회 목록"을 보고). 블록 카드·체력 조각은 판 중에 판 난수로 뽑는다.
- 확정 수량은 야영 화면에 미리 보여 주고, 추첨분은 정산 화면에서 꾸러미 여는 연출(`str.settlement.take.bundle`, `item.material_bundle`).
- 까마귀 보따리(`item.crow_bundle`): 그 프로필이 **처음** 웨이브 3을 넘긴 판의 정산에서 하급 강화석 3개(한 번, M 표 6.3-A).
- 표의 수치(5번째 웨이브, 보스, 엘리트별 확률)는 드랍 문서 담당(M 6.3).
- 시즌 주화·시즌 한정 드랍: **솔로 제외**(오프라인에선 나오지 않음, M 6.4, O 8.1).

### 10.4 첫 만남·복수
- 첫 만남 판이 웨이브 10을 넘겼으면 phantom_met = true(정산 때 바로).
- 웨이브 20 허상 첫 처치 판이면 복수 보상 지급 + revenge_done = true(5.3절). 추적기 값 갱신: phantom_tries(웨이브 20에서 허상에 도전했으면 +1), phantom_best_dent = max, revenge_runs.

## 11. 강화로 이어지는 부분 (진입과 흐름만. 규칙 세부는 강화 문서)
- 진입: 메인 메뉴 "강화", 정산 화면 "강화 화면으로". 판 중·야영엔 없다(D 2.4).

- 결과 분기(G 9): 대성공(성공의 15%, +2·슬롯 1칸, +1 도전엔 없음) / 성공 +1 / 실패 −1(+3 이하 하락 없음, 역대 최고 −2 아래로 안 감) / 폭주 변이(실패 중 25%). 장인의 기운, 부적, 슬롯 새기기, 변이 제거, 기댓값 표시 등은 강화 문서 담당(G 9, O 1.3~1.6, O 2.4).
- 강화 배율: 단계당 ×1.15(+13 ≈ 6.2배). 판 중엔 단계가 변하지 않는다(유리 지팡이 변이의 판 안 임시 하락만 예외, G 9).
- 오프라인 프로필도 같은 화면, 같은 확률, 같은 연출. 난수는 기기(G 9). 알림 없음.
- 상점(오프라인): 부적과 +0 새 지팡이는 메인 메뉴 상점에서만 산다(G 2.1-2). +0 새 지팡이 500골드(G 확인 74).
