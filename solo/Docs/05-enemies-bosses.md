## 1. 위험색과 예고 그리기 규칙 (S5 1.4, 8, 9 / M 1.4, 5)

### 1.1 위험색 정의 [확정: D 2.2]
- 위험색 = 색상각 330~15도 **그리고** 채도 ≥70% **그리고** 명도 ≥70%. **적의 공격과 예고에만** 쓴다(플레이어·메뉴·드랍·배경 금지). 쓸 때는 채도 80% 이상 + 흰 중심을 같이.
- 판정 함수: `IsDanger(h,s,v) = (h>=330 || h<=15) && s>=70 && v>=70`.

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `danger.zone.red` | `#FF3B30` | 예고 구역 채움·테두리 가운데 겹 |
| `danger.bullet.body` | `#FF2E88` | 적 탄 몸 |
| `danger.bullet.core` | `#FFFFFF` | 적 탄 흰 중심점 |
| `danger.bullet.outline` | `#A3004E` | 적 탄 외곽선 |
| `danger.weapon_tint` | `#FF2E88` | 공격 준비 무기 부위(예고와 **같은 틱**에 시작) |
| `zone.border.outer/mid/inner` | `#000000` 2px / `#FF3B30` 4px / `#FFFFFF` 2px | 예고 3겹 테두리(합 8px) |
| `rim.light` | `#EAF2FF` | 적·플레이어 윤곽 2px 림, 세기 낮 20%·해질녘 40%·밤/보스 60% |
| `outline.enemy` | `#1B2440` | 적 외곽선 |
| `gold.value` | `#FFD24A` | 엘리트 표식·골드에만 |

- 적 몸 색 규칙(그림 검수용, 구현은 회색 도형이면 무시 가능): 명도 ≥60%, 채도 ≤50%, 색상각 280~15도 금지, 청록 150~180도 금지, 눈은 흰/연노랑만.
- 보스의 탄·구역은 속성과 무관하게 위험색 (S6 2.4).
- 반투명/어둠에 숨는 적 없음. 밤에도 적 밝기 동일.

### 1.2 예고(텔레그래프) 수명 — 핵심 계약 (S5 3.3, 9.1) [확정: 문법]
시작 틱 `s`, 예고 길이 `N`(틱):

| 단계 | 틱 | 동작 |
|---|---|---|
| 나타남 | `s` | 최종 크기 3겹 테두리 즉시 전부 표시(**자라지 않음**), 구역 안 바닥 40% 어둡게. `lock=at_start`면 이때 방향 고정. 무기 부위 자홍 |
| 차오름 | `s..s+N` | `fill = (now−s)/N` 일정 속도. 채움은 빨강 70% 덮기, 앞선(흰 2px + 검정 2px) 함께 이동 |
| 번쩍 | `s+N−2`, `s+N−1` | 구역 전체 흰색 2프레임 |
| **판정** | **`s+N`** | 플레이어 판정원이 구역과 겹치면 피해. 남는 구역 생성. **차오름 끝과 판정은 같은 틱**(어긋나면 버그) |

- 차오르는 방향: Circle 중심→밖(반지름 r×fill), Band 적에게서 먼 쪽으로(길이 L×fill), Fan 꼭짓점→호, AimLine 빨강 굵기 2→8px(흰 심 2px 처음부터, 고정 순간 한 번 떨림), Ring 안쪽→바깥.
- `lock=last_n_ticks(n)`: `s..s+N−n` 동안 매 틱 플레이어를 향해 방향 갱신, `s+N−n`에 고정 + 떨림 이벤트.
- 판정 순간 맞지 않았고 경계 바깥 0.6칸(제자2 0.75) 안이면 스침 인정.
- 예고 모양은 **5종 고정**: `circle`, `band`, `fan`, `aim_line`, `ring`. (데이터 shape 문자열)
- 번쩍 한도: 최근 1초(60틱) 번쩍 넓이 합 > 화면 25%(1920×1080 기준 518,400px)면 번쩍 대신 흰 선 8px 테두리 강조 (S5 9.4) [제안].
- 남는 위험 구역(가시밭·불씨 띠·포자 안개): 3겹 테두리 + 빨강 빗금(4px, 간격 16px, 45도), 차오르지 않음, 사라지기 1초 전부터 초당 2회 깜박.
- 피해 없는 방해 구역(서리밭): 자홍 테두리 + 흰 빗금.
- 소리: 동시에 여러 예고면 가장 먼저 터질 2개만 차오름 음 (S5 9.3).
- 등장 예고: 일반 적은 스폰 지점 덤불 0.5초(30틱) 흔들림(덤불색, 위험색 아님), 그동안 피해 주고받지 않음 [임시 U-07]. 가시덩굴은 흙 금 1.0초(60틱).

### 1.3 예고 취소 (S5 3.2, 6.2)
- 꼬리표 없는 일반 적·뿌리 적은 **빙결**되면 예고 취소(구역 즉시 제거, 판정 없음, 동시 예고 수 −1). 엘리트는 유지. 기절(⑨)도 취소 대상(북두꺼비 울음 등).
- ② 반동 사격의 "돌진 예고 취소 + 0.8초(48틱) 경직"은 **꼬리표 없는 덤불 늑대에게만**.
- 빙결 내성: 한 번 언 적은 6초(360틱) 동안 다시 얼지 않음(살얼음 적중 수도 쌓이지 않음). 기준 = 빙결 시작 틱 [임시 U-67].

## 2. 회피 보장 규칙 R1~R5 (S5 1.2, 10 / S6 2.13)

모든 적·보스 공격이 지킨다. 데이터 로드 때 검사하는 것을 권장(실패 시 경고/로드 실패).

| 규칙 | 내용 | 구현 |
|---|---|---|
| R1 | 예고시간 ≥ 0.25 + 벗어나는거리/V + 0.05 | 로드 검사: `(T_ms−300)×V ≥ d×1000` |
| R2 | 예고 없이 몸으로 부딪치는 적의 이동속도 < V (버프 후에도). 늑대만 예외(접촉 피해 0) | 로드 검사 + 런타임 상한 `min(speed, V−ε)` [임시 U-22] |
| R3 | 흩뿌림·연사 탄은 발사점 3칸 지점 이웃 탄 사이 **호 길이** `3×Δθ(rad)` ≥ 1.0칸, 속도 ≤ 9 | 로드 검사 |
| R4 | 속도 > 9 조준 탄은 조준선 + 발사 0.4초(24틱) 전 방향 고정 | `lock_seconds ≥ 0.4` |
| R5 | 새 예고 시작 전, 떠 있는 예고 + 남는 위험 + 새 구역을 함께 놓고 "0.25초 뒤부터 V로 움직여 각 구역이 터지기 전에 밖에 있을 수 있는 길"이 없으면 시작하지 않고 대기 | 런타임 BFS(2.2) |

벗어나는 거리 `escape` (S5 10.1): Circle `r+0.15` / Band·AimLine `w/2+0.15` / Fan(반지름 R, 반각 α) `R·sinα/(1+sinα)+0.15` / 두 띠 교차점 `√2×(w/2+0.15)` / 데이터 `escape_override_milli`가 있으면 그 값(밀리칸).

- 웨이브가 깊어져도 **적 이동속도와 예고시간은 절대 변하지 않는다**. 격노도 예고를 줄이지 않는다.
- 유일한 예외: 허상 첫 만남 마무리 "되비침"(입력 잠금 연출, 9.5절).

### 2.1 동시 예고 상한과 대기 줄 (S5 3.4)
`TelegraphCap(w)`: 1~4 → 2, 5~8 → 3, 9~12 → 4, 13~29 → 5, 30+ → 6 (`waves.json.telegraph_cap`).
- 떠 있는 구역 1개 = 1. 여러 구역을 내는 공격(화분 어미 흙 띠 4, 꽃 핀 가시덩굴 씨앗 2)은 **전부 아니면 전무**. 조준선도 1. 시전 동작(술사 0.4초, 도깨비불 0.6초 등 구역 없는 탄 시전)은 세지 않음 [임시 U-11, U-12].
- **보스 패턴 하나의 여러 원(낙석 6, 기둥 4, 구름 3)은 1개로 센다** [조율 S6 C7]. 남는 위험 구역은 상한에 넣지 않음(R5에는 넣음).
- 대기 줄: 매 틱 (요청틱, id) 오름차순으로 전부 재검사. 앞 요청이 막혀도 뒤는 검사(줄 머리 막힘 없음). 단 120틱 넘게 기다린 요청이 막혀 있으면 그보다 늦은 요청은 그 틱 시작 안 함 [임시 U-50a]. 재검사 때마다 구역 위치는 현재 플레이어 기준으로 다시 계산 [임시 U-08]. 요청자 사망/조건 소멸이면 폐기.
- 예고 없는 적(슬라임·박쥐)은 상한과 무관.

### 2.2 R5 검사 알고리즘 (S5 3.5) — 솔로용 요약
- 격자 48×28(칸 0.5), 시간 단계 0.05초(3틱). 처음 5단계(0.25초) 제자리, 이후 8방향 이동. V=3.76: 직교 이웃 3단계, 대각 4단계 / 서리밭 칸 출발: 직교 4, 대각 6.
- 정적 막힘: 전장 밖, 장애물(바위·얼음 기둥), 남는 위험 구역(중심 거리 < 모양+0.15).
- 시간 막힘: 구역 z가 단계 `kz=floor((detonate−now)/3)`에 터지고, 칸 중심이 **구역을 0.10칸 줄인 모양**(양자화 보정 e=−0.10) 안이면 그 단계 위험 [임시 U-13, C-10]. 터진 뒤 위험 구역을 남기면 이후 단계 막힘.
- `kz ≤ 5`인 기존 구역은 검사에서 뺀다. 모든 구역이 그러면 통과.
- 지평선 K = max(kz)+6. 시작 칸은 막혀 있어도 출발 허용. 대각 이동은 모서리 자르기 금지(가로·세로 이웃이 둘 다 비어야). `reach[K]`가 비어 있지 않으면 통과.
- 탄은 넣지 않는다. 실제 캐릭터가 더 빨라도 V로 검사.
- 검증 벡터(S5 TV-R5): 단독 공격 14종 전부 통과, 원 1.8 + 반경 2.6 위 원 1.5×8 = 실패, 서리밭 칸 휘두르기 60틱 실패/72틱 통과, 가마등 발구르기 54틱 통과/48틱 실패.
- 솔로에서 R5를 생략하면 동시 예고로 피할 수 없는 상황이 생긴다 → 구현 권장(비트셋 21×ulong 또는 bool[48,28]).

## 3. 피해·체력 공식 (S5 3.7 / S6 2.2, 2.7)

### 3.1 플레이어가 받는 피해
```
if 접촉/탄/남는구역(contact, projectile, lingering): base = 1   (가마등 접촉 2는 종별 값, S6 C3)
else (예고 공격 telegraph): base = attack.damage
     if w >= 61: base += 1
     else if w >= 31 && (엘리트 || 보스): base += 1
if 보스 최종 격노: base += 1   (접촉·탄 포함 모든 공격, S6 C4/U1)
return min(base, 3)            // 공격 쪽 상한 3칸
// 그 뒤 플레이어 쪽 보정(제자5 그믐의 빚 +1 → 최대 4)은 플레이어 문서 소관
```
상수: `waves.json.damage`(`elite_boss_plus_from`=31, `attack_cap`=3), `bosses.json.common.final_rage_damage_plus`=1.
예고 뒤에 나오는 탄(발구르기 고리, 도약 8방향 등)은 "탄"이라 성장 없음 [임시 S6 2.7].

### 3.2 체력 배율 H(w) (S5 3.7, waves.json)
- `w ≤ 12`: `1 + 0.12×(w−1)` / `w ≥ 13`: `2.32 × 1.06^(w−12)`.
- 값: H(1)=1.00, H(6)=1.60, H(10)=2.08, H(12)=2.32, H(13)=2.4592, H(20)≈3.6977, H(30)≈6.6221, H(40)11.9, H(50)21.2, H(60)38.0, H(100)≈391.2.
- 일반 적 최대 체력 = `base_hp × H(w)`; 엘리트 ×3(`elite_hp_mul`); 변덕 "두꺼운 가죽" ×1.3.
- 보스 체력 = `base_hp × H(w) / H(hp_scale_anchor_wave)` (기본 10). 기대값(S6 T011~T020): 가마등 w10 3000, 허상 w20 7111, 천 갓 w30 14326, 밤눈 w40 28507, 흰뿔 w50 56157, 밤삼킴 w60 118855, 가마등 w70 98239, 허상 w80 234575. (정수 내림 반복 기준. float면 ±몇 차이 허용)
- **속도·피해 칸 수·예고 시간은 배율을 받지 않는다.**
- H(w)를 곱하는 그 밖의 수치: 꽈리 유폭 20(왕꽈리 60), 멧돼지 경로 피해 10, 북두꺼비 울음 끊기 30(큰북 60), 졸개 체력 [임시 U10].

### 3.3 적이 받는 피해
- 상성: 약점 ×1.25, 저항 ×0.8, 그 외 ×1. 속성 = **맞힌 투사체 블록의 속성**. 무속성(꽈리 유폭, 멧돼지 경로 피해, 돌 파편)은 상성 없음. 졸개는 상성 없음(`element.neutral`).

## 4. 공통 적 상태 기계 (S5 3.1, 3.2)

틱 순서 [임시 U-06]: 입력 → 플레이어 이동 → 적 AI(id 오름차순: 상태 전이·이동 의도·예고 **요청**) → 대기 줄 처리(허가된 요청 → 예고 구역) → 판정(`detonate==now`) + 남는 구역 생성 → 적 이동·탄 이동·충돌·접촉 → 피해 적용·사망·버프 만료 → 남는 구역 만료 → 표시 이벤트.

```
Spawning(30틱, 피해 주고받지 않음) → Act(종별 이동)
Act ─(공격 조건)→ RequestTelegraph ─허가→ WindUp(N틱, 무기 자홍) ─→ Strike ─→ Recovery(빈틈) ─→ Act
                     └─거부(상한/R5)→ Waiting(이동은 종별 규칙대로, 공격 시작 안 함) ─재검사 허가→ WindUp
어느 상태든 Hp ≤ 0 → Dead(사망 부수효과 뒤 제거, 사체 없음)
WindUp ─(빙결/기절, 취소 가능한 적)→ Interrupted → Act
```

접촉 피해 (S5 3.6):
```
if def.contact_damage>0 && !Burrowed && state!=Spawning && 겹침(body_radius, 0.15) && now>=contactReady:
    플레이어 피해 1(Contact); contactReady = now+90
```
- 비행 적의 판정 위치 = 발밑 그림자 중심(= Pos). 늑대는 접촉 0, 족제비는 땅속일 때 0.

스폰 위치 (S5 3.11): 플레이어에게서 **먼 두 변**에서 균등(모서리 1칸 제외). 동률은 위, 오른쪽, 아래, 왼쪽 순 [임시 U-24]. 가시덩굴은 예외(벽 2칸 이상 + 플레이어 3칸 이상 [임시 U-60]). 족제비는 땅속 상태로 변에서 [임시 U-25]. 이동은 직선 추적 + 장애물 미끄러짐(길찾기 없음) [임시 U-26]. 그림은 좌우 반전만(`flipX = facing.x<0`).

## 5. 꼬리표 반응 (S5 6, W 3.6) — 비기·패시브는 종이 아니라 꼬리표로 판단

- 비행 적도 바닥 지대(불가마) 피해·감속을 받는다.

### 8.3 상태 기계 (S6 2.8)
```
Intro(72) → Waiting(이동 AI, 대기 = 90×(10−rage)/10 → 90,81,72,63,54,45)
Waiting ─패턴 고름 + 첫 예고 R5 통과→ Telegraph(하위 예고 차례로, 각 단계 R5) → Execute → Recovery(recovery_seconds) → Waiting

어느 상태든: hp×100 ≤ hpMax×다음단계.enter_at_hp_percent → PhaseTransition(36) → Waiting
  (단계는 되돌아가지 않음. 한 틱에 두 경계를 넘으면 마지막 단계로 한 번만 전환)
hp==0(Normal) → Dead  /  첫 만남은 9절
```
- 패턴 고르기: 현재 단계 `patterns`에서 직전 패턴 제외 + `Eligible` 필터 → 비면 직전 포함 허용 → 그래도 비면 30틱 더 대기. 균등 난수 [임시 U9]. 보스별 강제 규칙(흰뿔).
- 한 번에 한 패턴. `passives`(상시 행동)는 패턴과 별개로 돈다.
- 격노: `fightTicks`(등장 끝부터) / 1200 = 스택(최대 5). 연사형(`rapid_fire: true`) 간격 = `base×(10−n)/10` 내림, 하한 `min_interval_ticks`(R3).
- 보스 반응: 넉백·기절 면역, 탄은 모두 스침 대상, R2: 모든 보스 속도 < 3.76(북두꺼비 버프 안 받음).
- 단계 눈금 = `enter_at_hp_percent`(100 제외). HUD: 이름(`boss.*`), 체력, 격노(`str.battle_hud.boss.rage` "격노 {n}", 최종 `str.battle_hud.boss.final_rage`), 약점/저항(`str.battle_hud.boss.weak`/`.resist`) 문양. 격노 연출: 림 2→6px 0.3초, 검은 김 초당 2×스택(위험색 금지), 최종 격노 시 체력 바 빨강 테 + 화면 가장자리 자홍 8px(HUD 층).
- 보스 사망: 1.0초 느린 연출(표시만) → 흰 번쩍 → 조각·드랍 분수, 남은 적 탄 전부 제거, 남은 졸개 즉시 제거 [임시 U11]. 처치하면 해가 뜨고 새벽 야영(체력 1칸 무료).

### 8.4 bosses.json 패턴 데이터 형식
- 보스: `id`, `rotation_index`, `base_hp`, `hp_scale_anchor_wave`(10; 허상 대안 20 — Q6), `move_speed`, `move_speed_on_frost`(흰뿔만 2.4), `contact_damage`, `body_radius`[임시], `element`/`weak`/`resist`, `phases[]`, `patterns[]`, `second_cycle[]`(Cycle ≥ 2일 때 적용할 덮어쓰기). 보스별 추가: `movement`, `phantom_copy`, `first_encounter`(허상), `body`(밤삼킴).
- phase: `index`, `enter_at_hp_percent`(이하가 되면 진입), `patterns`(키), `passives`(키), `tags`, `overrides[]`(`{pattern, step, key, value}` — 해당 패턴 step의 필드 덮어쓰기), `anchor_radius`(천 갓 1단계 중앙 1칸).
- pattern: `key`, `passive`(상시 여부), `graze`(`charge`/`bullet`/`zone`), `recovery_seconds`(패턴 뒤 빈틈), `recovery_damage_ratio`(빈틈 중 받는 피해 배율, 가마등 기절 1.5), `steps[]`.
- step: `attack`(AttackDef, 아래), `repeat`(반복 횟수, **0 = 상시 행동이 계속**), `repeat_interval_seconds`(반복 시작 사이, 0 = 앞 반복 끝난 틱), `repeat_angle_degrees`(반복마다 회전), `telegraph_each_repeat`(반복마다 예고 다시), `count`(한 번에 까는 구역·띠·졸개 수; 탄 수는 `proj.count`), `start_delay_seconds`(앞 단계 판정 틱 + 지연), `placement`(`at_player` 플레이어 위치에 둘 개수, `min_player_distance`, `max_player_distance`, `min_spacing` 서로 중심 거리, `wall_margin`, `max_tries` 거부 표본), `obstacle`(`kind`, `radius`, `duration_seconds`(0 = 무한), `hp`(0 = 플레이어 탄으로 안 깨짐), `max_count`(0 = 무제한), `blocks_player_shots`, `blocks_enemy_shots`, `shards` 깨질 때 탄), `clear_hazard_margin`, `rapid_fire`, `min_interval_ticks`, `stream`(`shots_per_second`, `sweep_degrees`, `sweep_degrees_per_second`), `frost_telegraph_seconds`, `hazard_speed_ratio`, `copy`(`arts`, `fallback`, `warn_seconds` — 허상), `summon`(`enemy`, `count`, `field_cap`(0=없음), `warn_seconds`). **다음 step은 앞 step의 판정 틱에 시작한다.**

## 10. 허상 첫 만남·복수 (S6 9~11) — 오프라인 프로필 포함

### 10.1 언제 (오프라인)
- 오프라인 저장 파일의 `phantomMet`(새 프로필 false). 출발 때 `phantomFirst = !phantomMet`을 판 정보에 넣는다. 캐릭터 무관, 프로필마다 1회.
- `phantomMet = true`로 바꾸는 때: 첫 만남을 치르고 웨이브 10을 넘긴 것으로 정산된 판. 싸움 도중 "판 포기"/강제 종료(마지막 중간 지점 5)면 그대로 false.
- 시작 웨이브 고르기는 최고 웨이브 15부터 열려 첫 만남을 건너뛸 수 없다.

### 10.2 첫 만남 설정 (`first_encounter`)
| 필드 | 값 | 의미 |
|---|---|---|
| `hp_floor_percent` | 50 | 체력 4000(w10 배율 1), 2000에서 멈춤. 피해 숫자는 계산값 그대로 |
| `max_fight_seconds` | 45 (2700틱) | 등장 끝부터 |
| `rage_stacks` | 5 | 처음부터 최대(대기 45틱, 연사 최단), 최종 격노 없음 |
| `start_phase` | 3 | 처음부터 3단계 행동 전부. mimic_art는 해금 무관 ③④⑧ 셋 다(연속 금지). 졸개 없음, 단계 전환 없음 |
| `finisher_seconds` | 3.0 (180틱) | 되비침 |
| `finisher_hp_zero_ticks` | 114 | 되비침 시작 +114틱에 플레이어 체력 0 |
| `collapse_seconds` | 4.0 (240틱) | 쓰러짐 |

```

Fight 종료 조건(같은 틱 우선순위: 체력0 > 50% > 45초):
  플레이어 hp==0       → 바로 Collapse (판 종료·사망 문구·정산 없음 — 사망 처리 가로채기)
  허상 hp==hpFloor     → Reflection (거울 금 0.4초 연출)
  fightTicks>=2700     → Reflection

```
- 플레이어는 평소와 똑같이 싸운다(연출용 무적·약한 탄 없음). 공격은 전부 R1~R5 준수.
