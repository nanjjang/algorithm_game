### 1.2 알고리즘 (S01 9.2~9.4)
```
OnPlayerProjectileHit(p, shotId, isCrit, source):
  if source in {Skill(비기), CopyCircle, Passive, Zone(불가마 등 지대)}: return   // [임시] 패시브·지대 제외
  p.comboIdleTicks = 0                       // 상한에 걸린 적중도 타이머는 다시 채운다 [임시]
  gained = p.shotComboGain[shotId] ?? 0
  inc = min(isCrit ? 2 : 1, 3 - gained)
  if inc <= 0: return
  p.shotComboGain[shotId] = gained + inc
  Add(p, inc)

Add(p, n):
  old = p.combo; p.combo += n
  k = p.stats.comboPerCrystal                // 15 또는 12
  for i in 1..(p.combo / k - old / k): Crystal.Gain(p, source: Combo)   // 15, 30, 45…를 "지날 때"
  emit ComboChanged(p.combo, n)

TickIdle(p):                                  // 틱 끝(02 요약서 2절 11단계)
  if p.locked or p.combo == 0: return
  if ++p.comboIdleTicks >= 120: Reset(p, Timeout)

Reset(p, reason): combo = 0; comboIdleTicks = 0; shotComboGain.Clear()
```
- "적중 하나" = 적중 이벤트 하나. 관통·그림자 구체·폭발·연쇄 전이로 여러 적을 맞히거나 부메랑이 한 적을 두 번 맞히면 각각 적중이고, 모두 **같은 shotId의 +3 상한을 나눈다**. 트리거 하위 스코프·분열·거울상 탄도 부모 발사의 shotId(= 03 요약서의 CastId)를 물려받는다 [해석].
- 임계 적중 = 임계 발사(`isCrit`)가 만든 탄의 적중.
- `shotComboGain`은 그 발사의 탄이 모두 사라지면 지운다 [임시].
- 결정이 상한이면 결정은 얻지 못하고 **콤보는 계속 오른다** [해석].
- **스침도 타이머를 다시 채운다** [임시](스침 +2가 바로 끊기지 않게).
- 끓어넘침(제자 1 패시브)·불가마 피해는 콤보에 넣지 않는다 [임시].

끊김 이유 `ComboResetReason`: `Timeout`(2초), `Hit`(피격), `UnstableCore`(자폭), `Rise`(허상 첫 만남 일어남), `WaveEnd`(웨이브 끝 [임시]). (`RoundStart`는 결투, 솔로 제외)

### 1.3 표시 (S01 9.3, E 11.2)
- 숫자 아래 **2초짜리 가는 막대**(남은 비율 = 1 − idle/120). 잠금 중 막대가 멈추고 **자물쇠 점**.
- +1: 숫자 1.2배로 튀었다 돌아옴(0.08초). 5·10 단위: 숫자 색 흰색 → 속성 보조색 → 속성 주색. 결정 직전(남은 콤보 3 이하): 숫자 옆 작은 결정 윤곽이 차오름. 시간 초과 끊김: 회색으로 흐려지며 떨어짐 + "스륵". 피격 끊김: 숫자가 깨져 흩어짐(조각 6개).
- 위치 옵션 `combo_position`: 캐릭터 옆(기본, 캐릭터 기준 (+40,−72)) / HUD — 08 요약서 6.1.

### 2.2 함수 (S01 10.2~10.4, 10.6)
```
Gain(p, source):                      // source: Combo | Starfall
  if p.debt > 0: p.debt -= 1; emit DebtRepaid; return          // 그믐: 빚부터
  if p.crystals >= cap: emit CrystalGainBlocked; return
  p.crystals += 1; emit CrystalGained(index=p.crystals)
  if p.crystals == cap: emit CrystalsFull
  // 불변식: debt > 0 ⇒ crystals == 0

CanAfford(p, cost, allowCredit):
  if p.crystals >= cost: true
  else allowCredit && p.char == 5 && p.debt + (cost - p.crystals) <= 2

Spend(p, cost, allowCredit):          // CanAfford 참일 때만
  use = min(p.crystals, cost); p.crystals -= use
  short = cost - use; if short > 0: p.debt += short
SpendAll(p)                            // 만개: 전부(최소 3), 외상 불가

LoseOnHit(p):
  char.4: crystals > 0 이면 emit CrystalProtected, 잃지 않음
  char.5: debt > 0 이면 debt = min(2, debt+1); return. 아니면 lost = min(2, crystals)
  그 밖: lost = min(1, crystals)
  crystals -= lost   // 결정 1개인 그믐이 맞으면 0개, 빚은 생기지 않음. 0개·빚 0이면 아무 일 없음

OnWaveEnd(p):                          // 마지막 적 사망 틱의 처리가 모두 끝난 뒤
  purse += crystals × 5; crystals = 0
  Combo.Reset(WaveEnd) [임시]; 열 0·잠금 해제·열 면제 해제·불가마 흡수 0 [임시]; 스침 가속 해제 [임시]
```
- 빚 세부(S01 10.3): 최대 2. 판 끝까지 남는다(웨이브 끝·야영에도). 예외: 허상 첫 만남 일어남에서 0. 빚 > 0이면 받는 피해 +1칸. 빚 2면 외상 불가. 만개는 외상 불가.
- 판정 순서: ① 그믐이면 외상 먼저(빚 2 넘지 않게, 만개 제외) ② 그래도 모자라고 고른 노드가 고유 비기면 부모 노드 기술로 한 번 내려가 외상 포함 다시 봄 ③ 그 밖은 불발.

### 3.2 누적 가림 상한 (E 9.2)
7·8층(내 탄, 꼬리, 적중 불꽃, 폭발, 처치 조각, 비기 효과)을 **화면 밖 렌더 텍스처 한 장**에 모아 그린 뒤, 자리별 알파 상한으로 눌러 한 번에 합친다.

| 자리 | 합칠 때 불투명도 상한 |
|---|---|
| 예고 마스크 밖 | 80% |
| 예고 마스크 안 | **40%** |
| 예고 마스크 안 + 그 예고가 번쩍이는 마지막 2프레임 | **0%** |

- 예고 마스크 = 떠 있는 모든 예고 구역 + 남는 위험 구역(가시밭·불씨·포자)을 바깥으로 0.25칸(16px) 넓힌 모양. 예고 셰이더가 마스크 버퍼에도 같이 그린다.
- 상한은 "내 탄 투명도" 옵션을 곱한 **뒤**에 적용(옵션으로 못 올림).
- 합친 뒤 9층에서 예고 3겹 테두리와 차오름 앞선(흰 2px + 검정 2px)을 100%로 다시 그림.
- 3층(내 지대)은 버퍼에 넣지 않는다. 적 탄(10층)은 버퍼보다 위.
- 순정 Unity 구현 제안(원문 없음): URP Renderer Feature 또는 별도 카메라 → RenderTexture, 합성 셰이더에서 마스크 RT로 알파 상한 적용.

### 3.3 입자 처리 규칙 (E 9.3) — `data/presentation/particle_budget.json` 값은 08 요약서 15.3
- 입자 = 본체에서 떨어져 혼자 움직이다 사라지는 조각. **입자가 아닌 것**: 투사체 그림, 꼬리 띠(탄 1발당 띠 그림 1장), 총구 섬광 1장, 지팡이 본체·딸린 부품, 셰이더 고리·예고·열 링·잔상.
- 꼬리 띠 한도: 길이 0.75칸(48px) 이하, 4프레임 이하, 불투명도 70% 이하.
- 모든 입자는 **입자 예산 관리기 한 곳**에서 발급(분류·수명을 대고 요청, 안 주면 안 그림).
  - 반복 효과(분류 4 탄 입자·총구, 5 지팡이 대기, 6 환경): 몫이 차면 새로 안 만든다.
  - 일회성(1 내 비기, 2 적중, 3 처치): 몫이 차면 가장 오래된 것부터 0.1초에 흐려지며 자리를 내줌. 새 사건은 항상 보임.
  - 합계 넘침: 6 → 5 → 4 → 3 → 2 순으로 줄임. 1은 마지막.
- 같은 적에게 0.05초 안에 3번 넘게 맞으면 큰 불꽃 하나(입자 8). 한 프레임에 5마리 넘게 죽으면 조각 절반.
- 화면의 내 탄 수에 따른 자동 감소: ≤100 그대로 / 101~200 탄이 흘리는 입자 끔·꼬리 길이 절반·적중 장식 절반 / ≥201 꼬리 끔·적중 장식 최소형(입자 2개).

## 9. 주문 트리 디버그 글자 출력 (S02 14.5) [제안, 형식 임시] — 시험용

loadout := "core=" id "; links=" slot ("," slot)* [ "; char=" 1..5 ] [ "; ext=" 0..3 ] [ "; mut=" mut ("," mut)* ]

```

SPELL interval=9t heat=26.80 count=6/64 mirror_count=12/64 T=30.00

DIAG none
```
