# 11. 재미 조정(fun pass) — 바꾼 값, 이유, 측정

사용자 지시(2026-11-15): "게임이 재미없다, 묻지 말고 아주 재미있게, 최대 품질로". 수치 조정 권한을 받았다.
DECISIONS 불변식은 그대로다: 판 중 강화 없음(1.7), 야영은 조립·회복·비기 선택만(2.3), 키보드 조작(1.19), 강화 시간 규모(1.20), 위험색은 적 전용, 같은 씨앗 = 같은 결과.

## 0. 손잡이의 자리 — 명세 값은 그대로 둔다

| 자리 | 무엇 | 켜는 곳 / 끄는 법 |
|---|---|---|
| `Assets/Resources/DataSolo/FunPass.json` | 명세 사본(`Resources/Data/**`)과 보충 조각(`DataSolo/G01·G09·G10`) **위에 덮어쓰는** 손잡이 목록. 줄마다 `id`, `_note`(이유), `was`(전 값) | 게임 부팅 `ContentDb.LoadFromResources()`가 켠다. 테스트·도구의 `ContentDb.LoadFromDirectory()`는 **기본 꺼짐**(`applyTuning: true`를 줄 때만). 파일의 `"enabled": false`면 전부 명세 그대로 |
| `DataSolo/G09.json` `horde` 절 | 떼 출현(이미 있던 솔로 손잡이)의 보상 나누기·웨이브 곡선·역할 상한·빠른 처리 보정 | `WaveDirector.HordeEnabled = false`(테스트의 `WaveRig.Create(horde: false)`) |
| `DataSolo/Juice.json` `camera` 절 | 카메라 줌(표시 전용) | — |

덮어쓰기 도구: `Assets/Scripts/Data/TuningPatches.cs`. 경로 = `'/'`로 이은 마디(`이름`, `이름[*]`, `이름[열쇠=값]`), `set`(열쇠 덮어쓰기), `append`(배열에 더하기). `was`가 실제 값과 다르면 `ContentDb.LoadErrors`에 오류가 남는다 → 명세 사본이 바뀌면 조정이 모르고 덮는 일이 없다(테스트 `Fun_Load__AllPatchesApplyWithoutErrors`가 잡는다). 덮어쓴 글로 데이터 판(`DataVersion`)을 센다.

명세 벡터 테스트는 전부 손잡이를 끈 `TestContent.Db`로 돈다(조정 전과 같은 값). 조정을 재는 테스트만 `FunPassKit.TunedDb`를 쓴다.

## 4. 위험과 남은 것

- **사람 기준 시간은 재지 않았다.** 봇은 피하지 않고 맞으며(체력만 채움) 쏜다. 초반 웨이브 봇 15~25초는 사람에겐 더 길다. QA에서 웨이브 길이가 너무 짧으면 G09 곡선의 앞쪽(1.6)을 올린다.
- 냉각 대기 0.08초는 모든 손 뗌에 들어서 야영 뒤·이동 중 열도 빨리 식는다(전투 밖 영향은 작다). 냉각 속도·임계 시작이 다른 캐릭터(char.3·4)는 끊어 쏘기 이득이 +41~45%로 다른 캐릭터(+29~37%)보다 크다.
- 커맨드 여유창 확대로 "기본 간격 = 커맨드 초기화 시간"도 0.3 → 0.35초가 됐다(멈칫한 뒤 다시 시작할 때 0.05초 더 기다린다).
- 시작 결정 1개는 안 쓰면 웨이브 끝에 골드로 환전된다(웨이브 1~3에 결정 환전 골드만큼 수입 증가).
- 카메라: 1080p·1.5배에서 카메라는 화면 3px 걸음으로 움직인다. 개체(적·탄)는 맞춤 없이 그려지므로 비정수 배율에서 개체 그림의 px 폭이 1~2px로 번갈아 보일 수 있다(카메라 떨림은 없음). 4K(UI 2배)는 1칸 192px = 정수 3배라 그림 1px 걸음. HUD·화면 밖 표시는 줌을 읽어 그리므로 보이는 범위가 넓어진 것 말고는 그대로다(View 쪽 확인 필요).
- 떼 split의 누적기는 종마다 웨이브마다 새로 시작한다(웨이브를 다 못 잡고 끝나면 남은 소수점은 사라진다 — 지체 뒤 절반 점수 규칙은 그대로 앞서 적용).

## 5. 다른 작업에 넘길 것

- **WP5(표시)**: 적 출현 예고 표시 이벤트는 이미 있다 — `SimEventType.EnemySpawnNotice`(Id = 종, P = 자리, A = 예고 틱, `const.json spawn_notice_seconds` 0.5초, `EnemySystem.Spawn`이 낸다). 화면 가장자리의 "가시 덤불 흔들림" 같은 그림·소리를 이 이벤트에 붙이면 된다. 줌 1.5로 화면 밖 등장이 줄었지만 전장(24 × 14) 끝은 여전히 화면 밖일 수 있어 `OffscreenMarkerLayer`가 이 이벤트로 가장자리 표시를 내면 좋다. 새 SimEvent는 더하지 않았다(Core 계약 그대로).
- **WP3(전리품)**: 등급 확률은 고치지 않았다(`DataSolo/Loot.json rarity_by_day`가 WP3 손잡이). 측정상 웨이브 11에서 빌린 블록이 돌아가며 DPS가 193 → 171로 떨어진다 — 웨이브 10 보스(첫 만남) 카드의 확정 칸이나 둘째 날 희귀·영웅 비율(지금 71/25/4)을 조금 올리면(예 66/28/6) 8~15의 "점점 세지는 느낌"이 더 난다. 제안만 한다.
- **WP4(정산)**: split으로 처치 골드 지급 횟수가 늘어 `GoldGained` 이벤트 수가 1.6~2.5배가 된다(합계는 같다).
