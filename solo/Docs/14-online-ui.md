# 14. 온라인 화면 구성 (2026-11-15)

온라인 화면을 "가운데 어두운 판 + 같은 크기 버튼 줄" 대신 장면 그림 위에 비대칭으로 다시 짰다. 새 그림은 만들지 않았다. 이미 있던 화면 그림(`Resources/Art/ui/screen/*`, `docs/ui-assets.md` 4.3·4.5·4.11·4.20~4.25절)과 월드 소품을 썼다. 공용 부품은 `Screens/Online/OnlineUi.cs`에 있다.

## 1. 원칙 (로그라이크·RPG 레퍼런스 조사에서)

| 원칙 | 출처(조사) | 여기서 |
|---|---|---|
| 장면이 곧 메뉴: 판 하나를 띄우지 말고 장소 안에 둔다 | Enter the Gungeon의 Breach(장소마다 메뉴), Inscryption(탁자·저울이 곧 점수판) | 야영지(S-0501), 결투 쪽 VS, 장터 거리(S-2307), 탑 벽(S-2506), 작업대 |
| 한 화면에 주인공 물건 하나 + 옆에 좁은 도구 띠 | 레퍼런스 종합 | 기록·강화 = 가운데 강화대, 장터 = 카드 격자 + 오른쪽 팔기 판 |
| 글 대신 아이콘·숫자 | Balatro(색이 곧 이름표: 칩·배수·돈) | 골드 아이콘 + 숫자, 강화석·부적 아이콘, 상태 아이콘(I-F4) |
| 확률은 문장 대신 색 칸 띠 | MapleStory 스타포스(성공·유지·하락·파괴) | 대성공(금)·성공(초록)·변이(연두)·실패(회청) 띠 |
| 방 코드는 크게, 헷갈리는 글자 없이, 복사 단추 | Among Us 로비(코드가 아래 가운데) | 핀에 꽂힌 쪽지(S-2102)에 F-48 코드 + [복사] |
| 자리 = 캐릭터가 선 받침, 빈자리는 "기다리는 중" | Slay the Spire 2·Fall Guys 파티 칸, Risk of Rain 2 | 캐릭터 그림 192 + 흙 받침(S-0503) + 준비 표시(S-2103) + 방장(S-2104), 빈자리 모래시계(S-2105) |
| 1대1은 두 사람을 마주 세우고 가운데 VS | 격투 게임 대전 화면(Giant Bomb, Street Fighter 6) | 두 자리 사이 S-0902 "대" 글자 그림 |
| 광장 머리 위: 이름판 + 짧은 말풍선 | Ragnarok 머리 위 말풍선, MapleStory | S-2001 이름판(나/남), S-2005 말풍선 + 꼬리, I-F10 감정 아이콘 |
| 장터: 카드 + 값 큰 글 + 수수료 영수증 | Lost Ark 경매장(보증금·수수료 5%), Moonlighter | S-2306 카드, 묶음 값·개당 값·판 사람, 입력하면 바로 바뀌는 영수증 |
| 친구는 화면이 아니라 서랍 | Fall Guys·Hearthstone 친구 목록 | 오른쪽 640 서랍, 접속한 친구 먼저, 있는 곳 |
| 로그인은 게임 장면 위의 판 하나, 오류는 판 안 한 줄 | Google 로그인 가이드, Overwolf 로그인 가이드 | 왼쪽 "서버 명부" 판 + 오른쪽 모닥불 장면, 경고 세모 + 호박색 한 줄 |

"AI가 만든 것 같은" 화면의 특징(피한 것): 가운데 판에 사방 같은 여백, 같은 폭 버튼 줄, 아이콘 대신 문장, 모든 것이 같은 크기, "없음"만 적힌 빈 칸, 성공해도 아무 반응 없음, 모든 화면이 좌우 대칭.

## 2. 화면별

| 화면 | 장면 | 구성 |
|---|---|---|
| 로그인 `OnlineLogin` | 야영지 밤 + 모닥불 | 왼쪽 640×936 판: 서버 카드 그림(S-0301), 탭(로그인/새 계정), 이메일·비밀번호(● 가림 + 눈 S-0302)·이름, [들어가기], 또는, [Google 계정으로 계속], [비밀번호를 잊었다] + "지금은 보낼 수 없음" 꼬리표. 새 계정은 머리 그림을 접는다. 오른쪽에 서버에서 되는 것 세 줄 |
| 들머리 `CoopLobby`(방 밖) | 야영지 | 위 띠(이름·계정 종류·골드·레이팅, 기록·친구·장터·로그아웃), 모드 카드 3장(S-0502, 400×520, 내 기록 한 줄), 오른쪽 판에 고른 모드의 할 일 |
| 방 `CoopLobby`(방 안) | 야영지 | 쪽지에 방 코드, 자리 4개(결투 2개 + VS), 오른쪽 판에 모드·인원·설명·결과 띠(S-1701)·[시작]·봇·[나가기] |
| 기록·강화 `OnlineProfile` | 탑 벽 | 왼쪽 제자 5명(얼굴·단계), 가운데 강화대(큰 그림·단계·확률 띠·비용·떨어짐·변이·제물 칸 5·창고 격자·부적·조립·강화, 변이 제시 쪽지), 오른쪽 순위 석판(S-2503, 1~3위 메달, 내 줄 고정) |
| 조립 `OnlineAssembly` | 작업대 | 위 판: 지팡이 + 회로(코어 K-63 → 이음 K-65 → 연결 칸 K-60, 칸마다 아이콘·이름), 아래 창고 격자, 변이 지우기, [칸 비우기] [저장] |
| 장터 `OnlineMarket` | 장터 거리 | 수레 띠(S-2305), 품목 카드 5×2(S-2306) + 쪽 넘김, 오른쪽 팔기 판(창고 격자, 개수·값, 영수증, [올리기], 내가 올린 것과 남은 시간) |
| 친구 `OnlineFriends` | 야영지(어둡게) | 왼쪽 까마귀 우편(facility.crow_mail) + 안내, 오른쪽 서랍(신청 칸, 받은 신청, 친구 목록 + 상태 아이콘) |
| 광장 `Plaza` | 야영지 | 문 = 한뎃벌 문·결투 게시판 소품 + 팻말(S-2007), 이름판·말풍선·감정 아이콘, 위·아래 어두운 띠 |
