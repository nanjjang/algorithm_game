# 인수인계: 솔로 빌드 통합과 나머지 작업

다른 코딩 에이전트(Codex, OpenCode 등)가 이어받기 위한 문서다. 작업 폴더는 `D:\algorithm_game\solo`.

## 1. 이 프로젝트가 무엇인가

게임 "엄청엄청 위대한 마법사 키우기"(2D 탑다운 로그라이크)의 **솔로(오프라인) 플레이 전부 + 지팡이 강화**를 순정 Unity 6000.3.20f1(2D URP, C#)로 만든 별도 프로젝트다.
흐름: 타이틀 → 메인 메뉴 → 원정 준비(캐릭터·지팡이·출발 조립·시작 웨이브) → 판(웨이브 전투 → 전리품 → 야영 → … → 10웨이브마다 보스) → 정산 → 강화 화면.

- `solo/` 밖(`unity/`, `src/`, `server/`, `tools/`, `tests/`, `data/`, `art/`, `docs/`)은 **읽기만 한다.** 옛 코드와 원본 데이터·그림이다.
- 규칙은 `AGENTS.md`(= `CLAUDE.md`)에 있다. 반드시 먼저 읽는다.

## 4. 도구 (모두 `solo/Tools/`, Git Bash에서 실행)

| 명령 | 하는 일 |
|---|---|
| `bash Tools/compile.sh` | Unity 없이 Roslyn으로 전체 컴파일. 수 초. `-f <폴더,폴더>`로 오류 필터, `-w`로 경고 포함. 끝 코드 0 통과 / 3 미확인(다시 돌린다) |
| `bash Tools/unity-compile.sh` | Unity 배치 모드 컴파일. `-m <메서드>`로 에디터 메서드 실행 |
| `bash Tools/unity-test-edit.sh` | EditMode 테스트. 결과 `Logs/unity/test-edit.xml` |
| `bash Tools/unity-test-play.sh` | PlayMode 테스트. `-w`는 창을 띄움. 결과 `Logs/unity/test-play.xml` |
| `bash Tools/artsync.sh` | `art/`의 그림을 `Assets/Resources/Art`로 다시 복사 |

주의:
- **Unity는 한 번에 한 프로세스만** 이 프로젝트를 열 수 있다. Unity 에디터 창을 열어 둔 채로는 배치 명령이 실패한다.
- 테스트 실행에 `-quit`을 붙이지 않는다(붙이면 테스트가 돌지 않고 0이 나온다). 래퍼가 알아서 한다.
- Unity 경로: `C:\Program Files\Unity\Hub\Editor\6000.3.20f1\Editor\Unity.exe`
- 배치 모드에서는 `ScreenCapture`가 파일을 만들지 않는다. 스크린숏은 `Assets/Tests/PlayMode/Integration/SmokeCapture.cs` 방식(RenderTexture)을 쓰거나 `-w` 창 모드로 찍는다.

## 6. 알아 둘 결정과 남은 일

- **소리 파일이 없다.** `ISoundPlayer`는 무음 구현이다. 이벤트 id만 걸려 있다.
